## imo-2026-01

**The clean winning route (scouted, numerically verified, NOT a proof yet — outliner's job).** The blackboard move is, prime-by-prime, a **subtractive Euclidean step** on the exponent multisets. This single observation gives BOTH parts via one invariant + one monovariant.

### Distinct openings

1. **(PRIMARY — the invariant route, gives (a)+(b) together).** For each prime p, let E_p = multiset {v_p(a_i) : i=1..2026} (include zeros). The move on positions i,j replaces the pair (a,b) of p-exponents with (min(a,b), |a-b|). Since gcd(a,b)=gcd(min(a,b),|a-b|) (Euclid), the **gcd of the entire multiset E_p is preserved** call it g_p := gcd(E_p) = gcd of all p-exponents (zeros are neutral: gcd(x,0)=x). Invariant: g_p fixed by every move.
   - In a terminal state (at most one entry M>1, rest =1), the p-exponents are (v_p(M),0,…,0), whose gcd is v_p(M). So v_p(M)=g_p, i.e. **M = ∏_p p^{g_p}** (product over primes dividing ≥1 initial entry). This is forced, so M is choice-independent -> part (b).
   - Since initially some a_i>1, at least one prime p divides an entry, so g_p>=1 and M>=2. Hence the terminal state cannot be all-1's; combined with "no move possible => <2 entries >1" this gives **exactly one** entry >1 -> part (a). [Verified: see intuition notes.]

2. **(Monovariant for termination, supports route 1).** Let S = Σ_i Ω(a_i) (total prime factors with multiplicity), c = #{i : a_i>1}. Each move: Ω(m)+Ω(n) -> Ω(gcd)+Ω(lcm/gcd)=Ω(lcm)=Σ_p max(v_p m,v_p n). The drop is Σ_p min(v_p m,v_p n) = Ω(gcd(m,n)) >= 0, with equality iff gcd(m,n)=1.
   - If gcd(m,n)>1: S strictly decreases (by Ω(gcd)>=1), c may stay or drop.
   - If gcd(m,n)=1 (so {m,n}->{1,mn}): S unchanged, but c drops by 1 (two >1 entries merged into one product).
   - So the lexicographic pair (S, c) strictly decreases each move; both bounded below -> **termination**. (No cycling: a cycle would force every move gcd=1, but then c strictly decreases each step, impossible to cycle.) [Verified up to n=2026, ~5000 steps, always lands at c=1.]

3. **(Alternative framing of the same invariant — ideal-theoretic).** For each prime p, the ideal (g_p) ⊆ Z generated by the exponent multiset E_p is preserved (the move replaces two generators a,b by two generators of the same ideal). The terminal single generator is g_p. Same content as route 1, phrased as "the exponent ideal is the invariant"; useful if the outliner wants a clean conceptual wrapper.

4. **(Distinguishing route — not pursued, flagged for diversity).** A genuinely different framing: forget per-prime decomposition and instead track the *lattice of divisibility* generated by the board entries (the set of all gcds of sub-multisets). The move replaces {m,n} by {gcd, lcm/gcd}; one checks the generated gcd-submonoid is preserved. The terminal "M" is then the unique >1 element generating the same lattice. This is heavier and less direct than route 1; mention only as a rival framing if route 1 stalls (it shouldn't).

### Dead ends (do not retry) — false invariants
- **"gcd of all numbers on the board" is NOT invariant.** {4,8} -> gcd 4; after move {4,2} -> gcd 2. [Verified.] The move preserves the gcd of *exponents*, not the gcd of the numbers (= min of exponents).
- **"min of p-exponents" (= v_p(gcd of all numbers)) is NOT invariant.** {4,8}: exponents {2,3}, min=2; after move exponents {2,1}, min=1. [Verified.]
- **"prime-power level-set count" #{i : p^k | a_i} is NOT invariant.** {4,8}, k=2: count 2 -> after {4,2}: count 1. [Verified.] (Dispatch hypothesized this as a candidate; it fails.) The move does NOT preserve divisibility-level counts.
- These three are the natural-sounding traps. Only the **gcd of the exponent multiset** survives.

### Small-case / intuition notes (all CONJECTURES until proved, but verified numerically)
- Confirmed on boards {4,8},{12,18},{16,64},{2,3},{4,16,2},{12,18,6},{6,10,15},{8,8,8},{4,8,16}: in every case the invariant M = ∏ p^{gcd_i v_p(a_i)} (zeros neutral) equals the terminal single >1 entry, across 8 random play-outs each. E.g. {16,64} (exponents {4,6}, gcd=2) -> M=4=2^2 (NOT 16=2^4 — this is the case that cleanly distinguishes gcd-of-exponents from min-of-exponents / gcd-of-numbers). {2,3} (exponents {1,0} and {0,1}, gcds both 1) -> M=6.
- Termination stress: n=2026 random board in [2,100] terminates in ~5000 steps, always c=1, terminal M matches invariant.
- The invariant M is always >=2 (since all initial entries >1, some prime divides something), which is the exact fact that rules out the all-1's terminal state and yields part (a) for free from part (b)'s invariant.
