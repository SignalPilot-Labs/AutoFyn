## imo-2026-03
- Distinct openings:
  - **(A) Greedy-picking reduction (load-bearing lemma).** After all cuts, M ≤ 2n+1 pieces sorted descending p_1 ≥ p_2 ≥ … ≥ p_M. Greedy (take largest available) is optimal for BOTH players by an exchange/backward-induction argument; outcome: Liu (first) gets S = p_1 + p_3 + p_5 + … (odd ranks), Xiang gets even ranks. I could not find a spoiling deviation that beats greedy on any multiset tested (small cases all confirm). So the picking phase collapses to: c(n) = max_{Liu config} min_{Xiang splits} (odd-rank sum). **This is the one-step cheap kill that flattens the game to a combinatorial minimax — the outliner must prove it rigorously (it is the load-bearing lemma).**
  - **(B) Geometric-config lower bound (the real attack).** Liu's extremal config is GEOMETRIC, ratio 2: intervals {1, 2, 4, …, 2^n} / (2^{n+1}−1). This is NOT the equal-spaced config (equal spacing gives only ~1/2). Verified n=1,2,3: c(1)=2/3, c(2)=4/7, c(3)=8/15. Conjectured formula **c(n) = 2^n / (2^{n+1}−1)**. Xiang's best response to this config is to split the largest interval 2^n/D into two equal halves (each = 2^{n-1}/D = the second-largest Liu interval), and recurse; the value degrades to exactly 2^n/D.
  - **(C) Upper bound via a recursive Xiang strategy (the hard half).** Need: for ANY Liu config of n+1 intervals, Xiang has a strategy forcing Liu ≤ 2^n/(2^{n+1}−1). The n=1 case is a clean threshold: if Liu's smaller interval a ≤ 1/3, Xiang equal-splits the big interval (Liu = (1+a)/2 ≤ 2/3); if a ≥ 1/3, Xiang makes a sliver of the big interval (Liu = 1−a ≤ 2/3). General n needs a recursive argument combining halving and slivering; I have not found a clean universal strategy — this is the biggest gap.

- Dead ends (do not retry):
  - **Additivity / Jensen route is WRONG.** I initially assumed f(L) (value of a single Liu-interval after Xiang's best disruption) is a clean function and Liu's total = Σ f(L_i), enabling Jensen → equal intervals. This FAILS: Xiang's optimal response to a config depends on the WHOLE multiset (he either halves big intervals OR shreds small ones with multiple marks, depending on relative sizes), so f is not additive. Equal-spacing config (1/(n+1),…) gives Liu only ~1/2, far below the geometric optimum. Do not pursue equal-interval / Jensen / concavity framing.
  - **Naive "pairing" upper bound is wrong.** I first guessed Xiang pairs up pieces equally → c(n)=(n+1)/(2n+1). Disproven: at n=1 that gives 2/3 (right answer but wrong reason), but at n=2 the equal-final config (1/5,2/5,2/5) does NOT give 3/5 — Xiang instead SHREDS the small interval (1/5) with both marks, keeping the two 2/5's intact, so Liu gets only 0.5. The "pairing" intuition misses the shred-the-small tactic. True value c(2)=4/7≈0.571, not 3/5=0.6.

  - Key tactical subtlety (load-bearing for upper bound): Xiang has TWO distinct disruption modes — (i) HALVE a big interval (creates a pair Liu/Xiang split 50-50); (ii) SHRED a small interval with multiple marks (fills Liu's low odd-ranks with tiny pieces while big intervals stay intact). Mode (ii) is why equal/symmetric configs fail for Liu and why the geometric (rapidly-decreasing) config is needed: it starves Xiang of a small-enough interval to shred profitably.
