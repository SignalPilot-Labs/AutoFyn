### Distinct openings (each a different attack the outliner could build)
1. **Value-level minimax recursion (the unpicked lever).** Prove `V(n+1) = V(n)/(2+V(n))` where `V(n) = max_Liu min_Xiang A` (the alternating-sum game value), `V(0)=1`, so `V(n) = 1/(2^{n+1}−1) = α(n)`. The recursion is at the VALUE level (one mark to each player = one full round), NOT a per-Xiang-mark monovariant — consistent with the round-1 "per-round not per-mark" finding. The proof must characterize the extremal Liu config of order n+1 as "one dominant piece ++ the order-n extremal config (the dyadic) scaled," and show Xiang's optimal response reduces the residual to an order-n instance. Equality iff Liu plays the self-similar dyadic at every level.
2. **Disjunctive two-regime invariant (the cleanest framing).** Replace the fragile single inequality `A ≤ α(n)` by the disjunctive invariant: **EITHER** (R1) the config is "dyadic-regime" (a dominant piece present with the right ratios) and `A ≤ α(n)` is forced by the pair-pile/bisect strategy (equality only at the true dyadic), **OR** (R2) no piece dominates and Xiang forces `A ≤ 0 < α(n)`. The second clause is the *reserve buffer* that catches the parity-flip-on-tail transition (the −2T term that killed per-mark induction): in the non-dominant regime we do not need to drive A continuously down to α(n), we just need a separate strategy capping at 0. This is methodologically identical to crux **aimo-0340**'s disjunctive invariant.
3. **Majorization / Schur-convexity of the sorted-piece multiset.** Frame the cap as: among all Liu partitions refinable by ≤n Xiang marks, the function (min_Xiang A) is Schur-concave (or the negative is Schur-convex) in the sorted piece vector, so its maximum is at the most "spread" admissible config — which is the dyadic. The dyadic is the unique partition whose consecutive ratios are all 2, the extremal point of the majorization order. This is speculative but worth a quick check: does the cap decrease monotonically as the config moves away from dyadic under a Robin Hood (spread-reducing) transfer? My perturbation data (rightward perturb drops the cap) is consistent with this.
4. **Self-similar recursion via the dyadic-dominance identity.** The (n+1)-dyadic's largest piece `L = 2^{n+1}/D(n+1)` exceeds the rest's total by EXACTLY `α(n+1) = 1/D(n+1)`, and the rest (scaled to mass 1) IS the n-dyadic. So `α(n+1) = L − (1−L) = 2L − 1`. The proof target becomes: show that for any Liu config, `min_Xiang A ≤ 2L − 1` where L is the largest piece, with equality iff the rest (scaled) is itself the n-dyadic AND L is exactly twice the rest's largest. This is a **recursive structural characterization**, not a per-mark induction. CAVEAT (verified below): `2L−1` is NOT itself the cap for arbitrary configs — it is only the cap when the rest has the dyadic structure; for a generic dominant config like (0.2, 0.2, 0.6) the true cap (~0.005 in A-units) is far below `2L−1 = 0.2`. So `2L−1` is an upper bound on the cap, tight only at the dyadic; the recursion must compress the "rest" recursively.

### Candidate invariant + the inequality to prove (concrete skeleton for the outliner)
- **Define** `α(n) = 1/(2^{n+1}−1)`; note `α(n+1) = α(n)/(2+α(n))`, `α(0)=1`.
- **Target inequality (Lemma U*, the two-regime version).** For every Liu partition P of [0,1] into n+1 pieces, Xiang with ≤ n marks forces `A(final) ≤ α(n)`, with equality iff P is the dyadic config `(1,2,4,…,2^n)/D(n)` (up to the pieces Xiang cannot touch). 
- **Proof shape (two regimes, by induction on n).** Given P, let L = largest piece, R = the rest (a partition of mass 1−L).
  - *Regime D (dyadic / dominant):* if L ≥ (1+α(n))/2 · (1−L) (the rest is "small enough" relative to L — this is the regime where the dyadic-dominance holds), Xiang plays the pair-pile / bisect strategy on L: bisect L into (L/2, L/2) (one mark), reducing the residual to an n-mark game on `R ∪ {L/2, L/2}`; the two equal halves pair to excess 0, and the residual game is an n-instance whose value is `α(n)` by IH (in A-units, scaled). Total `A ≤ 0 + α(n)·(mass) = α(n)` after rescaling. The recursion `α(n+1) = α(n)/(2+α(n))` falls out of the rescaling `mass(R) = 1−L`, `mass({L/2,L/2}) = L`.
  - *Regime N (non-dominant):* if L < threshold, no piece dominates; Xiang has a separate strategy forcing `A ≤ 0` (Liu ≤ 1/2 < f(n) < f(n) for n≥1... note f(n)>1/2 so 1/2 < f(n) suffices). The n=1 "sliver mode" (round-1 Lemma U(1)) is the base case of this regime. The mechanism: with no dominant piece, Xiang can pair up pieces so that consecutive sorted pairs have non-positive excess (a Hall-type or greedy-pairing argument works HERE because non-dominance is exactly the condition the round-1 Hall route was missing).
  - *Equality:* equality in regime D forces the rest to itself be dyadic (by IH equality case) AND L to be exactly twice the rest's largest piece — recursively this pins P to the (n+1)-dyadic uniquely.
- **The hard step (flag for outliner, do NOT pretend it's easy):** the rescaling in regime D — "the residual game on `R ∪ {L/2, L/2}` is an n-instance with value α(n) scaled by the mass" — is exactly where the **interleaving obstruction** (round-1, Lemma L gap G1) and the **parity-flip-on-tail** (round-1, Lemma U gap) live. The disjunctive framing helps because regime N does not need the rescaling induction (it caps at 0 directly), so the induction only needs to close in regime D, where the dyadic self-similarity provides the clean half-scale. The outliner should plan to prove regime N first (it is the easier half: non-dominant → cap 0) and then close regime D using the dyadic self-similarity + IH.
