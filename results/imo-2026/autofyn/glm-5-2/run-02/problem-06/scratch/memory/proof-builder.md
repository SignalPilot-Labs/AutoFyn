# proof-builder role memory

ALWAYS: prove the "exhibit a bounded admissible candidate" lemma first for greedy-sequence problems — the next multiple of rad(a_1) above a_n is admissible (divisible by all primes of a_1, hence shares a prime with every term via the cheap anchor), giving a_{n+1}-a_n <= rad(a_1) in one line. This gap bound is reusable by every approach and is often the only genuinely provable monovariant-adjacent result (round 1, IMO 2026 P6).

ALWAYS: reduce the shared crux to a single cleanly-stated lemma and prove everything ELSE conditional on it — the reviewer values a precisely-localized gap over a vaguely-claimed proof. For IMO 2026 P6, "E finite" reduced to "every pair of terms shares a prime <= rad(a_1)" (Lemma 4), and the entire periodicity machinery (finite-state mod L_0, cyclic-permutation residue walk, telescoping lift, no-transient for all n) was provable conditional on that one lemma (round 1).

NEVER: assume "transient = 0" from numerics alone. The no-transient follows ONLY if the residue walk is a cyclic permutation (bijection) AND the machinery holds from n=1 — for IMO 2026 P6 this needed the crux to hold for ALL pairs (including future terms), so the back-direction uses the stabilized transversal set H_inf, not the stage-n H_n (round 1).

ALWAYS: verify the crux computationally before trusting the outliner's framing — for IMO 2026 P6 the conjecture "E ⊆ primes <= a_1" was checked true for a_1 in {15,35,77,105} over 600 terms, and the free-rider-co-occurrence mechanism (large prime always accompanied by a small essential prime; the "would-be-essential" candidate like 11095=5·7·317 is inadmissible) was observed concretely, which is what the missing proof must formalize (round 1).

NEVER: use the unproven free-rider irrelevance (greedy = next-V-residue) to conclude a specific number is a term — that is circular. I caught myself nearly doing this for 11095; only direct greedy generation confirmed it is NOT a term (round 1).

ALWAYS: When a corpus crux move is flagged as circular by the outline-reviewer, pin the circularity to an EXACT named sub-step before declaring the route dead — the reviewer wants the sub-step, not a vague "it's circular" (propagation-bezout round 2).
NEVER: Propose a "promotable lemma" that is just a corollary of an already-certified sibling lemma (Lemma 1) — the reviewer will reject it; mark it "subsumed, not promotable" honestly instead (propagation-bezout round 2).

ALWAYS: when an outliner flags a "growing-window" / "aggregate-vs-per-cell" ceiling, write the clean provable lemma (the part that IS sound) and certify it, then characterize the ceiling honestly with TWO named obstructions — the growing threshold and the per-cell gap. An honest partial with one certified lemma + a definitively-characterized ceiling tells next round's orchestrator the route is structurally blocked, not stalled, so it stops re-dispatching the dead route (grid-counting round 2).

NEVER: invoke PNT/Mertens/Siegel/Jacobsthal as a black box when the knowledge_base has no prime-sum entry — re-derive the light analytic input from scratch. For Sigma_p 1/p^2 < 1/2: Euler product for zeta(2)=pi^2/6 gives Sigma_{gcd(n,6)=1} 1/n^2 = pi^2/9; primes >=5 are coprime to 6; Archimedes pi<22/7 gives pi^2<10; result 389/900<1/2 in three lines, no calculus (grid-counting round 2).

NEVER: close a display-math block with a single "$" — it must be "$$". Caught and fixed in grid-counting round 2 (tags 3,5,6,7,8 all malformed as "$...$" closing "$$" blocks); always re-read raw markdown after writing math-heavy files.

ALWAYS: when a retrieved crux (e.g. aimo-0030) has a "Comment" stating that a second construction (the good-number greedy enumeration) IS the test problem's rule, port the crux via that auxiliary construction rather than the direct greedy-minimality port. The direct port (using greedy minimality as the "move") hits the transversal-enlargement wall; the indirect port through the auxiliary game furnishes the "move" (bad => exists good coprime predecessor) cleanly, because the move is a statement about the auxiliary structure, not about greedy minimality. This closed IMO 2026 P6 Lemma 4 (round 2): aimo-0030's Claim 5 (good numbers share a small prime <= k) transfers to P6 via the greedy characterization (P6 seq = good numbers with k=a_1), giving Lemma 4' (every pair shares prime <= a_1), which suffices for the periodicity machinery at the cruder threshold B=a_1. Bound is weaker (a_1 vs rad(a_1)) but finiteness is all the machinery needs.
NEVER: assume the crux bound must be rad(a_1) if the auxiliary construction gives a_1 — the periodicity machinery only needs a FIXED FINITE threshold set, so the cruder bound a_1 (from the game with k=a_1) is sufficient; rad(a_1) is tighter but unnecessary. Verify computationally that the cruder bound holds for non-squarefree a_1 (round 2, P6).
