## imo-2026-05

**Conjectured answer (strong evidence, not a proof):** `f(x) = x + c` for an arbitrary constant `c >= 0`. The family is verified to work (both inequalities reduce exactly to the standard QM≥AM≥GM chain on the pair `(x, y+c)`); the open work is the *uniqueness* direction.

- Distinct openings (this lens = QM-AM-GM equality / sandwich framing):
  1. **Diagonal collapse `x = f(y)`.** At `x = f(y)` the outer pair `(x, f(y))` is equal, so QM = AM = GM = `f(y)` and the chain collapses to `f(y) >= (f(f(y))+y)/2 >= f(y)`. Forces the **orbit recurrence** `f(f(y)) = 2 f(y) - y` for every `y>0`. (Verified: substitution is legitimate since `f(y)>0`.) Equality-case analysis of the *standard* QM≥AM≥GM chain gives nothing here on its own — the collapse is forced by the pair-equal equality case.
  2. **Orbit/displacement structure.** Let `D(y) := f(y) - y`. The recurrence rewrites as `D(f(y)) = D(y)` (displacement is constant on each forward orbit) and iterates form an arithmetic progression `f^n(y) = y + n·D(y)`. Positivity of all forward iterates forces `D(y) >= 0` (if `D(y)<0`, `y + n D(y) < 0` for large `n`, contradicting `f^n(y) ∈ R_{>0}`). So **f(y) >= y** everywhere, with `D=0` ⟺ `f(y)=y` (fixed point).
  3. **Recognize the solution family as "middle AM uses the same pair as outer QM/GM".** The middle term `(f(x)+y)/2 = AM(f(x), y)`; the outer QM and GM use `(x, f(y))`. These two pairs coincide (same sum) iff `f(x)-x = f(y)-y = const`, i.e. `f(y)=y+c`. For this family the whole chain *is* literally `QM≥AM≥GM` on `(x, y+c)`, and direct factorization shows both squared-difference inequalities equal `(x - y - c)^2/4 >= 0`. So **every `c >= 0` works** (verified symbolically for `c = 0, 0.5, 1, 2, 5`).
  4. **Master cross-constraint (the uniqueness engine).** Writing both squared inequalities `L := 2(x²+f(y)²) - (f(x)+y)² >= 0` and `R := (f(x)+y)² - 4x f(y) >= 0`, one finds the clean identities
     - `L + R = 2(x - f(y))²` (always ≥0; the standard QM-vs-GM gap), and
     - `L - R = 2 (D(y) - D(x)) · (x + f(y) + f(x) + y)`.
     Since the second factor is positive, the **sign** of `L - R` is the sign of `D(y) - D(x)`. Hence requiring *both* `L,R ≥ 0` is equivalent to the single master bound
     `(★)  (x - y - D(y))² >= |D(y) - D(x)| · (2x + 2y + D(x) + D(y))   for all x,y>0.`
     This is the load-bearing uniqueness inequality. It is automatic when `D(x)=D(y)` and when `x = f(y)` (diagonal); it bites only across points with different displacements.
  5. **Diophantine contradiction on two unequal orbits (closes the gap).** Suppose `D` is not constant: pick `a, b` with `d1 := D(a) < d2 := D(b)`. The forward orbits `a + n·d1` and `b + m·d2` (all carrying the same `d1`, `d2`) must satisfy `(★)` for every `n, m ≥ 0`. Plugging `x = a + n d1`, `y = b + m d2`:
     LHS `= (a - b + n d1 - (m+1) d2)²`, RHS `~ (d2 - d1)·(2n d1 + 2m d2) → ∞`.
     - If `d1 = 0 < d2`: a coarse bound (sum the two parabolas, `(★★) 2(x+y)(d2-d1) <= (d1+d2)(5d1-3d2)/4`) gives RHS<0<LHS — immediate contradiction. So `D≡0` somewhere forces `D≡0` everywhere (`f = id`).
     - If `0 < d1 < d2` and `d1/d2` **irrational**: `{n d1 - (m+1) d2 : n,m ≥ 0}` is dense in R, so for arbitrarily large `n, m` the LHS stays bounded (near `(a-b)²`) while RHS → ∞. Contradiction (verified numerically: violation `diff ≈ -9940` at `n=5999, m=4241` for `d1=1, d2=√2`).
     - If `d1/d2 = p/q` **rational** (lowest terms, `p<q`): take `n = kq, m = kp - 1` (valid since `p≥1`); then `n d1 - (m+1) d2 = 0` exactly, LHS `= (a-b)²` constant, RHS grows linearly in `k`. Contradiction for large `k` (verified: `diff` goes `−6.59, −12.59, …, −300.59` for `k=1..50`, `d1=1, d2=3/2`).
     Hence no two unequal displacements can coexist: **`D` is constant**, so `f(x) = x + c`.
