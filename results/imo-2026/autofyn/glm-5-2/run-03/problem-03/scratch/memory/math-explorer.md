# math-explorer per-role rules

ALWAYS: For "alternating draft" claim games, the greedy-claim lemma (both pick largest; first player = sum of odd-ranked items desc) is the linchpin — state it first and flag it must be proved from scratch; knowledge_base.md has NO entry for it (round 1).
ALWAYS: Verify a conjectured closed-form c(n) at n=1,2,3 with EXACT rational arithmetic (fractions module), not just float DE — float DE confirmed c(n)=2^n/(2^{n+1}-1) for imo-2026-03 but a wrong formula 2n/(2^{n+1}-1) also matched n=1,2 and only the universal bound S_odd>=1/2 caught the n=3 error (round 1).
ALWAYS: For minimax over continuous marks, use scipy differential_evolution with init='sobol' for the inner (responder) optimum; nested DE for both players is too slow (>2min), use a coarse grid for the outer player and DE for the inner (round 1).
NEVER: Trust a 2-data-point pattern as the answer — c(n)=2^n/(2^{n+1}-1) and the wrong 2n/(2^{n+1}-1) both fit n=1,2; the universal lower bound S_odd>=1/2 killed the wrong one only at n=3 (round 1).
ALWAYS: For minimax-over-continuous-strategies problems, run a numerical minimax (grid + Nelder-Mead for the responder, grid+refine or differential_evolution for the strategist) BEFORE guessing a formula — it caught the wrong `(n+1)/(2n+1)` guess and confirmed `2^n/(2^{n+1}-1)` for the Chu-Han war (round 1, imo-2026-03).
NEVER: Trust a coarse grid alone for the responder (Xiang) side — coarse Xiang overestimates Liu's guaranteed value. Use continuous Nelder-Mead with multiple seeds for the responder, and a pure grid only as a fast first pass (round 1, imo-2026-03).
ALWAYS: use a FINE grid (>=150 points) for the inner (adversary) minimization in minimax problems — coarse grids systematically overestimate the outer player's value because they miss the adversary's true best response (IMO 2026 P3 / imo-2026-03, round 1).
ALWAYS: when small-n values look like clean fractions, test "nice" rational candidate configs (sevenths, fifteenths, cumulative dyadic sums) directly against a fine adversary grid — this nailed c(2)=4/7 and c(3)=8/15 far more reliably than continuous optimization (round 1).
NEVER: trust scipy Nelder-Mead / differential_evolution as the sole solver for a piecewise-linear minimax — it gets stuck in local optima; cross-check with exhaustive fine-grid search before reporting a value (round 1: DE reported c(2)=0.5795 vs true 4/7=0.5714).

ALWAYS: For the Chu-Han war splits-inequality (G1), use the parity-integral `D = ∫[j(t) odd] dt` with the FULL add/subtract decomposition — a split of piece `p` into `α+(p−α)` adds `+1` to `j(t)` on `[0, α]` AND subtracts `−1` on `[p−α, p]` (not just `+1` on `[0,α]`; the naive read gives wrong `j` profiles) (round 2, G1-lower route).
ALWAYS: For G1-general, the convexity-of-order-statistics route beats the naive sorted-order dyadic-induction: `S_odd = a_1+a_3+…` is CONVEX in the multiset (k-th largest = max of linear forms), so a local-min check at equal-halving lifts to global via convexity, sidestepping the interleaving/rank-shift obstacle (round 2, G1-lower route).
NEVER: Use the naive sorted-order dyadic-induction for G1 — descendants of the split largest piece interleave with the rest in the sorted order, so global `D ≠ D_small + D_large`; the `j(t)`-additivity picture defeats this (round 2, confirmed dead end).
ALWAYS: Verify the n=2 two-mark G1 sub-case by finite rational casework before generalizing — the equality family there (split largest into the (n−1)-dyadic tower + extra 1) generalizes the minimizer structure to all n (round 2).

ALWAYS: when probing an upper-bound minimax for a stick-division game, search for the WORST Liu config over random samples AND test the conjectured lower-bound witness (dyadic) — the witness should be the unique worst (round 2: confirmed for imo-2026-03 n=2; dyadic gives exactly 1/D_n, worst random was 0.139 < 1/7).
NEVER: use a single distribution-over-Xiang-marks (Yao averaging) as an upper-bound certificate for this problem — uniform gives E[D] 0.56 for n=1 worst Liu config, way above 1/3; the value is Liu-dependent, so a single σ for all Liu fails (round 2).
NEVER: pursue measure/parity-integral control as the UPPER-bound route — it hits the same factor-of-2 wall as the alternating-potential D-monovariant (each cut flips parity on an interval ≤ p/2; total reduction ≤ 1/2) (round 2).
NEVER: expect the recursion 1/c(n)=1/c(n−1)+2^{-n} to close a peeling induction on n — one Xiang mark splits a piece (n+1 → n+2 pieces), so the piece count does not decrease and the induction does not close (round 2, re-confirming dyadic-induction G2 wall).
ALWAYS: when a field risks collapsing to pairing, scout "min over a finite explicit-strategy family" framings where pairing is ONE member and barely-split strategies are the others — for imo-2026-03 n=2 dyadic, the barely-split p_2 + equal-halve p_1 strategy also attains 1/7 (genuinely different from pairing) (round 2).

ALWAYS: For the Chu-Han upper bound (G2), use the parity-integral XOR framework: D = ∫[j(t) odd] dt, and a split of piece p into u≥v toggles parity on [0,v) ∪ [u,p) (two intervals of length v each). This gives clean formulas (equal-split toggles [0,p); barely-split toggles ≈∅; equal-split all but two pieces p_a,p_b gives D_final = |p_a − p_b| EXACTLY) that bypass the sorted-order interleaving mess (round 2, imo-2026-03).
ALWAYS: The peeling lemma (split p_1 → p_j + (p_1−p_j) for ANY j, creating pair (p_j,p_j)) gives D_final = D_rest EXACTLY, UNCONDITIONALLY (no p_1 ≥ 2 p_j condition needed — the parity argument: the pair contributes +2 to j on [0,p_j), which is even, parity-neutral). Verified on 9 configs. This is the one place D is genuinely additive; the natural inductive engine. BUT the naive worst-case inductive bound (1−2p_j)/D_{n-1} is LOOSE for n≥3 (dyadic n=3 gives D_rest=1/3 vs target 1/15) — need a strengthened hypothesis capturing the rest's structure (round 2, imo-2026-03).
NEVER: close n≥3 upper bound with a fixed menu of 1–2-mark strategies — VERIFIED insufficient for n=3 (worst 0.099 > 1/15). The menu {A: D=p_{n+1}, B′: D=|2p_1−1|, C: D=|p_a−p_b|} suffices ONLY for n=2 (tight at dyadic). For n≥3 need full n-mark adaptive refinement or a unified amortized potential (round 2, imo-2026-03).
NEVER: assume peeling-smallest realizes the recursion 1/c(n)=1/c(n−1)+1/2^n for n≥3 — it gives D_final=D_rest exactly but the rest is NOT worst-case; the inductive bound is loose at dyadic (round 2, imo-2026-03).
ALWAYS: verify an upper-bound strategy is TIGHT at the dyadic config (1,2,…,2^n)/D_n (D must equal 1/D_n exactly, no slack) — the dyadic config is the unique maximizer of Xiang's best D (strong numerics n=2). A construction loose at dyadic is dead (round 2, imo-2026-03).

ALWAYS: Verify arithmetic identities (e.g. 1/g_n = Σ 2^{-k}) by exact Fraction computation for n=1..5 before citing — the dyadic tower telescoping is arithmetic, not structural, and conflating the two causes mis-attraction (round 4, telescoping-potential lens).
NEVER: Propose a LINEAR amortized potential Φ = α·D + β·(leftover) for imo-2026-03 — the factor-of-2 wall is arithmetic (geometric ratio 1/2 sums to 2), confirmed dead in alternating-potential round 2; only pair-cancellation (categorical, not geometric) supplies the missing factor 2 (round 4).
ALWAYS: When scouting a "nonlinear telescoping potential" lens, check whether the candidate collapses into the pairing framework — the factor-of-2 saving necessarily exploits pair-cancellation, which is pairing-charging's defining bet (round 4).
