ALWAYS: for geometry problems, run a numerical solver (scipy least_squares with method='trf' + bounds, many random restarts) to actually exhibit a configuration before reasoning about it — unsigned-angle ∠ equations are 4-dof/3-eq giving a 1-parameter family; random sampling rarely lands near a solution without bounded least_squares (round 1, imo-2026-02).
NEVER: claim "the angle conditions make two triangles similar" without computing the full angle tables numerically first — the three ∠-equalities in IMO 2026 P2 each give ONE angle pair only, so AA similarity fails for every candidate pair (BMK, LNC, LCK, LBK, ABK, ACL). Verify before recommending (round 1, imo-2026-02).
ALWAYS: check the isoceles/symmetric degenerate case of a geometry problem first — it reveals the hidden symmetry the general proof must generalize, and it is a free sanity check on the conclusion (round 1, imo-2026-02).
NEVER: assume the crux corpus has geometry entries — crux_moves_documentation.md states the corpus covers only number_theory, combinatorics, algebra; do not report a (nonexistent) geometry crux match (round 1).
ALWAYS: when a spiral similarity / homothety seems to transfer an angle picture between two vertices, verify the DIRECTED side (which side of the reference ray the image lands on) before committing — equal unsigned angles can put the image on the reflection of the target ray across the reference line, not the target ray itself (round 1, imo-2026-02: the A-centered spiral sim B→C, M→N sent line BK to the reflection of CL across CA, so K' missed line CL and the approach died).
ALWAYS: For circumcenter-of-triangle-with-one-vertex-at-origin, the linear system is [[2Kx,2Ky],[2Lx,2Ly]]·[Ox,Oy]=[|K|^2,|L|^2] — ROWS are the two vertices, not columns. Transposing silently produces a wrong O that still looks "solved"; verify |OK|=|OL|=|OA| before trusting reductions (round 1, imo-2026-02).
NEVER: encode undirected angle-equality as "oriented cross/dot tangent equality" (cross·dot − cross·dot = 0) — it captures the larger variety with α=β+π branches, giving a nonzero (wrong) Groebner remainder. Use a parametric angle construction (rays built from α,β,γ via tangent) that bakes in orientation, or use squared tangents (round 1, imo-2026-02).
