# Lemma (negative): syndetic + divisibility-closed $\not\Rightarrow$ periodic

**Statement (negative).** The set
$$B\;=\;6\mathbb Z\;\cup\;\bigcup_{\substack{p\equiv1\pmod4\\p\text{ prime}}}p\mathbb Z\;\subseteq\;\mathbb Z_{>0}$$
is (a) divisibility-closed (under taking positive multiples: $m\in B$, $m\mid n\Rightarrow n\in B$), (b) syndetic (bounded gaps $\le6$), and (c) **aperiodic** (not $L$-periodic for any finite $L\ge1$). Consequently, any proof that $\mathcal B_\infty$ is periodic MUST use a **greedy-specific dynamic property** beyond pure statics (divisibility-closure + syndeticity).

**Proof.** (a) Each summand ($6\mathbb Z$ and each $p\mathbb Z$) is closed under taking positive multiples; a union of multiples-closed sets is multiples-closed.
(b) $B\supseteq6\mathbb Z$, so every 6th positive integer lies in $B$; gaps $\le6$.
(c) Suppose (for contradiction) $B$ is $L$-periodic for some $L\ge1$: $m\in B\iff m+L\in B$ for all $m\ge1$.

**Step 1: $6\mid L$.** $B\supseteq6\mathbb Z$ (residue class $0\bmod6$). By $L$-periodicity, the residue class $L\bmod6$ is also $\subseteq B$ (each $6k\in B\Rightarrow6k+L\in B$, and $\{6k+L:k\ge0\}$ is exactly the class $L\bmod6$). But among the six residue classes mod $6$, **only** $0\bmod6$ is $\subseteq B$: classes $1,2,3,4,5\bmod6$ contain respectively $1,2,3,4,5$ (and $5\bmod6$ contains $11$), each of which is $\notin B$ ($1$ has no prime factors; $2,3$ are primes $\not\equiv1\bmod4$ and coprime to $6$; $4=2^2$ has no factor $\equiv1\bmod4$ and is $\notin6\mathbb Z$; $5\equiv1\bmod4$ so $5\in B$, but $11\equiv3\bmod4$ is prime with $\gcd(11,6)=1$, so $11\notin B$ — witness for class $5\bmod6$). Hence $L\equiv0\bmod6$, i.e. $6\mid L$.

**Step 2: $p\mid L$ for every prime $p\equiv1\bmod4$.** Fix such $p$. $B\supseteq p\mathbb Z$ (residue class $0\bmod p$). By $L$-periodicity, the residue class $L\bmod p$ is $\subseteq B$. We claim **only** $0\bmod p$ is $\subseteq B$: for each $r\in\{1,\dots,p-1\}$, the class $r\bmod p$ contains a prime $q\equiv3\bmod4$ with $\gcd(q,6p)=1$, hence $q\notin B$. Existence: by CRT, the system $q\equiv3\bmod4$, $q\equiv r\bmod p$, $q\equiv1\bmod3$ (choosing a nonzero residue mod $3$; possible since $\gcd(3,4p)=1$) is solvable modulo $12p$; the solution class is coprime to $2,3,p$, so by **Dirichlet's theorem on primes in an arithmetic progression**, infinitely many such primes $q$ exist. Each satisfies $q\not\equiv0\bmod6$ (coprime to $6$) and $q$ prime $\equiv3\bmod4$ (so $q\notin p'\mathbb Z$ for any prime $p'\equiv1\bmod4$, since $q\ne p'$), hence $q\notin B$. So class $r\bmod p\not\subseteq B$ for $r\ne0$; hence $L\equiv0\bmod p$.

**Step 3: contradiction.** By Steps 1–2, $L$ is divisible by $6$ and by every prime $p\equiv1\bmod4$. There are **infinitely many** primes $p\equiv1\bmod4$ (Dirichlet). A finite positive integer cannot be divisible by infinitely many distinct primes. Contradiction. $\square$

**Consequence.** Any viable proof of $\mathcal B_\infty$'s periodicity MUST exploit a **greedy-specific dynamic** property (e.g. the cyclic-successor generation order, or a bounded non-residue statistic) — NOT pure static structure (divisibility-closure + syndeticity), which the counterexample $B$ possesses aperiodically. This fences off all future "$\mathcal B_\infty$ has bounded gaps $\Rightarrow$ periodic" attempts and sharpens the target for finite-automaton / structural-induction / increment-pattern framings: they must identify a greedy-dynamic property the counterexample lacks.

**Status.** Reviewer-certified (round 3) as a **negative lemma**. The aperiodicity proof is rigorous (Dirichlet on primes in AP, applied to force $L$ divisible by infinitely many primes).
