Lens: ABANDON B_∞/MT/transversal. Work ONLY with (a_n) and (d_n). Greedy rule: a_{n+1}=smallest m>a_n with gcd(m,a_i)>1 ∀i≤n. Gap bound d_n≤M_1 (certified) ⇒ finite alphabet {1,…,M_1}. I scouted computationally (fast greedy with maximal/minimal-support tracking, period detection, window-determinism tests) on a_1∈{15,35,65,77,91,143,175,221,385,847,1309,2085}. ## Distinct openings (each a different attack the outliner could build from the increment-only view)

1. **Minimal-support stabilization in the PRIMAL (not dual/MT).** The live constraints at step n are the inclusion-MINIMAL term-supports of {S(a_i):i≤n} (a support S is redundant once a subset S'⊆S exists, since constraint_{S'}=∪_{p∈S'}pZ ⊆ ∪_{p∈S}pZ=constraint_S, so S is implied). B_n = ∩_{S minimal} ∪_{p∈S} pZ. The increment word IS the cyclic structure of B_∞ mod L. **Empirical headline:** the minimal-support set is TINY (3–7 supports across 9 tested a_1) and ALL primes entering it are ≤ M_1=rad(a_1) (0 failures; a_1=385: 7 supports, primes {2,3,5,7,11,19}⊆385; a_1=847: 5 supports, primes {2,3,7,11,41}⊆77; a_1=2085: 5 supports, primes {2,3,5,11,19}⊆2085). This is the live conjecture q≤M_1 RE-CONFIRMED in the primal. **BUT stabilization ⟺ Gap A** (forward: finite minimal set using primes G ⇒ B_∞ = ∩∪pZ is (∏G)-periodic; backward: L-periodic B_∞ ⇒ finitely many minimal supports with bounded primes). So the primal framing is a RE-LABELING of Gap A, not a bypass. The cofactor-circularity wall re-appears at "prove no prime >M_1 ever enters a minimal support."

2. **Increment-window finite automaton (the route's flagship hope).** Prove ∃ W, bounded by a function of M_1 (NOT of the period T), such that (d_{n-W+1},…,d_n) determines d_{n+1} for all n ⇒ finite state space M_1^W ⇒ eventually periodic ⇒ pure-from-start upgrades to periodic-from-start. **TESTED AND REFUTED on a_1=385 (T=5088):** minimal functional window W≈100 (W≤40 has 121–3786 conflicts; W=100 first gives 0 conflicts), and #distinct windows at W=100 is 4987 ≈ T=5088. The state size needed is ~T, NOT a function of M_1. The increment word is NOT generated by any small finite automaton; determining the next increment requires knowing the position within the cycle (size T), which is exactly what we want to bound. **This sub-route is dead.**

3. **Pure-from-start blocks the transient-shrinking induction template.** The certified `greedy-equals-cyclic-successor` lemma means the greedy enumerates B_∞ from n=1; there is NO pre-period. Verified directly on a_1=385: the d-word is periodic from index 0 (tail-run 6911 > T=5088 positions, all matching d[k]=d[k+5088] for k=0..6911). So the sequence is periodic-from-start OR aperiodic-forever — no middle ground. Any induction that works by shrinking a transient pre-period is VACUOUS. This kills the "induct on pre-period complexity / defect" template (the `aimo-0134` cumulative-defect C_n route was already dead via `aimo-0134-obstruction`; this is a second, independent reason).

4. **Coin/Frobenius angle on the increment value set.** Hypothesis: increment values are built only from governing primes (so the Frobenius/coin structure of the increment set isolates the governing set). **REFUTED on a_1=77:** governing primes = {2,7,11} (L=154=2·7·11), but increments include 6=2·3 and 10=2·5, introducing non-governing primes 3,5. Increment values do NOT factor over the governing set. Frobenius/coin arguments on the increment set do not isolate governing primes.

## Cheap-kill candidates

- **"Minimal supports form a pairwise-intersecting antichain ⇒ bounded size by Erdős–Ko–Rado"** — NO. Intersecting antichains can be large (all k-subsets containing a fixed element: size C(n−1,k−1)). EKR bounds INTERSECTING FAMILIES of fixed size k, not antichains of unrestricted size; and it bounds the COUNT, not the PRIMES — so even if it worked it would not close Gap A. Not a cheap kill.
- **Pure-from-start lemma (already certified)** is the one genuine cheap structural fact: it upgrades "eventual" to "from-start" for free, eliminating the transient. Already exploited.
- No v_p / parity / multiplicity kill is visible in the increment word.

## Sharpest sub-problem for a builder

**"Prove the inclusion-minimal term-supports of {S(a_i):i≥1} stabilize to a finite antichain whose primes are all ≤ M_1=rad(a_1), using ONLY the greedy rule (smallest admissible) — NOT the cofactor bound (which is circular)."** This is Gap A in the primal. The concrete entry point: when the greedy introduces a new minimal support ms (because ms is incomparable to all current minimals), analyze the greedy-minimality of the term a_{n+1} carrying ms — the term is the SMALLEST m>a_n hitting every current minimal, so ms's primes are forced by "smallest." The hope: greedy-minimality forces every prime in ms to be ≤ M_1 (the cofactor of the smallest admissible multiple is small). **Skeptical note:** this is almost certainly still the cofactor wall — the "incomparable" condition is precisely where a new prime q>M_1 would enter, and bounding that prime's cofactor IS the circular step certified dead for `witness-density-recurrence` (round 2) and `crt-period-lifting` (round 3).
