## imo-2026-06 (route: cyclic-successor map as a SUBSTITUTION / MORPHISM on the increment sequence (d_n))

## Headline verdict on THIS route

**DEAD — equivalent to Gap A restated in word-combinatorial language.** The substitution/morphism framing cannot close Gap A non-circularly, for three independent reasons established computationally below: (i) "is (d_n) the fixed point of a finite substitution" is *circular* — every periodic word is trivially morphic (σ: w→ww, or the identity), so morphicity presupposes the periodicity it is asked to prove; (ii) morphic ≠ periodic (Thue-Morse, Fibonacci word are fixed points of finite substitutions and aperiodic), so morphicity alone is insufficient — the only general word-combinatorial ⇒ periodic theorem is Morse-Hedlund, whose threshold n is EXACTLY T in every tested case (no independent foothold); (iii) the natural "greedy-derived substitution" (the window-state transition σ_n→σ_{n+1}) is NOT finitely determined — it leaks the free-rider primes of a_{n+1}, which IS Gap A (round-3 finite-statistic explorer, re-confirmed). The route does surface one new negative structural fact (period words are primitive, not powers of smaller words; no letter-permutation invariance; palindrome property is non-universal) and confirms the syndetic-guardrail gap is real. It does NOT escape the cofactor-circularity wall that killed rounds 1–3.

## Distinct openings (the angles I surfaced)

1. **(d_n) as fixed point of a finite letter-substitution σ on {1,…,M_1}^*.** Testable question: is the (eventual-)period word w = d_1…d_T a fixed point w = σ(w) of a substitution σ mapping each letter to a word, with σ NOT the identity? I checked all 10 resolved cases (a1 ∈ {15,35,65,77,91,105,143,1001,1309,2085}, T ∈ {8,34,58,18,20,58,64,282,912,1372}): in EVERY case the primitive period |u| equals T (the period is NOT a power of a smaller word), and NO nontrivial letter-permutation (length-1 substitution) fixes w. For a uniform length-k substitution to have a fixed point of period T, one needs k·T = T ⇒ k = 1; so the only uniform substitution with a periodic fixed point is a letter permutation, and (d_n) admits none. Conclusion: there is no nontrivial substitution-of-finite-order generating (d_n); the "substitution is primitive/finite-order ⇒ periodic" lever (Cobham–Lothaire characterization of periodic morphic words) has no purchase here.

2. **Greedy rule as a deterministic LOCAL REWRITING / finite-state transducer on the recent increment window.** This is the dispatch's question 2, and it is the same object the round-3 finite-statistic explorer already scouted under "Markov window-state." Re-confirming crisply: define σ_n ∈ {0,1}^{M_1} by σ_n(k)=1 iff a_n+k is admissible at step n. Then d_n = min{k: σ_n(k)=1}, the state space is finite (≤ 2^{M_1}), and the transition σ_n → σ_{n+1} = (shift right by d_n) + (impose new constraint from a_{n+1}). The P_1-part of the new constraint IS determined by (a_n mod M_1, σ_n) (since p | a_{n+1} ⇔ a_{n+1} ≡ 0 mod p for p ∈ P_1). The NON-P_1 part — which free-rider primes divide a_{n+1} — is NOT determined by σ_n or by a_n mod M_1 (verified: a1=385 has 89 conflicts on a_n mod 385 for d_n; minimal functional modulus = L = 43890 itself). So d_n is NOT a function of any bounded d-window + any P_1-finite state. Plugging the leak = bounding the active free-rider primes = Gap A. The transition is a "substitution" only with an unbounded (free-rider) state component.

3. **Morse-Hedlund (the ONE general word-combinatorial ⇒ periodic theorem).** Morse-Hedlund: a one-sided infinite word is ultimately periodic iff its subword complexity p(n) (number of distinct length-n factors) is bounded; equivalently iff p(n) ≤ n for SOME n. I computed p(n) for the resolved cases and located the first n with p(n) ≤ n: in EVERY case it is EXACTLY n = T (a1=15 T=8: first n=8; a1=35 T=34: n=34; a1=77 T=18: n=18; a1=91 T=20: n=20; a1=105 T=58: n≈58; a1=143 T=64: n≈64). This is a THEOREM-level fact, not coincidence: for a primitive periodic word of period T, p(n) = T for all n ≥ T−1 and p(n) > n for all n < T (the word is primitive). So MH gives back the period, never a shortcut. To USE MH non-circularly one would need an INDEPENDENT bound p(n) ≤ n for some n ≪ T derived from greedy structure; the data says no such n exists, and the greedy rule supplies no complexity bound below T. Circular.

4. **Block / run structure of the period word (does the greedy define a "block substitution" via active minimal transversals?).** The increments come in runs during which a single minimal transversal T is the active connector (the cyclic successor steps within one rad(T)Z-coset); crossing a coset boundary switches the active transversal. IF the sequence of active-transversal switches were generated by a substitution on a FINITE set of transversals, periodicity would be combinatorial. But the set of active transversals IS the set of minimal transversals of F_∞, whose finiteness IS Gap A (the binfinity-divisibility-progression-structure lemma gives the representation B_∞ = ∪_{T∈MT(F_∞)} rad(T)Z unconditionally, but periodicity requires the union to be finite = Gap A). So this "block substitution" is again conditional on Gap A; it is literally the cyclic-successor-bijection endgame in disguise.

5. **Palindromic / reflection symmetry of the period word (a candidate greedy-dynamic invariant).** Striking empirical finding: in SOME cases the period word w is a perfect palindrome (a1 ∈ {15, 77, 91, 105, 1001}: w = reverse(w)); in OTHERS it is not (a1 ∈ {35, 65, 143, 1309, 2085, 385}: not palindromic, no anti-palindrome w[i]+w[T−1−i]=const either). The palindrome cases are exactly those where A = B_∞ mod L is symmetric under negation (r ∈ A ⇔ −r ∈ A). Since B_∞ = ∪ rad(T)Z is unconditionally closed under negation (each rad(T)Z is), IF B_∞ is L-periodic then A is symmetric, hence w is palindromic. So the palindrome is a CONSEQUENCE of Gap A (conditional on L-periodicity), not an independent greedy invariant — and it is not even universal (asymmetry of the realized A breaks it in the non-palindrome cases). No proof lever here.

## Candidate technique(s)

- **Morse-Hedlund theorem** (subword complexity bounded ⇔ ultimately periodic) — the only general "word-combinatorial property ⇒ periodicity" theorem. Circumvented by the data (threshold n = T). Listed for completeness; the outliner should NOT expect it to close Gap A.
- **Cobham–Lothaire characterization of periodic morphic words** (a fixed point of a substitution is ultimately periodic iff the substitution is of finite order / a letter permutation on its image) — the property (d_n) provably does NOT satisfy (no letter-permutation invariance, primitive period). So the "morphic ⇒ periodic" direction is doubly blocked: morphic ≠ periodic in general, and our word is not of the periodic morphic subtype.
- **Finite-state transducer / pigeonhole on a window-state** — the natural greedy-derived candidate; killed by the free-rider leak (round-3, re-confirmed).

None of these is a live candidate technique for CLOSING Gap A; they are reported so the outliner does not re-open them.

## Cheap-kill candidates

- **Alphabet-size pigeonhole**: d_n ∈ {1,…,M_1} (finite alphabet) ⇒ SOME letter repeats infinitely often. Trivially true but useless — repeating a letter does not force periodicity (any aperiodic word over a finite alphabet repeats letters). Not a kill.
- **Bounded subword complexity from the gap bound alone**: p(n) ≤ M_1^n (trivial) is ≫ n for all n of interest; no kill. The only useful bound (p(n) ≤ n) requires n = T.
- **Injection of the realized window-state set into a finite set of size < T**: the realized set has size EXACTLY T empirically (round-3), so no proper sub-bound is available.
- None obvious as a kill.

## Dead ends (do not retry — route-specific)

- **Do NOT argue "(d_n) is morphic ⇒ periodic."** Morphic ≠ periodic (Thue-Morse, Fibonacci). The Cobham-Lothaire periodic-morphic characterization requires the substitution to be of finite order / a letter permutation on its image; the increment word provably admits no letter-permutation invariance (tested 10 cases) and is a primitive word (not a power). So even a successful morphicity proof would not yield periodicity.
- **Do NOT argue "any periodic word is trivially morphic, so exhibit the morphism."** That is circular: constructing the trivial morphism σ: w→ww requires already knowing the period w.
- **Do NOT retry the Markov window-state pigeonhole as a "substitution."** The transition σ_n → σ_{n+1} leaks free-rider primes (round-3, re-confirmed: 89 conflicts on a_n mod 385 for d_n; minimal functional modulus = L). This is Gap A in transducer clothing. (The round-3 outline-reviewer already CUT `increment-pigeonhole-window` as "Gap-A-restated, not built" — that ruling holds.)
- **Do NOT cite the palindrome property as a greedy invariant.** It holds in only ~half the cases (15, 77, 91, 105, 1001 yes; 35, 65, 143, 1309, 2085, 385 no) and is a CONSEQUENCE of B_∞ being L-periodic + closed under negation (each rad(T)Z is), not an independent route to it.
- **Do NOT retry Morse-Hedlund with a small-n complexity bound.** The threshold n where p(n) ≤ n is provably T (primitive-period theorem + data); no sub-T bound is available from the greedy rule.

## Verdict

**DEAD.** The substitution/morphism route cannot escape the cofactor-circularity wall. The framing founders on three independent obstructions, each certified by computation: (i) morphicity is circular (every periodic word is trivially morphic; constructing the morphism requires the period); (ii) morphic ≠ periodic and our word is provably NOT of the periodic-morphic subtype (no letter-permutation invariance, primitive period); (iii) the only general word-combinatorial ⇒ periodic theorem (Morse-Hedlund) has its threshold n equal to T in every tested case, giving back the period rather than an independent bound. The natural greedy-derived "substitution" (the window-state transducer) leaks free-rider primes at the one load-bearing step, which IS Gap A — re-confirming the round-3 finite-statistic finding. No crux in the corpus ports. The genuinely-promising-but-conditional sub-problem a builder would need to crack — and the sharpest one this route can pose — is:

> **Exhibit, from the greedy rule + d_n ≤ M_1 ALONE (no B_∞, no MT, no assumed L), an integer n with subword complexity p(n) ≤ n, where n is bounded by a function of M_1 INDEPENDENT of T.**

This is Morse-Hedlund made concrete. The data says the threshold n is T, so the sub-problem is to find an INDEPENDENT complexity bound below T — which is precisely the wall, in word-combinatorial language. A builder who cannot produce such an n has no substitution/morphism proof; the route should be set aside in favor of a framing that attacks the q ≤ M_1 governing-prime bound from a genuinely different (non-word-combinatorial) direction.
