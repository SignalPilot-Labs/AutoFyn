## Per-slug verdicts

### `transversal-saturation` — APPROVE
The canonical route. Sound endgame: once $\mathcal B_\infty$ exists, the cyclic-successor map on $A=\mathcal B_\infty\bmod L$ is the inverse of cyclic predecessor, hence a bijection, so every orbit is a cycle with no tail — elementary and correct. Gap A (finiteness of transversal primes) is the crux, honestly flagged with a candidate mechanism (each non-redundant insertion strictly shrinks the avoid-a-$P_1$-prime sub-antichain; finitely many such sub-antichains). The mechanism is the most concrete of the four candidates for wall (1). Gap B (pure-from-start) is the second hard step, with two candidate mechanisms (backward extension via predecessor-uniqueness; or the "looser-only-above-$a_n+M_1$" argument). Whole attempt, sound skeleton, gaps flagged with mechanisms. **Build this round.**

### `prime-power-dichotomy` — CHANGES REQUESTED
The dichotomy is exhaustive (either some term is a prime power, or none is), and the LOCK branch is genuinely certified: $a_i=p^k\Rightarrow$ every later term is a $p$-multiple $\Rightarrow a_{n+1}=a_n+p$, so $T=1,L=p$. That is a real, certified partial. **However the NO-LOCK branch's load-bearing mechanism is broken.** Gap C proposes "every $P_1$-prime recurs (else lock)" — the "else lock" justification is INVALID: a $P_1$-prime $p$ can drop out (future terms avoid $p$ but still hit $a_1$ via other $P_1$-primes, with supports of size $\ge2$, forcing no singleton and hence no lock — true even for $|P_1|=2$, since future terms can be $p'\cdot q$ with $q\notin P_1$). I confirmed computationally that the *lemma* "every $P_1$-prime recurs" does hold on $\{15,35,77,105,143\}$ (each $P_1$-prime divides a term among the last 50 of 400 terms), so the lemma may be true — but it needs a genuinely different proof. **Required fix for the builder:** either find a valid mechanism for "every $P_1$-prime recurs" / Gap C that uses the size-$\ge2$ hypothesis non-trivially, OR prove the no-lock branch yields a sharper bound than `transversal-saturation`'s Gap A — else this collapses into `transversal-saturation` with an unnecessary split. The lock-branch lemma itself is worth certifying into `lemmas/` regardless. **Build this round** (lock branch is near-term closable; no-lock mechanism to re-derive).

### `growing-modulus-descent` — CHANGES REQUESTED
Sound high-level framing (construct $L$ inductively, prove termination by typed descent), and the "witness type" classification is a genuinely finite object (subsets of $2^{P_1}$). But the load-bearing rank $r(q)$ in Gap D is NOT concretely defined — the outliner itself flags "a vague descent is the failure mode," yet leaves $r(q)$ unspecified. Without a concrete strictly-decreasing integer rank, the descent is a wish. Additionally, Gap D is a rival PROOF of the same finiteness fact as `transversal-saturation`'s Gap A (pulled-in primes ARE primes entering minimal transversals), and Gap E is essentially Gap B restated (the outliner concedes this). **Required fixes:** (a) define $r(q)$ concretely and prove it strictly decreases within a fixed type; (b) differentiate from the antichain route — show the typed-descent survives independently if antichain-shrink stumbles. Not built this round (the rank-definition problem is open-ended, not a near-term closable gap); kept in the population for a later round.

### `free-rider-type-replacement` — CHANGES REQUESTED
Most distinct framing (type-competition among free-riders, localized to per-type slots). The type $\tau(q)=(A,B)\subseteq 2^{P_1}\times2^{P_1}$ is finite and well-defined. But Gap F (same-type replacement) is the crux and the outliner itself flags it "may be FALSE — same-type primes might coexist without replacement." The candidate mechanism ("later dominates earlier in every minimal transversal") is not obviously valid: a transversal using the larger prime $q_2$ has larger $\operatorname{rad}$, hence a *sparser* AP, which is not "domination" in the hitting-set sense. **Required fix:** the builder MUST first verify Gap F computationally on $a_1=385$ free-rider data (does same-type replacement actually occur in the computed sequence?) before pursuing the spine. If it holds, this is a strong, genuinely different route. If it fails, the approach dies fast and cheaply — a good use of a round. Gap G's descent must be on a finite coverage set, not the unbounded witnessing value (flagged). **Build this round** specifically because the near-term signal (computational test of Gap F) is fast and decisive.
