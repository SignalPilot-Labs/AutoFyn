## The 6 most-portable cruxes

### 1. `aimo-0514` (USAMO 2021 P2, combinatorics/processes-and-algorithms + invariants-and-monovariants) — **bijection-on-finite-state ⇒ purely periodic** [STRONGEST FRAMING]
- **Crux move (one sentence).** Augment each state of a deterministic rule-based walk with the local bit the rule reads next, so the one-step map has a *unique successor AND a unique predecessor*; a bijection on a finite state set forces every trajectory to be a single totally-periodic orbit (each state recurs at most once per period).
- **Why it's analogous.** Our greedy rule IS a deterministic walk on "states"; the certified endgame (`cyclic-successor-bijection`, `greedy-equals-cyclic-successor`) already proves that *once periodicity has kicked in* the cyclic successor is a bijection. `aimo-0514` promotes this from "endgame" to "the whole argument": periodicity comes for free from reversibility + finiteness, with no cofactor/transversal step.
- **Honest port-assessment — GOLD-but-with-the-same-PreMISE.** The reversibility half ports cleanly and is partly already certified. The finiteness half is the issue: `aimo-0514`'s state set is finite because the *underlying object* (a finite planar graph) is finite — finiteness is free, not proved. In our setting finiteness of the augmented state IS Gap A (finiteness of the set of admissible increment-patterns / witness-configurations modulo nothing). So `aimo-0514` does NOT bypass Gap A; it **reframes** it as "exhibit a finite augmented state on which the greedy map is a bijection." That is a genuinely different *target* (a finite-state + bijection exhibit, not a cofactor bound), and it suggests a concrete sub-goal the outliner can mount: **find an augmented-state encoding of the greedy orbit whose transition is single-valued forward AND backward, and prove the realized state set finite without going through cofactors.** The round-4 ergodic-window fence (k_min unbounded in M_1) blocks the *window-of-increments* encoding specifically; `aimo-0514` says try a DIFFERENT augmented encoding (e.g. state = current term's residue-pattern against the small-prime skeleton + the last witness-type + the "local bit the rule reads next" = the next small-prime the greedy will use). Whether such an encoding has a-priori-bounded realized set is OPEN, not fenced. **Verdict: strongest framing to re-mount; does not by itself crack Gap A but pivots the search from "bound cofactors" to "exhibit finite bijective state."**

### 2. `aimo-0907` (IMO-SL 2020 A6, algebra/functional-equations) — **two-orbit-merge ⇒ additive offset ⇒ eventual periodicity criterion** [GOLD MECHANISM]
- **Crux move (one sentence).** When two deterministic orbits provably merge (agree from some point on), define the additive iterate-offset X(a,b) = n−m at any coincidence; **a second, differing offset would force the orbit to be eventually periodic**, so X is well-defined, additive, and pinnable from one seed coincidence.
- **Why it's analogous.** The load-bearing sub-move is a **deterministic eventual-periodicity criterion with no finiteness assumption**: "two coincidences at two different offsets ⇒ periodic." This is NOT the cofactor bound and NOT a finite-state pigeonhole. It is a *coincidence-doubling* argument.
- **Honest port-assessment — genuinely different, worth mounting.** Our greedy sequence provably has ONE self-coincidence structure: the cofactor AP `k_{i+s}=k_i+L/q` (certified `schur-cofactor-premise-fails-in-periodic-regime`, but that lemma *uses* periodicity to derive the AP — circular as a proof of periodicity). The `aimo-0907` lens inverts this: hunt for **two distinct offsets** at which some orbit-abstraction coincides; periodicity then follows for free, *without* first proving cofactor-finiteness. The open question: can we exhibit a SECOND coincidence in the pre-periodic greedy orbit that is not derived from periodicity? Candidate abstractions to test for double-coincidence: (a) the increment-word `d_n` read modulo the small-prime skeleton `P_1`; (b) the "witness-prime sequence" (which small prime `p∈P_1` carries the gcd at step n); (c) the residue-class skeleton `a_n mod M_1`. The single-coincidence AP is already known for (c) post-periodicity; the task is to find a *second* coincidence of the *same* abstraction at a *different* offset, pre-periodicity. **Verdict: the cleanest non-circular mechanism in the set. Mount a focused search for a second coincidence in abstractions (a)/(b); this is the one direction that could yield a non-circular route past Gap A.**

### 3. `aimo-0678` (IMO-SL 2015 N4, number_theory/divisibility-and-gcd + size-bounding + modular-CRT) — **frozen-invariant monovariant ⇒ bounded ⇒ reduce-mod-lcm ⇒ finite-state ⇒ periodic** [STRUCTURALLY CLOSEST, BUT HALF-FENCED]
- **Crux move (one sentence).** Form the sum `s_n=a_n+b_n` as a candidate invariant, isolate the regime where it is frozen, then construct the min-of-a-set monovariant `w_n = min{m ≥ a_n : m ∤ s_n}` and prove it is non-increasing, forcing `a_n` bounded; with `a_n` bounded, reduce `b_n` mod `M = lcm(attainable a_n)` ⇒ finite state ⇒ eventually periodic.
- **Why it's analogous.** Same shape: a gcd-driven recurrence, prove eventual periodicity. The natural closest analog in the corpus.
- **Honest port-assessment — three sub-moves, split verdict.**
  - (a) *Frozen invariant hunt.* Our setting has no obvious `s_n`-style frozen sum, BUT `M_1 = rad(a_1)` is a structural invariant (it never changes; it's fixed from the start). The analogy suggests hunting for a quantity that is *frozen* in the greedy regime and testing divisibility against `M_1`. This is a NEW monovariant template not yet tried (the round-2/3 monovariants were MT-frontier `w_n = min{q > M_1 : q ∈ ∪MT(F_n)}` and the `aimo-0134` running-average — neither tested "min{m ≥ a_n : m ∤ M_1}"-style). Worth flagging.
  - (b) *Min-of-failing-divisors monovariant.* `w_n = min{m ≥ a_n : m ∤ s_n}` is non-increasing because of a *specific* mechanism: in the non-divisibility regime, `a_n ∈ W_{n+1}` (so `w_{n+1} ≤ a_n = w_n`). Porting requires identifying, in our greedy step, an analogous "the current term falls into the next step's failing set" inclusion. This is NOT obviously present — our `a_{n+1}` is forced *admissible* (shares a prime with every prior term), so it is the OPPOSITE of a failing-divisor. The structural fit is weak here.
  - (c) *Reduce mod lcm ⇒ finite state ⇒ periodic.* **FENCED.** This is precisely the modular-residue statistic fence (minimal functional modulus = L; the round-3 reviewer certified `a_n mod L_0` predicts `d_n` iff `L_0` is a multiple of L). Do NOT re-walk sub-move (c) as a "bypass."
- **Verdict: sub-move (a)/(b) suggest a fresh monovariant template (`min{m ≥ a_n : m ∤ M_1}`-style or `min{m : m fails to be admissible-relative-to-skeleton}`); sub-move (c) is fenced. The monovariant template is genuinely different from the two certified-dead monovariants (which were both MT-frontier / running-average), but it is a LONG SHOT — the structural fit of the "failing-divisor inclusion" is weak.**

### 4. `aimo-0077` (Germany TST 2010, combinatorics/extremal-principle) — **minimal-index-on-state-cycle descent** [GOLD MECHANISM, NEEDS RE-INVERSION]
- **Crux move (one sentence).** Assume nontermination forces a repeating state-cycle; take the minimal-index object acted on within that cycle, and show restoring it would require a forbidden smaller-index action.
- **Why it's analogous.** A minimal-counterexample descent on the *violation* of the desired property, using a well-ordering on the objects acted on. Genuinely different from cofactor/transversal.
- **Honest port-assessment — needs re-inversion, but the template fits.** Our sequence is infinite-and-increasing (it does NOT terminate), so "nontermination ⇒ cycle" does not directly apply. BUT the re-inverted form does: **suppose NOT eventually periodic; then [some finite abstraction] never cycles; take the minimal-index object where the abstraction first violates the would-be periodic structure; produce a smaller-index violation.** This is a minimal-counterexample-on-the-first-violation-of-periodicity, structurally akin to `aimo-0009`'s "smallest i with `a_i ≥ n+i`" descent. It does NOT require finiteness of the state space up front (unlike `aimo-0514`/`aimo-0678`-c); it requires a well-ordering and a "forbidden smaller-index action" — i.e. a greedy-specific local rewriting that turns a violation into a smaller violation. The round-4 minimal-criminal setup (Steps 1–6, certified SOUND) is exactly the mount point for this: it well-orders governing primes `q > M_1` and takes the smallest. What `aimo-0077` adds is the suggestion to mount the descent on the **first index where the increment-word `d_n` deviates from a candidate period** (a smaller-index descent on the *deviation index*, not on the prime `q`). **Verdict: genuinely different mount (descent on deviation-index, not on prime); compatible with the certified Steps 1–6 mount point; the "forbidden smaller-index action" must be supplied by a greedy-specific local rule — OPEN whether the greedy rule supplies one. Worth one focused attempt.**

### 5. `aimo-0028` (IMO-SL 2013 N3, number_theory/size-bounding-and-descent) — **self-referential index identity forbids infinite strictly-increasing run** [LONG SHOT]
- **Crux move (one sentence).** Use a self-referential index identity that equates a far-ahead term of a sequence to a nearby term to forbid an infinite strictly-increasing run.
- **Why it's analogous.** Our `a_n` is strictly increasing, so the literal "forbid strictly-increasing run" does not apply. BUT the *mechanism* ports to any derived sequence `(q_n)` (e.g. the sequence of distinct new primes entering term-supports, or the witness-prime sequence): find an index identity `q_{f(k)} = q_k` with `f(k) > k+1` to forbid monotone increase, plus "can't strictly decrease forever" to force infinitely many local maxima.
- **Honest port-assessment — long shot.** The greedy rule gives one obvious index identity: `a_{n+1}` is the smallest admissible `> a_n`. There is no obvious *far-ahead* identity `a_{N(k)} = a_k` (that would BE periodicity). The derived-sequence version requires exhibiting a non-trivial self-referential identity on e.g. the witness-prime sequence — none is currently known. The round-3 `block-index-advance` lemma is the closest certified ingredient (block-index structure of `B_∞`), but it is conditional-on-Gap-A. **Verdict: only worth mounting if a non-trivial pre-periodic self-referential identity on a derived sequence can be exhibited; none currently on the table. Lower priority.**

### 6. `aimo-0009` (IMO-SL 2013 A4, algebra/sequences-and-recurrences + size-bounding) — **minimal-index counterexample + modular-exclusion forces a jump by a full period** [TEMPLATE, CIRCULAR-IF-USED-LITERALLY]
- **Crux move (one sentence).** To prove a self-referential index bound `a_i ≤ n+i−1` for a periodically-extended sequence, take the smallest counterexample `i`, use periodicity to forbid a whole residue window mod `n`, forcing the value to jump into the next period, then collapse via minimality.
- **Why it's analogous.** A minimal-index counterexample + residue-window-exclusion forcing a structural jump. The shape of "exclude a residue block, force a jump, contradict minimality" is genuinely different from cofactor-bounding.
- **Honest port-assessment — circular if used literally, useful as a template.** `aimo-0009` *assumes* periodic extension to run the residue-exclusion; we are trying to PROVE periodicity, so the literal use is circular. BUT the *template* (minimal-index counterexample + exclude-a-block + force-a-jump + collapse) ports to a non-circular setting: take the smallest index `i` where the increment-word `d_n` first violates the candidate period; use the greedy rule to exclude a block of would-be continuations; force the violation to jump; collapse. This pairs naturally with `aimo-0077`'s descent-on-deviation-index. **Verdict: useful as a complementary template to `aimo-0077`; not a standalone route.**

## Candid verdict: does any crux give a non-circular route past Gap A?

**No crux in the corpus gives a *ready-made* non-circular route.** That was the realistic expectation (the problem is IMO-P6-hard and the corpus is disjoint from the 2026 set). But the pull is NOT empty — it surfaces **two genuinely-different mountable mechanisms** that are NOT in the fenced list and that the outliner should consider as rival framings:

1. **`aimo-0907`'s two-coincidence ⇒ periodicity criterion** (mechanism, not framing) — the single cleanest non-circular idea in the set. It needs NO finiteness assumption and NO cofactor bound; it needs a *second* pre-periodic coincidence in some orbit-abstraction. This is a NEW search target (hunt double-coincidence in the increment-word mod P_1, or in the witness-prime sequence), not a re-walk of any dead mechanism. **Highest-value new direction.**

2. **`aimo-0077` + `aimo-0009`'s minimal-index-on-deviation descent** (framing) — descent on the *first index where the increment-word deviates from a candidate period*, with the greedy rule supplying the "forbidden smaller-index action." Pairs with the certified Steps 1–6 mount point but mounts the descent on the deviation-index, not on the prime `q`. Genuinely different from the cofactor/transversal wall.

3. **`aimo-0514`'s augmented-bijective-state framing** (framing) — re-frames Gap A as "exhibit a finite augmented state on which the greedy map is a bijection," with the reversibility half already partly certified. The finiteness half IS Gap A, but the *encoding search* (try a non-window augmented state — residue-pattern + last witness-type + next-small-prime-bit) is NOT fenced (only the window-of-increments encoding is fenced). Worth one focused attempt at a non-window encoding.

4. **`aimo-0678`'s frozen-invariant monovariant template** (mechanism, long shot) — a min-of-failing-divisors monovariant against the frozen `M_1 = rad(a_1)`, structurally different from the two certified-dead monovariants. Weak structural fit but untried.

**If the outliner builds ≥1 of these as a genuinely-different framing** (not a Gap-A variation), the field diversifies. If all four fail with clean obstructions, the run should consolidate — the conditional proof + LOCK + 25 lemmas are substantial partial progress.

**No crux found that lifts the `q ≤ M_1` cofactor bound directly** — every corpus hit for "bound which primes appear" either is the `aimo-0727`/`aimo-0231` cofactor-transversal mechanism (already certified dead) or presupposes finiteness/periodicity. The non-circular route, if it exists, goes AROUND the cofactor bound (via periodicity-via-coincidence or bijective-state or deviation-descent), not THROUGH it.
