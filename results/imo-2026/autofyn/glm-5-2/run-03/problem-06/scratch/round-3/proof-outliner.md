Target: prove $(d_n)$ is eventually periodic (equivalent to the whole theorem via `cyclic-successor-bijection` + `greedy-equals-cyclic-successor`, both certified).
Technique: `aimo-0134` crux — find an integer-valued running statistic of the greedy sequence that is eventually constant (or eventually monotone-bounded), then transfer eventual constancy back to periodicity of $d_n$ via a difference identity.   3. KEY LEMMA (load-bearing; the `aimo-0134` adaptation): exhibit an integer-valued statistic $c_n$ on the orbit that is EVENTUALLY CONSTANT.   4.   5. Apply `cyclic-successor-bijection` $\Rightarrow a_{n+T}=a_n+L$ for all $n\ge1$. — by certified endgame

### increment-pigeonhole-window: new (genuinely-different framing; Markov window-state; the cleanest finite-statistic isolation of the shared wall)
Target: prove $(d_n)$ is eventually periodic.
Technique: finite-state pigeonhole on the window admissibility state $\sigma_n\in\{0,1\}^{M_1}$.
Skeleton:
  1. Define $\sigma_n:\{1,\dots,M_1\}\to\{0,1\}$ by $\sigma_n(k)=1$ iff $a_n+k$ is admissible at step $n$ (shares a prime with every $a_i$, $i\le n$). By `linchpin-and-gap-bound`, $d_n=\min\{k:\sigma_n(k)=1\}\le M_1$, so the window of size $M_1$ always contains the pick. — by certified linchpin
  2. State space $\{0,1\}^{M_1}$ is finite ($\le 2^{M_1}$). — by finiteness
  3. Transition: $\sigma_{n+1}$ is $\sigma_n$ shifted right by $d_n$, with the new constraint "shares a prime with $a_{n+1}$" imposed. The $P_1$-part of the new constraint is determined by $a_{n+1}\bmod M_1=(a_n+d_n)\bmod M_1$ (since $p\mid a_{n+1}\Leftrightarrow a_{n+1}\equiv0\bmod p$ for $p\in P_1$). — by modular arithmetic on $P_1$-primes
  4. KEY LEMMA (load-bearing, = Gap A restated in increment language, but cleanly isolated): the transition $\sigma_n\to\sigma_{n+1}$ is determined by a bounded function of $(\sigma_n,\text{recent }d\text{-window})$ — equivalently, only finitely many non-$P_1$ primes ever enter $S(a_{n+1})$ in a way that FLIPS a bit of $\sigma$ in the window. Mechanism (target): the free-rider primes that change $d_n$'s selection are exactly those $\le M_1$ (the round-1 conjecture $q\le M_1$, restated as "only primes $\le M_1$ ever act as the unique connector reducing $d_n$ below the $P_1$-skeleton value"). — mechanism to prove (the wall)
  5. Pigeonhole: $(\sigma_n)$ takes finitely many values $\Rightarrow$ eventually periodic $\Rightarrow$ $d_n$ eventually periodic. — by pigeonhole on the finite realized state set
  6. Apply `cyclic-successor-bijection`. — by certified endgame
Key lemmas (claim + one-line mechanism):
  - $d_n=\min\{k:\sigma_n(k)=1\}$ and the window size $M_1$ suffices — because $d_n\le M_1$ (linchpin), so the pick is always inside the window.
  - The $P_1$-part of the transition is finitely determined — because $p\mid a_{n+1}\Leftrightarrow a_{n+1}\equiv0\bmod p$ for $p\in P_1$, and $a_{n+1}\bmod M_1$ is a function of $(a_n\bmod M_1, d_n)$.
  - (Fallback sub-lemma, empirically observed): the realized window-state set $\{\sigma_n:n\ge1\}$ has size exactly $T$ (the period) — because the orbit is the increasing enumeration of $\mathcal B_\infty$ and $\sigma_n$ encodes the local admissibility pattern, which repeats with the period; if this can be proved directly (without first knowing $L$), pigeonhole closes the theorem.
Open gaps: step 4 (transition finite-determinedness — the wall); the fallback sub-lemma is a weaker target if the full transition bound is out of reach.
Cases to cover: $|R_1|=1$ cases (385-class: $\sigma_n$ structure is entirely from free-rider discounts, $\approx 8$ distinct discount values) vs $|R_1|>1$ (2085: $|R_1|=139$, looser); the argument must handle both.
Watch out for: (i) the $L_0$-functionality test — any residue-modulus statistic fails unless $L_0=L$; the state MUST be the full window pattern (or a dynamic recent-$d$ window), not $a_n\bmod L_0$; (ii) the transition leak is concretely real: for $a_1=385$, two indices with identical $a_n\bmod 385$ can have different $S(a_{n+1})$ free-rider parts (89 conflicts on $d_n$) — so $\sigma_n$ alone (without the free-rider bound) is NOT a closed state; (iii) the negative lemma fences off "bounded gaps $\Rightarrow$ periodic" — the pigeonhole must use the finite STATE space, not just syndeticity.

### crt-period-lifting: new (`aimo-0231` template; inductive on governing primes ADDED)
Target: construct $L$ prime-by-prime and prove the eventual AP.
Technique: `aimo-0231` CRT period lifting — bound the period growth per governing prime added, starting from the LOCK base.
Skeleton:
  1. Base: LOCK ($|P_1|=1$ / prime-power term) certified by `lock-lemma` — period $L=p$, $T=1$. — by certified `lock-lemma`
  2. Inductive setup: suppose periodicity with period $L_k$ (product of the first $k$ governing primes, lifted in increasing order) is established. Let $r$ be the next governing prime to add; $L_{k+1}=L_k\cdot r^{e}$ for the appropriate power. — by induction hypothesis
  3. KEY LEMMA (the `aimo-0231` lift bound, adapted): the first-return time of the cyclic-successor map mod $L_{k+1}$ grows by at most a factor $r$ over the return time mod $L_k$. Mechanism (the `aimo-0231` crux): the fiber over each residue mod $L_k$ has $\le r^{e}$ elements mod $L_{k+1}$; counting the residues mod $L_{k+1}$ that reduce to a fixed admissible residue mod $L_k$ bounds the return-time growth by the fiber size $\le r^{e}$. — by the `aimo-0231` fiber-counting move (adapted; the map here is the greedy cyclic successor, not a polynomial iterate)
  4. KEY LEMMA 2 (finiteness of the governing set + well-founded addition order): the set of governing primes to add is finite, and the lift can be ordered so each added prime $r$ satisfies $r\le M_1$ (round-1 conjecture), making the candidate set $\{r:r\le M_1, r\text{ prime}\}$ finite. Mechanism: each new governing prime $r$ enters as the cofactor of the smallest $L_k$-admissible multiple above a witness; the gap bound $d\le M_1$ bounds the cofactor $r\le M_1$. — mechanism to prove (this IS Gap A, but the inductive fiber structure gives a cleaner handle than the strip)
  5. CRT-combine the lifted prime-power periods into $L=\operatorname{lcm}$; the product of bounded per-prime factors is finite. — by CRT
  6. Apply `cyclic-successor-bijection`. — by certified endgame
Key lemmas (claim + one-line mechanism):
  - Per-prime lift factor $\le r$ — because the fiber of $\mathbb Z/L_{k+1}\mathbb Z\to\mathbb Z/L_k\mathbb Z$ has $r^{e}$ elements, and the cyclic-successor return time on the fiber is bounded by the fiber size (the `aimo-0231` crux).
  - Governing primes are finite and $\le M_1$ — because each enters as a cofactor of a smallest-admissible-multiple witness, and the gap bound $d\le M_1$ bounds the cofactor.
Open gaps: step 3 (the lift bound for the GREEDY successor — not a polynomial iterate; admissibility couples all primes simultaneously, so CRT does NOT cleanly decouple; the `aimo-0231` fiber-count must be re-proved for the cyclic-successor map); step 4 (finiteness of governing primes — Gap A; the inductive structure is the new handle, not a bypass).

Watch out for: (i) the drop-$r$ quotient map is DEAD (the not-$r$ sub-sequence does NOT match $\text{greedy}(a_1/r)$, verified for $a_1=385,r=11$) — the induction is on governing primes ADDED via CRT fiber lifting, NOT on $|P_1|$ via quotient descent; (ii) $v_p(a_n)$ does NOT stabilize (fluctuates in the tail for $a_1=385$), so the lift cannot rely on $p$-adic valuation stabilization; (iii) the governing set is NOT $P_1\cup\{2,3\}$ — 2085 has $139\in P_1$ but $139\notin$ governing set, so the lift order is not simply "add $P_1$-primes then free-riders"; (iv) $|P_1|=3$ is mostly EASIER than $|P_1|=2$ (non-$P_1$ gov $\subseteq\{2,3\}$ except 385) — do not assume monotonicity in $|P_1|$.

### p1-equals-2-direct: new (smallest open base; narrow the wall to $|P_1|=2$ NON-LOCK)

  3. KEY LEMMA (load-bearing, = Gap A specialized to $|P_1|=2$): every governing prime $q$ satisfies $q\le M_1=\operatorname{rad}(a_1)=p_{\rm sm}\cdot p_{\rm lg}$. Mechanism (target): after $2$ enters at $n=2$, $2$-multiples occur at density $1/2\gg 1/p_{\rm sm}$; each witness $a_j$ that pulls in a new prime $r$ does so as the cofactor of the smallest $2$-multiple (or $p_{\rm sm}$-multiple) above $a_{j-1}$, and the gap bound $d_{j-1}\le M_1$ bounds the cofactor $r\le M_1$. The $2$-density dominance ensures the smallest-admissible candidate is always $2$-divisible in this regime, making the cofactor structure rigid. — mechanism to prove (the strip is dead; the new lever is the $2$-density dominance, unavailable for $|P_1|\ge3$)
  4. Once governing primes are bounded ($\subseteq$ primes $\le M_1$, finite), the state space is finite; apply `cyclic-successor-bijection`. — by certified endgame
  5. (Conditional, deferred to `crt-period-lifting`) Lift to general $|P_1|$ via CRT period lifting. — by the crt-period-lifting approach
Key lemmas (claim + one-line mechanism):
  - $a_2=a_1+p_{\rm sm}$ is even — because $q+1$ is even ($q$ odd prime), so $a_2=p_{\rm sm}(q+1)$ is divisible by 2.
  - Governing primes $\le M_1$ for $|P_1|=2$ NON-LOCK — because the $2$-density dominance ($1/2 \gg 1/p_{\rm sm}$) forces witnesses to be $2$-multiples, and the gap bound $d\le M_1$ bounds the cofactor prime $r\le M_1$.
