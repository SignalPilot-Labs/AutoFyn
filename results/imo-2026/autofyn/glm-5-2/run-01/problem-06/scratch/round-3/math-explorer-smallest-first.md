### Distinct openings (each a different attack the outliner could build)

1. **The free-rider lemma (REFUTES the unique-connector obstruction).** Across **135+ seeds (saturated AND freeze)**, EVERY promotion entering a new minimal M'=P(a_{n+1}) has the property: M' contains a PROPER subset R⊊M' that is already a transversal of the OLD family M_n. I.e. M' is NEVER a minimal/irredundant transversal of M_n. Zero violations in 135 seeds. **Consequence:** every entering prime q is a *free-rider* — it tags along in a_{n+1}=prod(R)·k (q|k) but is structurally redundant (R already hits everything). The "unique connector" obstruction (γ GAP-3 honest obstruction, α GAP-S) — a large fresh q being the sole element of M'∩M_0 — is **empirically vacuous: it never occurs.** This kills the obstruction that made GAP-3 look hard. CONJECTURE (universal, 0 counterexamples): *the greedy's smallest-first pick a_{n+1}=min{valid m>a_n} never has P(a_{n+1}) a minimal transversal of M_n.* Mechanism intuition (NOT a proof): the smallest valid m>a_n is a multiple of mtp(M_n)=prod(T*) (gap bound), so P(a_{n+1})⊇T*; for P(a_{n+1}) to EQUAL a minimal transversal would require the cofactor k=a_{n+1}/mtp to have all prime factors inside that transversal — a "tight" pick the smallest-first rule avoids because looser (denser, smaller-prime) valid m always exist below it.

2. **The bounded-entering-prime structural lemma (saturated regime) — the wall-closer.** Across **~135 saturated seeds** (2-,3-,4-prime squarefree a_1, primes up to ~97, plus products like 7429, 4199, 12673, 20677, 46189), **every prime q that ever enters a minimal support satisfies q ≤ a_1/p_min(a_1)** where p_min is the smallest prime factor of a_1. ZERO violations. Examples: a1=1001=7·11·13→max_ent=97≤143; a1=19549=113·173→max_ent=109≤173 (boundary: 173 itself is a factor of a1); a1=7429=17·19·23→251≤437; a1=4199→127≤323; a1=7387=83·89→79≤89. If proved, this DIRECTLY closes the wall: P_ess ⊆ P(a_1) ∪ {primes ≤ a1/p_min}, a finite set ⟹ the pairwise-intersecting antichain M over a finite prime set is finite ⟹ reaches self-blocking by finiteness of the transversal hypergraph ⟹ Sat-criterion (certified) ⟹ frozen ⟹ post-stabilization-theorem. **This is the single structural lemma the field needs; it is CONJECTURE (135 seeds, no proof).**

3. **Stronger 2-prime bound (mechanism hint).** For 2-prime saturated seeds pq (p<q), the bound sharpens to **max_ent < p_min(=p)** — the entering primes are all SMALLER than the smallest factor of a_1. Verified: 187(11·17)→7<11; 323(17·19)→13<17; 899(29·31)→23<29; 7387(83·89)→79<83; 8633(89·97)→79<89. This suggests the mechanism is NOT about a_1/p_min generically but about something tighter tied to p_min; for ≥3-prime seeds the bound reverts to a_1/p_min. The difference is a mechanism clue, not yet a proof.

4. **Cofactor/free-rider arithmetic (mechanism candidate, NOT yet a proof of the bound).** When q enters as a free-rider: a_{n+1}=prod(R)·k, R⊆M' proper transversal of M_n, prod(R)≥mtp(M_n), q|k. So q≤a_{n+1}/mtp≤(a_n+mtp)/mtp=a_n/mtp+1. This DEPENDS ON a_n (circular — termination is the conclusion). BUT empirically a_n at the last promotion stays ≤~1.4·a_1 in saturated regime (e.g. a1=1001 last promo a=1364; a1=19549 last a=24634; a1=7429 last a≈8816), giving q≤~1.4·a_1/mtp. Since mtp≈2·p_min often (transversal {2,p_min}), this gives q≤~0.7·a_1/p_min, matching the observed ratios (0.3–0.89). **The circularity (bound on a_n uses termination) is the residual gap** — the outliner must break it with a non-circular invariant. Candidate: a direct argument that the smallest-first pick cannot push a_n past ~2·a_1 without first forming a self-blocking family (because every large-a_n pick would carry a free-rider prime already in P_ess, hence no new minimal, hence mtp already stabilized).

5. **Regime split confirmed sharply by the data.** FREEZE-regime seeds (some p∈P(a_1) stays common) have HUGE entering primes — up to ~a_1 (a1=273→241; a1=715→619; a1=2310→2039; a1=3·283→727) — all evicted by the eventual singleton {p} when the AP a_n=p(c+n-1) hits p^k. So "only small primes enter" is FALSE for the transient set in freeze regime — but freeze is SOLVED (α r2), so irrelevant. The bounded-entering lemma is a **SATURATED-regime-only** statement. The dispatch's question "can primes larger than a_1 enter?" — answer: NO across all seeds (max_ent ≤ a_1 always, even in freeze where it reaches ~a_1). But the meaningful bound is the saturated a_1/p_min.

### Cheap-kill candidates
- **Free-rider property is near-tautological via the gap bound:** a_{n+1}≤a_n+mtp means a_{n+1} is within mtp of a_n; the mtp-witness T* (prod=mtp) has all multiples valid; the smallest multiple of mtp above a_n is ≤a_n+mtp and is picked (or something smaller is). Either way P(a_{n+1})⊇T* unless a strictly-smaller valid m exists with fewer primes. A cheap structural observation: *if a_{n+1} is a multiple of mtp then M'⊇T* so M' is non-minimal-transversal unless P(a_{n+1})=T* exactly.* The only way the free-rider property fails is if a_{n+1}'s prime set is EXACTLY a minimal transversal — worth checking whether this is provably impossible under smallest-first. This is the cheap-kill direction.
