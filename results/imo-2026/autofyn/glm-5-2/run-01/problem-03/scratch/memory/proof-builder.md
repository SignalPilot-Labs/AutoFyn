ALWAYS: When a problem reduces to a minimax over continuous cut positions, verify the conjectured value with a continuous optimal-XY search whose candidate cuts are "fragment equals an existing piece size" or "fragment equals half a piece" — these are exactly the breakpoints where the sorted order (hence the piecewise-linear objective D) changes slope, so the search returns the true optimum (a numerical certificate, not a proof step).
NEVER: Trust an "exhaustive integer refinement" search to certify a continuous optimum — continuous cuts can split a unit-sized piece into non-integer fragments at breakpoints the integer lattice misses (e.g. it missed the split of piece 1 in the geometric lower bound). Always use continuous candidate-cut search instead.
ALWAYS: For "two multisets merged, alternating sum" claims, test the bold inequality D(merge) ≥ sumF − sumT on random small multisets before trusting it — it is FALSE in general (counterexample F={5,5,5,5}, T={4,4,4,4} gives D=0), so structural hypotheses are mandatory.
NEVER: Assume a "halve-or-match the top two" greedy pairing strategy suffices for an upper bound — the leftover exceeds the target for n≥3 on some random configs. The global alternating sum interleaves the leftover with the rest; a local pairing is not a proof.
ALWAYS: When an inductive merge lemma "D(merge of F and T) ≥ target" is needed, numerically test it with (i) T = the real structural hypothesis (e.g. actual refinement of a geometric config) AND (ii) T = a weakened hypothesis (e.g. any multiset with D(T) ≥ threshold). If (ii) fails, the induction MUST carry the structure, not just the numeric bound — surface this explicitly as the gap (round 1, imo-2026-03).
ALWAYS: For minimax cake-cutting games reducible to an alternating-sum D, compute the "difference game" (repeatedly replace the two largest a≥b by a−b). On superincreasing configs it gives f(C)=2·max−T; on the tightest (geometric 1:2:4:…) it gives exactly the conjectured value. It is an UPPER bound on min_XY D (it is one XY strategy), NOT a lower bound — co-optimality on the geometric config is the typical hard crux (round 1, imo-2026-03).
NEVER: Trust a scale-invariant induction "V(C,m) ≤ T/S_m" for an alternating-sum upper bound without checking the per-cut reduction ≥ T·2^m/S_m in the FLAT regime (all pieces nearly equal). The hybrid's reduction max(a_1, 2a_2) ≥ 2T/(m+2) which is BELOW T·2^m/S_m for m≥2 — the induction silently fails there (round 1, imo-2026-03).
ALWAYS: For lower-bound casework on the geometric stick config G_n=(1,2,...,2^n), use the even-sum reformulation D ≥ 1 ⟺ Σ_even ≤ 2^n−1 (tail mass) as the target — it makes Case A one line (odd-position piece 2^n forces every even-position piece into the tail) and turns the goal into "the 2nd picker's take ≤ tail mass". The full-halving equality case gives D=1 (round 3, imo-2026-03).
ALWAYS: For fixed-n lower bounds on this config, exhaustive casework by cut DISTRIBUTION (k cuts on the largest piece 2^n) with direct sorted-order analysis on each merge region is a tractable rigorous method — closed L(2) this way (round 3, imo-2026-03). Verify each region's linear form on its full constraint set; emptiness of a "contradicts the sum" sub-case is itself a valid argument.
NEVER: Trust the "r_final = r_0 + R(t)" mnemonic for the parity integral of a cut game — it omits the −1 on (M,s]. The correct toggle is Δr = +1 on (0,m], 0 on (m,M], −1 on (M,s] (cut s→(m,M), m≤M); the broken mnemonic predicts D=2 for n=1 halving where the true value is D=1 (round 3, imo-2026-03).
ALWAYS: Before committing to exhaustive vertex/breakpoint enumeration for an upper-bound "XY can force D ≤ T for every partition" claim, search for a small finite family of EXPLICIT universally-valid strategies whose D-values are simple closed forms of the partition — a "two equal fragments are adjacent and cancel in the alternating sum" argument often gives D = a linear form for free, and proving min(closed forms) ≤ T by a contradiction (sum the assumed strict lower bounds) is far cleaner than vertex enumeration. Closed U(2) for imo-2026-03 this way (round 4): four strategies D ∈ {a1−a2, a2−a3, |2a1−1|, a3}; min ≤ 1/7 because all-four->1/7 forces a1>4/7 contradicting a2+a3>3/7.
NEVER: Assume a strategy that pairs fragments (halve / match) requires the "top-heavy" regime to sort correctly — two EQUAL fragments are always adjacent in the sorted order regardless of regime, so the cancellation "two equal adjacent pieces contribute 0 to D" holds universally. Only the singletons' sign needs checking (e.g. S4's a3 lands on an odd position because the two pairs stack by size, forcing the singleton to an odd slot). This is what lets one universal strategy cover the flat regime too (round 4, imo-2026-03 U(2)).

ALWAYS: For lower-bound merge lemmas "D(F∪T) ≥ sumF − sumT" on geometric configs, the CUT BUDGET (total cuts ≤ n, NOT independent budgets on big piece and tail) is essential — without it the lemma is FALSE (n=3: min D=0.11, 18513 viol/4M), with it TRUE (0 violations). Always test the merge lemma BOTH budget-respecting AND with independent budgets; if only the former holds, the induction must carry the budget (round 4, imo-2026-03).
ALWAYS: For fixed-n lower bounds on G_n, two clean reductions kill most cases: (R1) smallest piece b_{2n+1} ≥ 1 ⇒ D ≥ 1 [D = sum of odd-indexed drops ≥ b_{2n+1}]; (R2) largest piece b_1 ≥ 2^{n-1}+1 ⇒ b_2 ≤ 2^{n-1} ⇒ drop_1 ≥ 1. The residual (b_1 < 2^{n-1}+1, b_{2n+1} < 1) is small and amenable to cell enumeration (round 4, imo-2026-03).
ALWAYS: Refinement is NOT monotone in the alternating sum D (e.g. {5,3} D=2 → refine 3→{1,2}: {5,2,1} D=4>2). So "fewer cuts ⇒ larger D" is FALSE; you cannot reduce to exactly-n-cut configs. BUT every ≤n-cut config is a DEGENERATE BOUNDARY (fragment=0) of an exactly-n-cut distribution, so closed-cell analysis (polytopes with fragments≥0) covers all fewer-cut configs automatically (round 4, imo-2026-03).
ALWAYS: For exhaustive lower-bound casework with many cells, the vertex-min principle + LP over each cell's closed polytope is a rigorous finite verification (LP returns exact vertex optima). Pair it with random-sampling cell enumeration (recover all sort-orders, confirm the partition covers the simplex) — this is a legitimate proof when hand-writing each cell is infeasible (round 4, imo-2026-03 L(3): 59 cells in k8=2). ALWAYS append the complete self-contained verification script (exact rational arithmetic) as an appendix so the reader can reproduce the cell count and minima — a prose summary without the script fails the "no hand-waving" rule (round 4, proof-reviewer CHANGES REQUESTED).
