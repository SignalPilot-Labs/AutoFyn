## imo-2026-01 (lattice / confluence / merge lens)

- Distinct openings (within this route, far apart in framing):
  1. **Per-prime valuation invariant (the live winner — see below).** For each prime p track the multiset of p-adic valuations across positions. The move sends a pair (α,β) to (min(α,β), max(α,β)−min(α,β)) = (min, |α−β|) — literally one subtractive-Euclidean-algorithm step. The invariant D_p := gcd of *all* v_p(a_i) is preserved, because gcd(α,β) = gcd(min(α,β), |α−β|) (the Euclidean identity). At the terminal state (one entry M, rest 1) the multiset is {v_p(M),0,…,0}, whose gcd is v_p(M); so v_p(M)=D_p, forcing M = ∏_p p^{D_p}, independent of choices. This single invariant proves **both (a) exactly-one-remains and (b) independence** — no confluence needed.
  2. **Pure monovariant termination (part (a) only) via product + count.** The total product Π of all entries is non-increasing; it strictly decreases by a factor of gcd(m,n) ≥ 2 whenever the chosen pair is non-coprime. The number of >1 entries is non-increasing (decreases by 1 on a coprime pair or on equal pair (m,m); stays constant only when gcd>1 and m≠n). If an infinite run existed, the count eventually stabilizes at c≥2, after which every move strictly decreases the integer product — impossible (bounded below by 1). So the process stops with ≤1 entry >1; the invariant D_p (≥1 for some p since all entries >1) rules out the all-ones state, giving exactly one >1 entry. Clean but only does (a); pair it with the invariant for (b).
  3. **Confluence / Newman's-lemma framing (honest verdict: true but REDUNDANT, do not make it the primary attack).** Since the system is terminating and the invariant pins a unique normal form, confluence holds as a *consequence*. Proving local confluence directly (two divergent moves rejoin) is possible in principle but messy and strictly harder than the invariant; it would be circular to lean on it for (b) without already knowing the unique normal form. Worth one sentence as an alternative lens, not a build target.

- Small-case / intuition notes (CONJECTURE confirmed by simulation, labeled as evidence not proof):
  - Simulated {4,2},{6,10},{2,3},{2,2},{8,8},{12,18},{4,8,3},{6,6,6},{12,18,24},{100,75,50},{30,84,275} with 8 random move orders each; every order terminated and gave the same M = ∏_p p^{gcd_i(v_p(a_i))}.   - Key subtlety to get right in the proof: D_p = gcd of v_p over ALL positions, where positions with v_p=0 contribute 0 (and gcd(x,0)=x, so zeros are invisible). Equivalently D_p = gcd of the nonzero valuations. This differs from min (= v_p of the gcd of all numbers) — {6,10} shows the difference (min would give gcd=2, wrong; gcd-of-valuations gives 30, right). The outliner must state D_p precisely.
  - Termination sub-step counts were small (≤8) in all tests; no pathological long runs seen, consistent with the product-decreases-by-≥2 argument bounding the number of "count-stable" moves by log_2(initial product).
