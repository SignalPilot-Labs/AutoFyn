# proof-builder per-role rules

ALWAYS: When a confluence/Newman's-lemma approach is dispatched and the reviewer says positioned-board local confluence fails, immediately reframe on MULTISETS (quotient positions) — the value M is position-independent so the multiset carrier is faithful, and multiset local confluence is what actually holds. (round 1, imo-2026-01: positioned boards fail 72/1331, multisets pass 1331/1331.)

ALWAYS: For the per-prime-to-board lift in a confluence proof, exploit that per-prime CONFLUENCE (not just local confluence) means EVERY reduction schedule reaches the unique per-prime normal form — so the coupled board schedule's projection reaches each prime's normal form WITHOUT needing to synchronize schedules across primes. This is the clean way the lift closes. (round 1, imo-2026-01.)

NEVER: Assume "gcd(g, xy) = 1" for the move (m,n)→(g,xy) — it is FALSE in general (e.g. m=4,n=8: g=4, xy=2, gcd=2). The two outputs share prime factors at primes dividing both m and n. The correct per-prime picture is v_p(g)=min(α,β), v_p(xy)=|α−β|, and gcd(min,|α−β|)=gcd(α,β)≥1 only when p|gcd(m,n). (round 1, imo-2026-01: the outliner stated gcd(g,xy)=1 wrongly; not load-bearing for the (min,|α−β|) valuation approach but a trap if reused.)

ALWAYS: Be honest when a confluence proof's local-confluence step uses the same algebraic core (Euclidean identity) as the invariant approaches — record it in Approaches tried. A valid non-circular proof that shares a tool is still solved; the differentiator is the proof ARCHITECTURE (local confluence + Newman vs direct invariant pin), not the tool. (round 1, imo-2026-01.)
