ALWAYS: for game-theory "claim pieces alternately" problems, first establish (and cite as a proven lemma, not KB) that greedy-take-largest is optimal for both players on a fixed multiset of pieces (exchange argument) — this converts the game into "sum of odd-ranked pieces when sorted descending," which is the tractable object to optimize (round 1, imo-2026-03).
ALWAYS: when a continuous minimax game (stick/interval marking, alternating claims) resists closed-form guessing, build a numeric bilevel search (scipy Nelder-Mead with many random restarts, inner = adversary's best response enumerated over discrete "which segment gets how many splits" compositions, outer = grid/perturbation search over the first player's construction) — this found the exact answer 2^n/(2^{n+1}-1) for imo-2026-03 (IMO 2026 P3) and refuted two plausible-looking closed-form guesses that would have wasted an outline round.
NEVER: trust a "matches n=1" closed-form guess without checking n=2 — (n+1)/(2n+1) matched n=1 exactly (2/3) but was numerically refuted at n=2 (predicted 3/5, true value 4/7) (round 1, imo-2026-03).

ALWAYS: for pick-largest-alternating games with a fixed final multiset of pieces, use the alternating-sum identity S=Σ(-1)^{i+1}p_(i) (sorted desc), first-player total=(1+S)/2 — it turns the whole game into a one-shot optimization and is the natural potential for bounds (imo-2026-03, round 1).
ALWAYS: numerically verify small-n conjectures with an actual nested min/max grid search (outer over the first player's partition, inner near-exhaustive over the second player's split options) before trusting a pattern-matched formula from n=1 alone — a plausible-looking formula ((n+1)/(2n+1)) matched n=1 but was refuted by n=2 numerics (true answer ~2^n/(2^{n+1}-1)) (imo-2026-03, round 1).
NEVER: assume a near-zero "sliver" split can freely flip rank-parity of a suffix of sorted pieces — a tiny sliver always sorts to the very bottom of the whole list, not locally after the piece it was cut from (imo-2026-03, round 1).

ALWAYS: for sorted-descending alternating-sum potentials S=Σ(-1)^{i+1}p_(i), remember/use the identity S = min over all pairings of the elements (with one leftover if odd count) of Σ|pair diffs|+leftover, attained by adjacent-in-sorted-order pairing (classical min-cost-matching-on-a-line fact) — this lets you upper-bound S by exhibiting ANY witness pairing instead of proving exact rank/parity claims; verified numerically to be exact on random 3-5 element lists (imo-2026-03, round 2).
NEVER: simulate a "use all n allowed cuts" strategy when the rule is "≤n cuts" — forcing full cut usage even when a cut doesn't help (e.g. bisecting repeatedly after the opponent already made only one real piece) drives the simulated value far above the true optimum and looks like a refutation when it's actually a simulation bug (imo-2026-03, round 2).
NEVER: when simulating a "match" move (cut a carry piece C into a twin of some already-fixed piece q so they cancel in rank), forget that BOTH the new twin and the ORIGINAL q survive as separate pieces in the final multiset — a lookahead/candidate-comparison list that only appends the twin and tracks q via a side "consumed" pointer will silently omit q's contribution, making a bad strategy look like it always beats the target (false-negative bug found this way in round 2, imo-2026-03).
ALWAYS: when testing a candidate one-step/local greedy rule for a peel-and-recurse minimax (e.g. "match vs bisect" per cut), stress-test it against thousands of RANDOM (non-adversarially-chosen) partitions, not just the handful of cases used to derive the rule — a rule that passes on hand-picked or the first batch of random cases (e.g. "always match except decide on the very last cut") can still fail 15-30% of the time on a wider random sweep once bookkeeping bugs are fixed (imo-2026-03, round 2).
NEVER: propose Hall's-marriage-theorem/matching-existence framings for a problem where a min-pairing identity (like L4) already gives the optimal pairing in closed form (consecutive sorted elements) — there is no matching-existence question left, so Hall's theorem answers a question the problem doesn't have; confirmed dead in round 3 of imo-2026-03.
ALWAYS: before proposing a "potential/DP restated in different variables" as a new opening, algebraically check whether it's a pure relabeling of an existing approach's recursion (e.g. β vs S via S=1-2β) — if so it inherits the identical obstruction and is not a distinct opening (imo-2026-03, round 3).
ALWAYS: for a stuck "prove S(whole)≥1" gap decomposed as S(whole)=S(Q)+S(C)-2W, numerically find the EXACT extremal configuration (not just confirm the bound holds) — computing S(Q), S(C), W separately at the true minimizer reveals whether the abstract bound (e.g. S≥|S(Q)-S(C)|) is tight or slack (imo-2026-03 round 3: the minimizer is a full binary cascade splitting the top piece through every dyadic level with the rest left uncut, giving |S(Q)-S(C)|=1 exactly with FULL overlap W=min(S(Q),S(C)) — so the missing ingredient is an upper bound on W, not a better use of the IH alone).
NEVER: assume "S(C)≥1 by induction hypothesis" alone is enough input for a binding lower-bound subcase without checking the IH's value at the actual extremal witness — it can be far from its own bound (imo-2026-03 round 3: S(uncut R) grows like a Jacobsthal sequence 1,1,3,5,11,21,... not staying near 1, yet S(whole) stays exactly 1 at the true minimizer, so a proof using only "S(C)≥1" in isolation cannot be tight).
NEVER: trust an "oblivious/positionless" strategy (a fixed cut set independent of the adversary's move) for an adaptive alternating-marking game without a 30-second sanity test — a fixed XY cut set at {1-2^-1,...,1-2^-n} regardless of LB's partition gives worst-case ratio up to 15x over target; LB just marks one point adversarially close to a fixed XY cut point (imo-2026-03, round 3).
ALWAYS: when a "uniform/non-adaptive one-shot" strategy reproduces the exact optimum ON the conjectured extremal profile (e.g. dyadic) but hasn't been stress-tested off that profile, do NOT treat the on-profile match as evidence it works generally — for imo-2026-03's "split a_i into (a_i-a_{i+1}, a_{i+1})" telescoping rule, it degenerates to the correct bisection cascade exactly at dyadic A but fails by up to 28x off-profile (one-dominant-piece case), because match-only rules always need a bisect fallback (round 3).
NEVER: add a single top-level threshold test (e.g. "bisect while a_1 > sum(rest), then apply a fixed follow-up rule") expecting it to replace a full backward-induction/DP for a peel-and-recurse minimax — tested for imo-2026-03 and it fails even AT the exact optimum (not just off it) due to the classic "twin and original both survive" bookkeeping trap re-appearing in the follow-up phase; budget only ~10 min to rule one out numerically before moving on (round 3).

ALWAYS: when asked to check whether an "extremal witness is unique/rigid" (e.g. a proposed equality-characterization theorem), numerically search the FULL equality set (many random configs at the exact optimum), not just confirm one witness attains it — for a layer-cake/parity potential S(B)=meas{N(t) odd}, equality regions are generically OPEN/full-dimensional plateaus (S is locally constant, only jumps when a part crosses another's value), so "equality iff THE extremal point" is very often false even when the extremal point itself is correctly identified; imo-2026-03 round 5: for LB's dyadic profile, S(B)=1 held on a positive-measure interlacing-pattern region (~4.7% of random splits at n=3), not just at the cascade — this also retroactively explains why "smoothing toward the unique cascade" (Lemma G) was doomed, since there was no unique target to smooth toward.
ALWAYS: when dispatched to find a "genuinely new UB/LB framing" after several are refuted, first re-run the refuted mechanism's crux-corpus source (e.g. aimo-0198) against a DIFFERENT branch pair before assuming a "new" probabilistic/averaging idea is independent — aimo-0956 turned out to be the same 2-branch-equalizing trick as the already-refuted aimo-0198, not a new mechanism (imo-2026-03, round 5).
ALWAYS: numerically test a candidate greedy/lookahead rule against the EXACT DP value (memoized min over ≤k cuts, Fraction arithmetic) on ~50-80 small random instances before writing it up — one-step S-minimizing greedy and max-adjacent-gap-first greedy both looked plausible but failed 15-55% of random trials with gaps up to 3-4x the true value (imo-2026-03, round 5).
NEVER: assume an "S(B)=1 iff cascade-type" extremal characterization generalizes to a constructive recipe for ARBITRARY starting profiles — numerically the S-minimizing witness is cascade-shaped only at the LB-optimal profile itself; for generic A the minimizer is a trivial single bisect/match far from cascade-shaped, so such a characterization is a lower-bound tightness tool, not an upper-bound construction (imo-2026-03, round 5).

ALWAYS: when a residual inequality is reduced to a concrete finite quantity in known variables (e.g. imo-2026-03's (CB) shard inequality), probe BOUNDARY configurations (one variable pinned at its cap) for an invariance — imo-2026-03 round 6 found that pinning the top Q_low-shard exactly at the cap H makes the slack numerically INDEPENDENT of how the remaining mass is split, a strong hint of a peel/recursion-to-one-level-down mechanism nobody had tried (induction on shard-count, not on n) — found by a targeted exact-Fraction sweep, <60s.
NEVER: trust a floor/ceiling-splitting rewrite of an already-equivalent identity (e.g. splitting ∫⌊D+/2⌋ vs ∫⌈D-/2⌉ using ⌊x/2⌋=x/2−(x odd)/2) as if it were new leverage — for imo-2026-03's (PM)/IB-1, this algebraic manipulation was checked by hand and found EXACTLY CIRCULAR (reduces back to the same inequality it was meant to prove); always do the one-line algebra check before treating a reformulation as progress (round 6).
