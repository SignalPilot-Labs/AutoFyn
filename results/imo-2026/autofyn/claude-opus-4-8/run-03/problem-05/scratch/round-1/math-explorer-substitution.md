## imo-2026-05

- **Distinct openings** (substitution/pinning lens):
  1. **Pinning substitution x = f(y).** This is the crux finding of this pass (see below): it collapses the LHS of the QM-AM inequality to exactly f(y), forcing *both* chained inequalities to become tight simultaneously, yielding the exact identity `f(f(y)) = 2f(y) - y` for all y>0. This is a hard *necessary* condition on every solution, proven rigorously (not conjectured).
  2. **Candidate solution family via reverse-engineering the QM-AM/AM-GM structure.** Guessing `f(x) = x + c` (c a constant) and substituting shows the whole inequality chain becomes *exactly* QM-AM and AM-GM applied to the pair `(x, y+c)`: LHS = QM(x,y+c), middle = AM(x,y+c), RHS = GM(x,y+c). This makes both inequalities hold identically for **every** c ≥ 0, not just c = 0. **This contradicts the run_state's a priori guess "likely answer f(x)=x" — the correct answer is very plausibly the whole family f(x) = x + c, c ≥ 0, not just f(x)=x.** Verified numerically (see below) and algebraically (exact identity, not approximation).
  3. **Injectivity for free.** From `f(f(y))=2f(y)-y`: if f(a)=f(b) then f(f(a))=f(f(b)) ⟹ 2f(a)-a = 2f(b)-b ⟹ a=b (since f(a)=f(b)). So f is injective — falls straight out of the pinning identity, no extra work needed.
  4. **Diagonal substitution x=y is a dead end / gives nothing.** Setting x=y in either inequality just reproduces QM-AM or AM-GM applied to the pair (x, f(x)) — trivially true for *any* positive function f, so it carries zero information about which f work. Do not waste effort here.
  5. **Ruling out non-constant-shift ("shifting the constant by region") solutions.** A quick numerical stress test with a piecewise-defined f (shift by 1 for y≤5, shift by 2 for y>5) satisfies f(f(y))=2f(y)-y *locally* but breaks the original left inequality when x,y are swapped across the two regions (x=7,y=3 fails: LHS≈5.701 < middle=6). This is empirical evidence (not proof) that the shift constant c must be *globally* the same, i.e. the necessary identity f(f(y))=2f(y)-y is not by itself sufficient — the outliner will need an argument (monotonicity? using generic x,y, not just x=f(y)) to upgrade "f(f(y))=2f(y)-y" into "f(y)-y is constant."
  6. **Squaring approach.** Squaring both inequalities gives `2(x²+f(y)²) ≥ (f(x)+y)²` and `(f(x)+y)² ≥ 4x f(y)`. These are the algebraic forms to feed into an SOS/completing-the-square argument once the shift-family is conjectured — e.g. for f(y)=y+c, the middle expansion (f(x)+y)² - 4x f(y) = (x - (y+c))² ≥ 0 is a clean SOS certificate for the right inequality, and 2(x²+f(y)²)-(f(x)+y)² = (x-(y+c))² is the SOS certificate for the left inequality too (both differences equal (x-y-c)²) — worth double-checking and using directly in the sufficiency direction of the proof.

- **Candidate technique(s):** Equality-forcing substitution (x=f(y)) to pin composite f∘f; SOS certificate (x−y−c)² for sufficiency of the shift family; injectivity from the pinned identity; then an argument (monotonicity/boundedness via the original two-sided inequality at generic x,y) to show the "difference function" d(y)=f(y)-y is forced constant.
