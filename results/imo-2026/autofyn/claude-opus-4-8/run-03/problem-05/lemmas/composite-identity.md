# Lemma (composite identity)

For every solution f : ℝ_{>0}→ℝ_{>0} of
$\sqrt{(x^2+f(y)^2)/2}\ge (f(x)+y)/2\ge\sqrt{x f(y)}$,
$$f(f(y))=2f(y)-y\qquad\forall y>0.$$

**Proof.** Put x=f(y) in the squared inequalities. R gives (f(f(y))+y)²≥4f(y)² ⇒ f(f(y))+y≥2f(y);
L gives 4f(y)²≥(f(f(y))+y)² ⇒ f(f(y))+y≤2f(y). Both sides positive, so equality. ∎
