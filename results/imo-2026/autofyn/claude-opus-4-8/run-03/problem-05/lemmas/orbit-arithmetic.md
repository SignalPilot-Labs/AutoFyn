# Lemma (orbit arithmetic and nonnegativity)

For every solution f, with d(y):=f(y)−y:
(i) d(f(y))=d(y); (ii) fⁿ(y)=y+n·d(y) for all n≥0; (iii) d(y)≥0.

**Proof.** (i) d(f(y))=f(f(y))−f(y)=(2f(y)−y)−f(y)=d(y) by the composite identity.
(ii) Induction; d is constant along the orbit by (i) iterated, so f^{n+1}(y)=fⁿ(y)+d(y).
(iii) fⁿ(y)=y+n·d(y)>0 for all n forces d(y)≥0. ∎

Certified round 1.
