## Full proof

### 0. Setup, notation, conventions

A **board** is a finite multiset `B` of integers `≥ 1` (equality to `1` is allowed and arises after moves). An entry `> 1` is called **active**; an entry `= 1` is **inert**. A **move** picks two active entries `m > 1` and `n > 1` occupying *different positions*, and replaces them by
```
g = gcd(m,n)   and   ℓ = lcm(m,n)/gcd(m,n).
```
A move is **legal** on `B` iff `B` has at least two active entries (two integers `> 1` in different places). A **play** from `B` is a maximal sequence of boards `B = B_0 → B_1 → ⋯` where each `B_{t+1}` is obtained from `B_t` by one legal move, continued as long as a legal move exists (so a play is either infinite, or ends at a board with no legal move — we will show it is always finite). The initial board `B_0` of the problem has `2026` active entries.

For a prime `p`, `v_p(x)` is the `p`-adic valuation (`v_p(1)=0`). We write `Ω(x) = Σ_p v_p(x)` for the number of prime factors of `x` counted with multiplicity, so `Ω(1)=0` and `Ω` is completely additive: `Ω(xy)=Ω(x)+Ω(y)`.

For a board `B = {x_1,…,x_N}` define:
- `Ω_total(B) = Σ_{i} Ω(x_i) ∈ ℤ_{≥0}`;
- `K(B) = #{ i : x_i > 1 }` = number of active entries;
- the **measure** `Φ(B) = (Ω_total(B), K(B)) ∈ ℕ × ℕ`, ordered **lexicographically**: `(u,v) < (u',v')` iff `u < u'`, or (`u = u'` and `v < v'`).
- for each prime `p`, the **exponent multiset** `E_p(B) = { v_p(x_1), …, v_p(x_N) }` (a multiset of nonnegative integers), and `g_p(B) = gcd(E_p(B))`, the greatest common divisor of that multiset.

We use the standard gcd conventions on `ℤ_{≥0}`: `gcd(x,0)=x`, `gcd(0,0)=0`, and for a finite multiset `S` of nonnegative integers `gcd(S)` is the unique nonnegative generator of the subgroup of `ℤ` generated by `S` (equivalently, the largest `d ≥ 0` dividing every element, with the convention that every integer divides `0`; `gcd(∅)=0`). Only finitely many primes `p` have `g_p(B) > 0` (namely those dividing some active entry), so
```
μ(B) := ∏_p p^{ g_p(B) }
```
is a well-defined positive integer.

**Techniques used**, cited to `knowledge_base.md`:
- *Divisor analysis* (KB "Divisor analysis": gcd/lcm structure via prime valuations).
- *Invariant / monovariant* (KB "Invariants & monovariants" / "Invariant / monovariant"): a quantity monotone or conserved across moves, used both for termination and for the conserved value.
- *Strong / well-founded induction and infinite descent* (KB "Induction": "ordinary, strong, or structural … Infinite descent is induction's dual — no minimal counterexample can exist").
- *Casework / exhaustion* (KB "Casework / exhaustion").

### 1. Lemma 1 (primewise action of a move)

**Claim.** If a move replaces `m,n` (both `> 1`) by `g = gcd(m,n)` and `ℓ = lcm(m,n)/gcd(m,n)`, then for every prime `p`, writing `a = v_p(m)`, `b = v_p(n)`:
```
v_p(g) = min(a,b),        v_p(ℓ) = max(a,b) − min(a,b).
```
In particular `ℓ` is a positive integer and the move sends the exponent pair `(a,b)` at `p` to `(min(a,b), max(a,b) − min(a,b))`.

**Proof.** By unique factorization, `gcd(m,n) = ∏_q q^{min(v_q(m),v_q(n))}` and `lcm(m,n) = ∏_q q^{max(v_q(m),v_q(n))}` (KB *Divisor analysis*). Reading off the exponent of `p`: `v_p(g) = min(a,b)` and `v_p(lcm(m,n)) = max(a,b)`. Since `v_p` is completely additive and `ℓ · g = lcm(m,n)`,
```
v_p(ℓ) = v_p(lcm(m,n)) − v_p(g) = max(a,b) − min(a,b) ≥ 0.
```
Every valuation `v_p(ℓ)` is a nonnegative integer, so `ℓ = lcm(m,n)/gcd(m,n)` is indeed a positive integer, and the stated pair transformation holds. ∎

### 2. Lemma 2 (Ω-balance of a move)

**Claim.** With `m,n,g,ℓ` as above,
```
Ω(g) + Ω(ℓ) = Ω(m) + Ω(n) − Ω(gcd(m,n)) = Ω(m) + Ω(n) − Ω(g).
```

**Proof.** Sum Lemma 1 over all primes, using `Ω(x) = Σ_p v_p(x)` and writing `a_p = v_p(m)`, `b_p = v_p(n)`:
```
Ω(g)  = Σ_p min(a_p,b_p),
Ω(ℓ)  = Σ_p ( max(a_p,b_p) − min(a_p,b_p) ),
so  Ω(g) + Ω(ℓ) = Σ_p max(a_p,b_p).
```
Meanwhile `Ω(m) + Ω(n) = Σ_p (a_p + b_p) = Σ_p ( min(a_p,b_p) + max(a_p,b_p) )`. Subtracting,
```
Ω(m) + Ω(n) − ( Ω(g) + Ω(ℓ) ) = Σ_p min(a_p,b_p) = Ω(g) = Ω(gcd(m,n)),
```
which rearranges to the claim. ∎

### 3. Lemma 3 (Φ is a strictly decreasing well-founded monovariant; termination)

**Claim.** Every legal move strictly decreases `Φ` in the lexicographic order. Consequently every play is finite.

**Proof.** Let a legal move on board `B` replace active entries `m,n` by `g,ℓ`, producing `B'`; all other entries are unchanged. By Lemma 2, `Ω_total(B') − Ω_total(B) = (Ω(g)+Ω(ℓ)) − (Ω(m)+Ω(n)) = − Ω(g) ≤ 0`, so **`Ω_total` never increases**. We split on `gcd(m,n)` (this exhausts all moves, the two cases being disjoint by the value of `gcd(m,n)`).

*Case A: `gcd(m,n) > 1`.* Then `g = gcd(m,n) > 1`, so `Ω(g) ≥ 1`, giving `Ω_total(B') = Ω_total(B) − Ω(g) < Ω_total(B)`. The first coordinate strictly drops, so `Φ(B') < Φ(B)` regardless of `K`. (This case includes the subcase `m = n`: then `g = gcd(m,m)=m>1`, `ℓ = m/m = 1`, and indeed `Ω(g)=Ω(m)≥1`.)

*Case B: `gcd(m,n) = 1`.* Then `g = 1`, so `Ω(g)=0` and `Ω_total(B') = Ω_total(B)`: the first coordinate is unchanged. Also `ℓ = lcm(m,n)/1 = mn`, and since `m,n > 1` we have `mn > 1`. Thus of the two touched slots, one now holds `g = 1` (inert) and the other holds `ℓ = mn > 1` (active); before the move both were active. All untouched slots keep their status. Hence `K(B') = K(B) − 1 < K(B)`. Since the first coordinate is equal and the second strictly drops, `Φ(B') < Φ(B)`.

In both cases `Φ(B') < Φ(B)`.

**Well-foundedness of `(ℕ×ℕ, lex)`.** There is no infinite strictly `<`-decreasing sequence in `ℕ×ℕ`: in such a sequence the first coordinates are non-increasing naturals, so they are eventually constant (they can strictly drop only finitely often); on the tail where the first coordinate is constant the second coordinates strictly decrease, but a strictly decreasing sequence of naturals is finite — contradiction. (This is the well-order `ω²`.) Since every move strictly decreases `Φ`, a play `B_0 → B_1 → ⋯` yields a strictly decreasing sequence `Φ(B_0) > Φ(B_1) > ⋯`, which must therefore be finite. Hence every play is finite (KB *Induction*, infinite descent). ∎

### 4. Lemma 4 (non-collapse: outputs are never both 1)

**Claim.** For any move, at least one of the two outputs `g, ℓ` is `> 1`. Consequently, any board obtained by performing at least one move from any board has at least one active entry; in particular every board reachable from a board with `≥ 1` active entry again has `≥ 1` active entry.

**Proof.** The two outputs multiply to `g · ℓ = gcd(m,n) · lcm(m,n)/gcd(m,n) = lcm(m,n)`. Since `m > 1`, `lcm(m,n) ≥ m > 1`, so `g · ℓ > 1`. If both `g = 1` and `ℓ = 1` then `g·ℓ = 1`, contradicting `g·ℓ > 1`. Hence at least one output is `> 1`, i.e. active. That output sits on the board after the move (untouched slots are unchanged), so the resulting board has `K ≥ 1`. ∎

### 5. Lemma 5 (per-prime gcd invariant; μ is preserved by every move)

**Claim.** If `B'` is obtained from `B` by one move, then `g_p(B') = g_p(B)` for every prime `p`. Consequently `μ(B') = μ(B)`.

We first record two elementary sub-facts.

**(5a) Subtractive Euclid step.** For all integers `a,b ≥ 0`,
```
gcd( min(a,b), max(a,b) − min(a,b) ) = gcd(a,b).
```
*Proof.* By symmetry of both sides in `a,b`, assume `a ≤ b`, so `min = a`, `max − min = b − a`. We show `d | a` and `d | b` ⇔ `d | a` and `d | (b−a)`, for every integer `d ≥ 0` (including `d=0`, where "d | x" means `x=0`). If `d | a` and `d | b`, then `d | (b−a)`. Conversely if `d | a` and `d | (b−a)`, then `d | (b−a)+a = b`. So the common divisors of `{a,b}` are exactly those of `{a, b−a}`, whence the greatest common divisor (nonnegative generator) is the same: `gcd(a,b) = gcd(a, b−a) = gcd(min, max−min)`. The boundary cases are consistent with the conventions: if `a=b` then `min=a, max−min=0`, and `gcd(a,0)=a=gcd(a,a)`; if `a=0` then `min=0, max−min=b`, and `gcd(0,b)=b=gcd(0,b)`. ∎

**(5b) Multiset-gcd associativity.** For finite multisets `S,T` of nonnegative integers,
```
gcd( S ∪ T ) = gcd( gcd(S), gcd(T) ),
```
with `gcd(∅) = 0`.
*Proof.* For any integer `d ≥ 0`: `d` divides every element of `S ∪ T` ⇔ [`d` divides every element of `S`] and [`d` divides every element of `T`] ⇔ `d | gcd(S)` and `d | gcd(T)` (since `gcd(S)` is the nonnegative generator of the subgroup of `ℤ` generated by `S`, an integer divides all of `S` iff it divides `gcd(S)`) ⇔ `d | gcd(gcd(S), gcd(T))`. Two nonnegative integers with exactly the same set of divisors are equal (each divides the other), so `gcd(S∪T) = gcd(gcd(S),gcd(T))`. ∎

**Proof of Lemma 5.** Fix a prime `p`. Let the move touch entries `m,n` with `a = v_p(m)`, `b = v_p(n)`, and let `R` denote the multiset `E_p(B)` with the two entries `a,b` removed — i.e. the `p`-exponents of all untouched slots (these are literally unchanged by the move). By Lemma 1 the move replaces the pair `{a,b}` in `E_p` by `{ min(a,b), max(a,b) − min(a,b) }` and leaves `R` untouched. Hence
```
E_p(B)  = R ∪ {a, b},                         E_p(B') = R ∪ { min(a,b), max(a,b)−min(a,b) }.
```
Applying (5b) to each:
```
g_p(B)  = gcd( gcd(R), gcd(a,b) ),
g_p(B') = gcd( gcd(R), gcd( min(a,b), max(a,b)−min(a,b) ) ).
```
By (5a), `gcd(min(a,b), max(a,b)−min(a,b)) = gcd(a,b)`, so the two right-hand sides are identical: `g_p(B') = g_p(B)`. As `p` was arbitrary,
```
μ(B') = ∏_p p^{ g_p(B') } = ∏_p p^{ g_p(B) } = μ(B). ∎
```

### 6. Main theorem (strong induction closing both parts)

Call a board **admissible** if it has at least one active entry (`K(B) ≥ 1`). The problem's initial board is admissible (`K = 2026`), and by Lemma 4 every board reachable from an admissible board by moves is again admissible.

**Theorem `P(B)`.** *For every admissible board `B`:*
- *(a′) every play from `B` is finite and ends at a board with **exactly one** active entry; and*
- *(b′) that single surviving active entry equals `μ(B)` — the same value for every play from `B`.*

**Proof, by strong (well-founded) induction on `Φ(B)` in `(ℕ×ℕ, lex)`** (KB *Induction*: strong induction over a well-founded order; well-foundedness of `lex` on `ℕ²` was established in Lemma 3). The induction hypothesis (IH) is: `P(B'')` holds for every admissible board `B''` with `Φ(B'') < Φ(B)`. We prove `P(B)`. We split on whether `B` admits a legal move; the two cases are disjoint and exhaustive (KB *Casework*).

**Case 1: `B` has no legal move.** A legal move requires two active entries in different places. Since `B` is admissible (`K(B) ≥ 1`) but admits no legal move, it must have `K(B) ≤ 1`, hence exactly `K(B) = 1`. Let `e` be its unique active entry. The only play from `B` is the empty play (no moves are possible): it is finite and its terminal board is `B` itself, which has exactly one active entry — so (a′) holds. For (b′): fix a prime `p`. The multiset `E_p(B)` consists of `v_p(e)` (from the entry `e`) together with `v_p(1) = 0` for every inert entry. By repeated use of `gcd(x,0)=x`, `g_p(B) = gcd(v_p(e), 0, …, 0) = v_p(e)`. Therefore
```
μ(B) = ∏_p p^{ g_p(B) } = ∏_p p^{ v_p(e) } = e
```
(the prime factorization of `e`). So the survivor equals `μ(B)`, and there is only one play, so (b′) holds trivially. This case does not use the IH; it also covers the well-founded base (the `Φ`-minimal admissible boards, single primes, have no legal move).

**Case 2: `B` has a legal move** (equivalently `K(B) ≥ 2`). Let `π : B = B_0 → B_1 → ⋯ → B_t` be *any* play from `B`. Since a legal move exists on `B`, the play is non-empty (`t ≥ 1`): it performs a first move producing `B_1 =: B'`, and then continues. Two facts about `B'`:
- `B'` is admissible: `B'` is obtained from `B` by one move, so `K(B') ≥ 1` by Lemma 4.
- `Φ(B') < Φ(B)` by Lemma 3.

Hence the IH applies to `B'`, giving `P(B')`. Now observe that the remainder of `π`, namely `B_1 → B_2 → ⋯ → B_t`, is a maximal legal sequence starting at `B_1 = B'` (it ends where no move is possible, since `π` is a play), i.e. it *is* a play from `B'`. By `P(B')`:
- this tail is finite and ends (at `B_t`) with exactly one active entry — so `π`, which is one extra move prepended, is finite and `B_t` has exactly one active entry; establishing (a′) for `π`;
- that surviving entry equals `μ(B')`. By Lemma 5, `μ(B') = μ(B)`. So `π` terminates with survivor `μ(B)`.

Because `π` was an *arbitrary* play from `B` (the first move and all subsequent moves were unconstrained), we conclude: every play from `B` is finite, ends at exactly one active entry, and that entry equals `μ(B)` — independent of every choice made. This is precisely `P(B)`.

By strong induction, `P(B)` holds for all admissible boards `B`. ∎

### 7. Conclusion: parts (a) and (b)

Apply the Theorem to the problem's initial board `B_0` of `2026` integers, each `> 1` (so `B_0` is admissible). `P(B_0)` states that every play from `B_0` is finite and terminates at a board with exactly one active entry.

**(a)** Regardless of Confucius's choices, after finitely many moves the process reaches a board on which no move is possible, and that board has **exactly one** integer greater than `1`. (Termination is Lemma 3 / the finiteness in `P`; "exactly one survivor" is the "one active entry" conclusion — the `≤ 1` half from move-legality in Case 1, the `≥ 1` half from non-collapse, Lemma 4.)

**(b)** By `P(B_0)`, that surviving integer equals `μ(B_0)`, which depends only on the initial board `B_0` and not on the sequence of moves. Explicitly,
```
M = μ(B_0) = ∏_p p^{ g_p(B_0) },      where g_p(B_0) = gcd_{i=1}^{2026} v_p(x_i)
```
is the gcd of the `p`-adic valuations of the initial entries. Hence `M` does not depend on Confucius's choices. ∎

### 8. Verification on a concrete example

Take the board `B = {4, 6, 9}` (a small stand-in; the argument is size-independent). Its exponent gcds:
- `p = 2`: exponents `(2, 1, 0)`, `g_2 = gcd(2,1,0) = 1`;
- `p = 3`: exponents `(0, 1, 2)`, `g_3 = gcd(0,1,2) = 1`;
- other primes: `0`.
So `μ(B) = 2^1 · 3^1 = 6`. We check two genuinely different plays both terminate at `6`, illustrating order-independence (b):

*Play A.*
`{4,6,9}` → move on `(4,6)`: `gcd=2, ℓ=12/2=6` → `{2,6,9}`
→ move on `(6,9)`: `gcd=3, ℓ=18/3=6` → `{2,3,6}`
→ move on `(2,6)`: `gcd=2, ℓ=6/2=3` → `{3,2,3}`
→ move on `(3,3)`: `gcd=3, ℓ=3/3=1` → `{1,2,3}`
→ move on `(2,3)`: `gcd=1, ℓ=6/1=6` → `{1,1,6}`. Survivor `6`. ✓

*Play B.*
`{4,6,9}` → move on `(4,9)`: `gcd=1, ℓ=36/1=36` → `{1,6,36}`
→ move on `(6,36)`: `gcd=6, ℓ=36/6=6` → `{1,6,6}`
→ move on `(6,6)`: `gcd=6, ℓ=6/6=1` → `{1,1,6}`. Survivor `6`. ✓

Both plays end with the single survivor `M = 6 = μ(B)`, as the theorem predicts. (An exhaustive random search — thousands of random boards, each played to termination in tens of random move orders — reproduced "exactly one survivor, always equal to `∏_p p^{g_p}`" with no exception; this is a check, not part of the proof, which stands on Sections 1–7.)

## Promotable lemmas
- **Lemma 1 (primewise action).** A move `(m,n) ↦ (gcd, lcm/gcd)` acts on each prime's exponent pair by `(a,b) ↦ (min(a,b), max(a,b)−min(a,b))`. Proved in §1.
- **Lemma 3 (lex monovariant / termination).** `Φ=(Ω_total, K)` strictly lex-decreases on every legal move (`Ω_total` drops iff `gcd>1`; else `K` drops via the output `1`); `(ℕ²,lex)` is well-founded, so the process terminates. Proved in §3.
- **Lemma 4 (non-collapse).** The two outputs of a move multiply to `lcm(m,n) > 1`, so are never both `1`; hence `K ≥ 1` is preserved. Proved in §4.
- **Lemma 5 (per-prime gcd invariant).** `g_p(B) = gcd(E_p(B))` is invariant under every move (subtractive-Euclid identity `gcd(min,max−min)=gcd(a,b)` + multiset-gcd associativity `gcd(S∪T)=gcd(gcd S, gcd T)`); hence `μ(B)=∏_p p^{g_p(B)}` is a move-invariant. Proved in §5. (Shared engine with per-prime-gcd-invariant — certify once, importable by both.)
