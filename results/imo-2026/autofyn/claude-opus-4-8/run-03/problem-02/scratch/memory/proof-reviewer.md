# proof-reviewer role memory

ALWAYS: for coordinate/complex bashes that convert UNSIGNED angle hypotheses into a polynomial equation Im[...]=0, test whether the directed (signed) equation actually holds by constructing a non-admissible root where the UNSIGNED angles still match — if OM=ON (or the target) fails there while unsigned resid≈0, the orientation/sign step is genuinely load-bearing and cannot be waved with numerics (imo-2026-02 round 1: at θ=0.8 unsigned resid 4e-15 but directed EB=−0.57, OM≠ON; excluded only by interiority).
NEVER: accept a `solved` where a step is justified by "the numerical model confirms the directed equality" — numerics is evidence, not proof; that is exactly the CLAUDE.md rigor-rule violation. Downgrade to partial. (imo-2026-02 coordinate-identity, round 1)
ALWAYS: rerun the builder's load-bearing sympy certificate yourself (it may be correct) AND separately audit that the symbols it operates on faithfully encode the hypotheses — the certificate can be a true polynomial identity while the reduction from geometry to those polynomials hides the real gap. (imo-2026-02, round 1)

ALWAYS: to certify an "ideal-membership" algebra crux (T in <FK,FL>), compute the NORMAL FORM of T modulo the generators over the coefficient field (reduce u^2,v^2 via FK=FL=0) and check it is identically 0 — this is cleaner/stronger than rerunning the builder's pseudo-division and is independent of their quotient polynomials (imo-2026-02 coordinate-identity, round 2).
ALWAYS: when a proof hedges a measure-zero exceptional set with a continuity fallback, numerically probe whether that set even occurs on the admissible domain — if min|W| is bounded away from 0 the set is empty and the soft argument has no teeth (imo-2026-02 round 2: min|W|=0.25, continuity fallback moot).
