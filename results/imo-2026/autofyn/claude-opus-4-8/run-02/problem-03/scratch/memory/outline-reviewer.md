# outline-reviewer role memory

ALWAYS: for game/exchange-argument outlines, brute-force test the blanket exchange lemma AND the proposed adversary strategy separately — the claimed optimal strategy can be far from optimal even when the target VALUE is correct (imo-2026-03: "XY bisects the max n times" gave 0.75 vs true cap 4/7; "non-max cut never helps XY" false in general but true restricted to the extremal config, round 1).
NEVER: pass a "worst response = X" or "strategy Y achieves the cap" claim on plausibility — a verified maximin value only proves the bound exists, not that the sketched recipe attains it (round 1).

ALWAYS: when an induction "closes" a gap by reducing to an exchange/collapse lemma, check whether the IH actually applies to the POST-move object — often the move leaves the induction class (post-cut multiset is no longer W-shaped) and the real work is proving the lemma holds over the WHOLE reachable class, not the clean base object. Flag that as the load-bearing gap, don't let it read as done (imo-2026-03 telescoping cascade, round 2).

ALWAYS: for an amortized/phase mass-removal outline, check that the standing hypothesis is actually CONSUMED — if the claimed inequality would be FALSE on a boundary case (e.g. balanced inputs undershoot) that only the hypothesis excludes, a proof not using it is wrong; demand the explicit link, not a "bounds the gaps" hand-off (imo-2026-03 GAP-U f>s/D_b, round 3).
ALWAYS: a chamber/piecewise-affine descent that "terminates at a nice minimizer" hides its work in cross-tie constant-value walks — require an explicit no-cycle/strict-drop-per-visit argument for ties (degeneracy legs that drop the budget are the easy part); a bare "iterate" is not termination (imo-2026-03 GAP-L Step 4, round 3).

ALWAYS: when two "diverse hedge" approaches share a proven prefix and only diverge at the sole crux, check they diverge with DIFFERENT MECHANISMS at that crux — one may silently reuse the other's argument in its lemma list, making it a redundant copy. Force each to commit to its own distinct route and supply a mechanism, else it is not a hedge (imo-2026-03 block-recursion Step 4 muddled slide-vs-integrality, round 4).
NEVER: pass a "vertices are integer / config bottoms out at integer" claim on n=2,3 numerics alone — an integrality conjecture with no linear-algebra mechanism (why the integer-coefficient tie system forces integer not merely rational) is an unverified hand-off; within-piece ties give non-integer vertices ({4/3,..}), so any such claim MUST use the purely-cross-tie structure (imo-2026-03, round 4).

ALWAYS: run the outliner's mandated cheap-kill numerically BEFORE ranking a revise whose whole value is a NEW mechanism — round 5 the block-recursion "consecutive-ones TU one-shot" was refuted in one script (C1P is false on any cycle incidence matrix, and the residual vertices contain chorded cycles), so the revise added nothing; don't pass a plausible-sounding structural lemma on the outliner's say-so (round 5).
NEVER: accept a Φ/potential-maximality exclusion lemma whose stated mechanism is a compensated same-piece 3-shift {v,v,v}->{v+s,v+s,v-2s} — that is the refuted V-kink move (f=m+2|s|, strictly UP both ways), it LEAVES the minimizer set G and cannot witness a within-G potential increase; demand a perturbation that provably stays in G (round 5 Lemma Φ-EVEN).
ALWAYS: watch "μ even ⇒ integer" type leaps — even ≠ power of two; 2^k/6 is non-integer. A divisibility integrality claim needs μ restricted to {1,2,4,8,...}, and even-non-power-of-2 splits (μ≥4) are killed by the two-invisible-pairs P1 move (stays in G, raises Σx²), which IS a valid distinct mechanism (round 5).

ALWAYS: for a "prove f∈ℤ ⇒ f≥1" dual/integrality outline, check positivity separately — f∈ℤ + f≥0 only gives f≥0; f≠0 (excluding the all-even-blocks/bisect-all f=0 case, held off only by the cut budget b=n<m) is a CO-EQUAL gap the outline often asserts as "min is positive." Demand f odd (λ_0 odd) or an explicit budget-based positivity argument (imo-2026-03 dual-integer-certificate, round 6).
NEVER: pass an exclusion lemma whose mechanism is a "mass exchange BETWEEN two pieces" for imo-2026-03 — the domain is the PRODUCT of simplices ∏Δ_k, each piece's sub-pieces sum to its own fixed 2^k, so cross-piece transfer is INFEASIBLE; and a tie-PRESERVING redistribution needs a direction d with Ud=0, impossible since ker U={0} (S-core). The only feasible moves break a tie (cut-slide-derivative). "Same engine as S-core" cannot yield MORE than S-core already gave (ker U={0}) (round 7 concentration-exclusion step 2).

ALWAYS: to judge whether a DUAL reformulation genuinely bypasses a primal integrality wall, compare the lattice conditions — primal w∈ℤ needs det=±1 (unimodular); dual "s∈U^Tℤ" needs only gcd of maximal minors =1, strictly weaker. A det=−3 obstruction ([[1,2],[2,1]]) can still be dual-solvable for the specific s. So a dual route CAN be a real different wall, not a disguise — verify numerically on the known refuter configs (imo-2026-03, round 6).

ALWAYS: for a "remove an f-invisible block then apply IH to the complement" induction, numerically check BOTH invariants at once on the outliner's own example — f-invariance AND the complement being a genuine object in the IH's class. In imo-2026-03 round 8 the unified slug's peel was in provable tension: BF-preserving complement {2,4/3,1} had sum 13/3 (NOT a W_m refinement, IH doesn't apply); mass-conserving reattach {4,2,1} was a valid W_2 refinement but f jumped 5/3->3 (BF broken). This is the load-bearing gap, not a detail — flag it, don't let "f(P)=f(complement)>=1" read as done (round 8).
