ALWAYS: for adversarial "cut/discard" geometric games, check whether the game reduces to a
discrete additive/modular process (e.g. angles shifting by exact ±θ) — a mod-θ residue
invariant is often the cleanest necessity proof for "adversary escapes forever," and a
"build an exact multiple then fork down" chain is often the cleanest sufficiency
construction for the forceable set (round 1, imo-2026-04 Mulan's Triangle Game).

NEVER: trust a convergence/limiting argument as a finiteness proof in a "win in finitely
many steps, exact value" game — always look for an explicit forced move or discrete
invariant instead (round 1, imo-2026-04).

ALWAYS: when the crux corpus has no geometry cruxes (per crux_moves_documentation.md), grep
past_problems_database.json by keyword (e.g. "triangle", "cut") for weak analogues instead
of assuming the games-and-strategy subtopic alone will surface a match — but expect to
report "no strong analogue" for geometric adversarial games (round 1, imo-2026-04).
