## imo-2026-06 (lens: eventual-periodicity / finite-state route to a_{n+T}=a_n+L)

### Distinct openings (routes to the exact conclusion)

**Route A — "Stabilized prime set S + CRT residue state" (primary candidate).**
Conjecture (verified numerically, see below): there is a finite set of primes S (which primes actually end up mattering for divisibility going forward) that *stabilizes* after finitely many terms — i.e. past some point n0, every gcd(a_{n+1},a_i) for i≤n is witnessed by a prime in S, and moreover every a_n for n≥n0 has all its "load-bearing" prime factors inside S. Once S is fixed, let L = ∏_{p∈S} p (an lcm/product of the stabilized primes; empirically it equals plain the product since exponents/multiplicities don't matter for the gcd>1 condition). The state that determines the *entire future* of the sequence is then finite: it is essentially "which residues mod L have already been used / are still eligible," which lives in a space of size ≤ L (or 2^|S|, the subset-of-primes-used-per-residue). Since the process from that point on is a deterministic function of this finite state (the greedy rule "smallest integer above current term compatible with all needed residues" only needs to know, for each prime p∈S, whether a term ≡ (blocking residue) has occurred recently enough), pigeonhole on the (finite) state forces a repeat, hence periodicity of the increments with period T (a bound on the state space) and total increment L over one period.
Main gap this route must close: (1) prove S is truly finite and stabilizes (no new prime is *ever* load-bearing again after some point) — this is the crux fact, likely provable via a counting/density argument (route B) or via a direct "two small primes always available nearby" argument; (2) formalize the finite state precisely (naive "current residue mod L" is NOT enough by itself, because whether a candidate residue is admissible depends on the multiset of *all* previous terms' primes-in-S, not just the last one — need the right finite state, e.g. "for each p∈S, the residue class mod p of the terms since p's last appearance," which is itself bounded because p reappears with bounded gap).

**Route B — "Bounded gap via two-fixed-primes" density/counting argument, feeding pigeonhole.**
To get any finite-state argument off the ground you need a uniform bound on a_{n+1}-a_n (else the "state" needed to decide the next term could depend on unboundedly much history / unboundedly large numbers). Candidate mechanism: if 2 and 3 (or any two fixed primes p,q known to be load-bearing, i.e. dividing infinitely many terms) are both "in play," then among any run of ~2pq consecutive integers there is a multiple of p or of q past a_n, giving a candidate within a bounded window — this bounds the gap sequence uniformly. This is the analytic engine underlying Route A's finiteness; it doesn't by itself finish the periodicity proof but supplies the boundedness needed for pigeonhole. Gap: proving that *some* two primes are guaranteed to recur with bounded gaps from the very start (need to rule out the sequence perpetually introducing new large primes to satisfy gcd — i.e. rule out "escaping to infinity" scenarios where the greedy process keeps needing fresh primes).

**Route C — "Exact-from-n=1" via reversibility/bijectivity of the state map (closes the eventually-periodic vs exactly-periodic gap).**
The problem demands a_{n+T}=a_n+L for **every** n≥1, not just eventually — a real subtlety since naive pigeonhole on a forward-deterministic process only gives an eventual (tail) periodicity, with a possibly non-matching pre-period. Candidate fix: show the finite state map (once defined per Route A) is *injective* (a bijection on the finite state space) rather than merely a self-map — because the greedy process, run backward, is also uniquely reconstructible (the previous term is determined as the largest integer below a_n compatible with the same constraints) OR because the state truly only depends on data intrinsic to residues mod L that is already fully present from n=1 for many starting values. Empirically (see below) the periodicity relation held EXACTLY from n=1 in every example tested, with no pre-period at all — suggesting the "state" is already in its recurring regime immediately, not just eventually. This route's crux move directly parallels crux `aimo-0514`: "show a deterministic process is reversible so its state graph is a union of cycles, forcing the orbit to be purely periodic rather than eventually periodic" — i.e. prove the map on the finite state space is a bijection, which upgrades eventual periodicity to *exact* periodicity from the start. Gap: proving reversibility/injectivity of whatever finite-state map Route A ends up defining; alternatively, prove directly (by strong induction from n=1) that the periodic relation holds outright rather than arguing eventual-then-backward.

**Route D — Direct construction of T, L from the initial segment (no abstract pigeonhole).**
Rather than an abstract finite-state/pigeonhole existence argument, explicitly construct S = the set of primes dividing some early "complete" window of the sequence once every prime that will ever matter has appeared once (finite by Route B), set L = ∏S, and *directly verify* by strong induction that a_{n+T}=a_n+L holds for all n, where T is read off as the number of terms needed for the residues mod L to return to the exact same "admissibility pattern." This sidesteps having to abstractly prove a bijection (Route C) — instead it constructs the periodicity by an explicit induction: assume a_{k}=a_{k-T}+L for all k≤n (as an induction hypothesis reaching back the required window), and show the greedy rule forces a_{n+1}=a_{n+1-T}+L by exhibiting a_{n+1-T}+L as *the* smallest integer compatible with all of a_1,...,a_n — using that a_i and a_i+L behave identically mod every prime in S (since L is a multiple of every p∈S, translating by L preserves residues mod each p∈S) and that S captures all load-bearing primes for i in the relevant window. This is likely the cleanest way to actually finish rigorously — it converts the "why exactly, not just eventually" mystery into a clean induction once S, L, T are pinned down from a finite computation.

### Candidate technique(s)
- Pigeonhole on a finite state (residues mod a stabilized modulus L, or "last-occurrence" data per prime in S) to get eventual periodicity of the difference sequence — standard eventually-periodic-sequence technique (see knowledge_base.md "Order of an element, Fermat/Euler: periodicity ... eventual periodicity of products of a sequence mod m" and the linear-recurrence eventual-periodicity-mod-m entry).
- Reversibility/bijectivity-on-finite-state to upgrade eventual to exact periodicity (Route C).
- A density/covering argument (two fixed primes give bounded gaps) — related to Bertrand's-postulate-style "always a prime/multiple nearby" reasoning (knowledge_base.md Bertrand's postulate entry, adapted from primes to multiples of a fixed prime).
- Strong induction with an explicit translation-by-L argument (Route D) — the most concrete, likely to be preferred by the outliner since it avoids abstract state-space bijectivity claims.

### Cheap-kill candidates
- None that dispatch the problem outright, but a useful structural cheap fact: gcd(a_{n+1}, a_i) > 1 forces a_{n+1} composite direction — i.e. every a_n for n≥2 shares a prime factor with a_1, so all a_n (n≥2) lie in the union of prime-multiple classes of a_1's prime factors; this immediately shows any prime NOT dividing a_1 can only become "load bearing" via later co-occurrence, giving a starting handle on bounding S (not a full proof, but narrows the search: S must always contain at least one prime factor of a_1).
- Symmetry/reduction: a_1 can be assumed squarefree WLOG for the purposes of figuring out S (only the prime factors of a_1 matter, not multiplicities) — simplifies case analysis without loss of generality.

### Small-case / intuition notes (all CONJECTURE from numerical experiments, not proofs)
Computed via python (gcd greedy simulation, up to a few hundred terms per start):
- a_1=2,3,5,9,25 (prime or prime-power start): trivial, T=1, L=a_1's smallest prime factor value pattern — e.g. a_1=3 gives all multiples of 3 (T=1,L=3); a_1=9 also all multiples of 3 (T=1,L=3, since only rad(9)=3 matters).
- a_1=15 (=3·5): sequence is 15,18,20,24,30,36,40,42,45,48,50,54,60,66,70,72,75,78,80,84,... Empirically period T=8, L=30=2·3·5, **and the relation a_{n+8}=a_n+30 holds exactly for every n≥1 tested (n=1..~1990), with zero mismatches** — no pre-period needed. Strongly suggests Route C/D's "exact from n=1" is achievable, at least whenever the full prime set S is already "in play" essentially from the start.
- a_1=45 (=9·5): same qualitative pattern as 15 (T=8, L=30), confirming multiplicities of a_1 don't matter (only rad(a_1) matters) — supports the squarefree-WLOG cheap reduction above.
- a_1=105 (=3·5·7): checked to 400 terms; period found T=58, L=210=2·3·5·7, verified with **zero mismatches from n=1 to n=342** (i.e., a_{n+58}=a_n+210 holds for literally every n in range, not just eventually). Primes actually dividing terms of the sequence keep growing arbitrarily large (up to 257 seen within 400 terms) — but these large primes are always *co-factors* riding along with a small even/S-prime factor (e.g. a term = 2·p for large prime p), so they are never load-bearing for the gcd condition; this confirms the S-stabilization picture: S={2,3,5,7} is what matters, large prime companions are irrelevant noise.
- a_1=225 (=9·25=3²·5²): same T=8, L=30 as a_1=15 case, again exact from n=1 — consistent with squarefree-radical-only dependence.
- These experiments substantially de-risk Route A's central conjecture (finite stabilized S, L=∏S) and Route C/D's "exact from the start, no separate pre-period" phenomenon, but they are only 5-6 numeric examples up to a few hundred/thousand terms — NOT a proof, and larger/more adversarial starting values (e.g. a_1 with many prime factors, or a_1 chosen so 2 is excluded for a long stretch) should be probed further before the outliner commits to "exact from n=1 always" as a lemma to prove outright.
