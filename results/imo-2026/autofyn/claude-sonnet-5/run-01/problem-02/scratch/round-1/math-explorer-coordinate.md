## imo-2026-02

- Distinct openings:
  1. **Reduce OM=ON to a linear condition on O.** With B=(-1,0), C=(1,0), A=(p,q) (so M=(A+B)/2, N=(A+C)/2 automatically have the SAME y-coordinate q/2, since B,C are symmetric about the origin), OM²-ON² is linear in O and the claim collapses to **O_x = p/2** (O's x-coordinate equals half of A's x-coordinate), i.e. O lies on the fixed vertical line x=p/2 = perpendicular bisector of MN. This is a very clean scalar target for a coordinate bash: verified numerically to hold in every case tested (see below).
  2. **O as intersection of two perpendicular bisectors.** O is defined by |OA|=|OK|=|OL|, i.e. O = perp-bisector(A,K) ∩ perp-bisector(A,L), giving two explicit linear equations in O once K, L are known: 2O·(K−A)=|K|²−|A|², 2O·(L−A)=|L|²−|A|². The target equation 2O·(C−B)=|N|²−|M|² (equivalently O_x=p/2) should then be some explicit linear combination of these two equations, with the combination coefficients forced by the three angle conditions. This is the natural algebraic path once K, L have coordinates.
  3. **Reduce to a 1-parameter family via the KBA=ACL condition.** Set t=∠KBA=∠ACL. This single shared value puts K on a fixed ray from B (making angle t with BA, on the interior side) and L on a fixed ray from C (making angle t with CA, on the interior side); K and L then each have ONE remaining scalar degree of freedom (their distance r1, r2 along these rays). The two remaining angle conditions ∠LBK=∠LNC and ∠LCK=∠BMK are then 2 equations in the 2 unknowns (r1,r2) for FIXED t — a well-posed (generically 0-dimensional) system. So the actual configuration lives in a 1-parameter family indexed by t, and one can try to solve r1(t), r2(t) implicitly/algebraically and substitute into the O_x=p/2 target.
