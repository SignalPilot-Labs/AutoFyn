ALWAYS: when a coordinate-bash outline asks to prove a target identity holds "on the correct branch" of a system of angle-equality hypotheses, actually test raw ideal membership (Gröbner basis reduction of the target modulo the ideal of the RAW angle-equality polynomials, no containment inequalities) before trusting a resultant/elimination derivation — if the remainder is nonzero, the raw equalities alone do NOT force the target (spurious branches exist) and the containment/orientation inequalities are load-bearing, not just bookkeeping; report this explicitly as the open gap rather than asserting the identity from numerics alone (round 1, imo-2026-02).
NEVER: encode an "angle equality between two angles known to lie in (0,π)" as tan-equality (cross*dot=cross*dot) or cos-equality alone and assume it pins the exact branch without checking — even though the (0,π) range rules out the coarse mod-π/sign ambiguity in principle, the JOINT polynomial system in several unknowns can still have multiple real components only one of which is geometrically valid; verify via direct Gröbner ideal-membership test on a concrete rational example, not by argument alone (round 1, imo-2026-02).

ALWAYS: for an "OX=OY where O is a circumcenter of some triangle, X/Y are midpoints" target, try the classical median-length (Apollonius) identity OZ^2=(OX^2+OY^2)/2-XY^2/4 FIRST -- it reduces OM=ON to a single power-of-a-point identity (pow_G(B)-pow_G(C)=(AB^2-AC^2)/2) that is strictly cleaner than expanding the circumcenter via Cramer's rule/cross products; this reduction is itself a promotable, fully-general lemma worth writing up even when the remaining power identity isn't closed (round 1, imo-2026-02).
ALWAYS: before writing up a "clean" numeric pattern (e.g. an angle-sum identity like ∠AKB+∠A*KB=270°) as a lemma, test it on K,L chosen randomly WITHIN the containment region but NOT satisfying the problem's angle hypotheses — if the pattern only holds on hypothesis-satisfying configurations, it's likely equivalent to (or a disguised restatement of) the very target being proved, not an independent stepping stone; this catches circular "lemmas" before they're written up as progress (round 2, imo-2026-02).
NEVER: assume a one-sided angle-equality hypothesis (e.g. ∠LBK=∠LNC) is secretly the full spiral-similarity-center condition (which needs a SECOND matching angle pair, e.g. ∠LKB=∠LCN, plus a ratio) — test the second pair and the ratio numerically before building a synthetic argument on the spiral-similarity reading; it is often false even when the given single angle equality holds exactly (round 2, imo-2026-02).
ALWAYS: when a target angle formula involving a constructed point (e.g. angle-ABA*=theta+90-gamma) numerically depends on the base triangle's own angles, try substituting the base triangle's OWN circumcenter O' as reference (angle-O'BA=90-gamma is a free classical isosceles-triangle fact) -- it often reveals the "genuinely new content" as a clean invariant (e.g. angle-O'BA*=theta) that isolates what needs proving, even without closing the gap; then test whether it is a full spiral similarity (matching ratio too) and report that check explicitly rather than assuming angle equality implies full similarity (round 3, imo-2026-02).
NEVER spend the whole build budget chasing the numerically-clean upstream target formula itself when time is short -- bank a fully rigorous, gap-free write-up of the DOWNSTREAM reduction (e.g. "L1 and L2 imply A*B=A*C" with all sign/degenerate cases handled via continuity) even if the upstream formulas remain unproved; this is genuine, certifiable partial progress (round 3, imo-2026-02).
ALWAYS: when asked to build a "genuinely different framing" that reparametrizes the same free variables (e.g. pure-trig vs coordinate), actually push the derivation far enough to state the FINAL target identity in the new medium before declaring success on the "avoid coordinates" mandate — a sub-step (e.g. solving one hypothesis for a length as a closed-form quadratic root) can be genuinely new and valuable even when the final identity is later shown to require reintroducing frame-equivalent data (position of a point relative to two fixed vertices) and thus collapses to the same wall; report both facts honestly rather than either overclaiming full novelty or discarding the real partial gain (round 3, imo-2026-02).
ALWAYS: when a monotonicity/IVT argument's "sign convention" assumption fails past some point, look for the EXACT boundary as a closed-form root of a linear cross-product equation (point-on-fixed-ray meets fixed-direction-ray reduces to one linear equation in the free parameter) rather than treating the failure as requiring a fresh global inequality — often the failure point coincides exactly with a hypothesis boundary (e.g. "K inside angle LBA" failing), and characterizing it in closed form lets you replace a false global inequality with an unconditional per-case endpoint computation (round 3, imo-2026-02).
ALWAYS: when two candidate boundary parameters (e.g. r2max vs r2_signflip) could bind first, resolve the dichotomy by comparing the values of the SAME monotonic function (e.g. the polar angle) at both boundaries rather than comparing the raw parameters directly — monotonicity converts "which parameter is smaller" into "which function value is smaller," which is often a one-line comparison of two named fixed angles (round 3, imo-2026-02).
ALWAYS: when a prior round's directed-angle sign step is flagged as buggy ("by symmetry, same convention"), try computing the SECOND vertex's base direction (e.g. dir(C,A)) independently and elementarily from the coordinate frame (e.g. dir(C,A)=180°-γ since A-C has positive y-component) rather than patching the old symmetry argument — often this yields a strictly simpler, sign-determinate identity requiring NO case-split trichotomy at all, not just a fixed version of the old casework (round 4, imo-2026-02).
ALWAYS: when numerically re-verifying an angle identity via a custom root-finder (bisection/brentq or fsolve) near the domain boundary (θ→min(β,γ)), explicitly check containment of constructed points (K inside triangle BMC, L inside BNC) before trusting a "mismatch" as a real counterexample — spurious algebraic roots outside the geometric domain are common there and can look like a formula breaking down (round 4, imo-2026-02).
ALWAYS: when an outline claims a step is "trivial by definition" (e.g. "exact angle equality is a special case of equality mod π, so this direction needs no branch resolution"), actually check the SIGNS of the two signed angles feeding the mod-π claim before writing "trivial" — outlines routinely miss that the unsigned-angle hypothesis only pins magnitude, and a genuine sign-matching lemma (provable via the Sweep Lemma's cross-product computation) is usually needed and is exactly the kind of gap that turns a false "trivial" claim into real, citable content (round 4, imo-2026-02).
ALWAYS: when dividing a target polynomial by two auxiliary quadratics (Bézout/cofactor certificate) and sympy's plain field-division (sp.div) returns quotients with denominators (rational functions, not polynomials), multiply through by that denominator to get a genuine polynomial identity (Δ·T=P1·Q2+P2·Q1) rather than presenting rational-function "quotients" as the certificate — the cleared form is smaller, fully polynomial, and reveals the denominator's geometric meaning (often a leading-coefficient/nondegeneracy quantity worth proving nonzero anyway) (round 4, imo-2026-02).
NEVER: treat "D≠0" (non-collinearity of constructed points forming a named triangle in the problem statement, e.g. "the circumcentre of triangle AKL") as needing an independent algebraic derivation from the angle hypotheses by default — first check whether the problem statement's own phrasing ("triangle AKL") already presupposes it as well-posedness data; a resultant-elimination attempt to derive it algebraically can burn significant time with no payoff if the well-posedness reading is the intended and sufficient resolution (round 4, imo-2026-02).
ALWAYS: when claiming a trig polynomial identity (in cosθ,sinθ as free symbols) is "unconditional, no Pythagorean relation needed" as a stronger/cleaner variant, actually re-derive it treating cosθ,sinθ as truly independent symbols and check a spot-check point that deliberately violates cos²+sin²=1 BEFORE writing the claim — if it fails there (as it will whenever the true identity only holds mod the ideal ⟨cos²θ+sin²θ-1⟩), the honest and equally sufficient fix is to state the identity as conditional on the Pythagorean relation (always true for a genuine angle θ anyway) rather than the stronger false claim; verify via exact polynomial division by (cos²θ+sin²θ-1) for remainder 0, or substitute real sp.cos(theta)/sp.sin(theta) and simplify to 0 (round 4, imo-2026-02).
NEVER: define a rescaled variable like R:=r·|side| when the geometric point is P=B+r·u(θ) and d(θ):=|side|·u(θ) — check the algebra direction explicitly (P=B+r·u=B+(r/|side|)·d, so R=r/|side|, the RECIPROCAL) rather than assuming the more "natural-looking" R=r·|side|; a single inverted definition at the final assembly step of an otherwise-correct multi-lemma chain is exactly the kind of load-bearing error that survives many rounds unless explicitly numerically instantiated at the end (round 4, imo-2026-02).
