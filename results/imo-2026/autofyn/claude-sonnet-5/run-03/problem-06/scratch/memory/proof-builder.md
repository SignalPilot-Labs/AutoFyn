NEVER: assume "the greedy sequence needs to expand its active prime set Q because some past term isn't covered by Q" as the mechanism for prime recruitment in greedy-gcd-chain problems — the anchor a_1 already covers EVERY future term unconditionally (gcd(a_n,a_1)>1 for all n), so a "covering restoration" phase induction is never actually triggered; real recruitment of outside primes is driven by MINIMALITY (an outside prime yields a strictly smaller valid candidate via an incidental extra factor), not by necessity for existence. Check this distinction with a concrete computed example (e.g. a_1=35: a_3=42 beats the safe P-only fallback 45 only because 42=2·3·7 has an incidental factor 2 outside P={5,7}) before building a covering-based termination lemma (round 2, imo-2026-06, jacobsthal-covering-bound).
