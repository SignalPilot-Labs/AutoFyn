## imo-2026-06

### Distinct openings

1. **NEW proven lemma — the adjacent-pair link is bounded by rad(a_1), for ALL n, with no hypothesis.**
   Since `i=n` is *always* one of the covering constraints defining `a_{n+1}`, we get
   `gcd(a_n,a_{n+1}) > 1` for every `n`, and — this is the new observation —
   `gcd(a_n,a_{n+1}) = gcd(a_n, a_{n+1}-a_n) = gcd(a_n,d_n)` divides `d_n`
   (elementary: `gcd(x,x+d)=gcd(x,d)`, which divides `d`). Combined with the
   already-certified `bounded-gap-via-rad-a1.md` (`d_n ≤ R := rad(a_1)` for
   every `n`), this gives, **unconditionally and for every single `n`**:
   `gcd(a_n,a_{n+1}) ≤ R`, hence **every prime dividing `gcd(a_n,a_{n+1})` is
   ≤ R** — drawn from a fixed finite set of at most `π(R)` primes, the same
   set for all `n`, forever. I did not find this stated in any existing
   approach/lemma file (checked `pairwise-non-coprimality.md`,
   `bounded-gap-via-rad-a1.md`, and grepped all approaches for "consecutive" —
   none isolate this specific pairwise fact). One-line proof, fully rigorous,
   not just empirical — verified numerically too (below).
   - This gives a genuinely different *state* to track than `Q`/`S`/`L`: the
     **link sequence** `ℓ_n := gcd(a_n,a_{n+1})`, valued in the fixed finite
     alphabet `{1,...,R}` (in fact only divisors of integers `≤ R`), for
     *every* `n` from the start — no "eventually" needed, no transient.
   - **Sharpens/clarifies round 2's "distance-1" counterexample.** That
     counterexample (a large prime `p_0` landing at distance 1 from `a_n`,
     hence cheaply useful) **cannot involve `i=n` itself**: a candidate at
     distance 1 from `a_n` is `a_n+1`, and `gcd(a_n+1,a_n)=1` always (consecutive
     integers), which would outright violate the `i=n` constraint. So that
     counterexample necessarily concerns a *non-adjacent*, older index `i<n`,
     not the immediate predecessor. This means large "cheap" primes can only
     ever be recruited to satisfy compatibility with *older* history, never to
     satisfy the always-present `i=n` link — a real (if partial) structural
     restriction on where large-prime recruitment can occur, worth recording
     precisely for the next attempt at a monovariant.

2. **Tested and REFUTED extension: "Q (rad(L)) = set of all-time link primes."**
   Natural follow-up conjecture: since the link prime set
   `Λ_n := {p prime : p | gcd(a_i,a_{i+1}) for some i<n}` is monotone
   non-decreasing and confined to the *fixed* finite universe `{p ≤ R}` (not
   an ever-growing universe — this differs structurally from the `T_n`/type-set
   used in `monotonicity-obstruction.md`/`minimal-type-reduction.md`, whose
   universe is unbounded), `Λ_n` must stabilize after ≤ `π(R)` growth steps by
   a *trivial*, obstruction-free pigeonhole (bounded monotone sequence of
   subsets of a fixed finite set). I conjectured the stabilized `Λ` equals
   `rad(L)` (the eventual active set). **Checked numerically and this is
   FALSE**: for `a_1=35`, the true period is `T=34, L=210=2·3·5·7` (verified
   by direct simulation to 4000 terms), so `7 | L`, yet `7` **never once**
   divides `gcd(a_n,a_{n+1})` across all 3999 checked consecutive pairs — `7`
   is in `L` but never serves as the adjacent link. So `Λ` (link primes) is a
   strict subset of `rad(L)` in general; stabilization of `Λ` alone does not
   capture (or imply) full self-sufficiency. **Do not pursue "Q = link
   primes" as stated** — it is refuted by this concrete instance. The gap this
   leaves open: is there a still-useful relationship between `Λ` and `Q`
   (e.g. `Λ ⊆ Q` always, `Q` generated by `Λ` plus a bounded-size correction,
   or a generalized link notion — e.g. `gcd(a_i,a_j)` for bounded index gaps
   `j-i ≤ k` rather than just `j=i+1` — that does capture all of `Q`)? Not
   resolved this round; flagged as the natural next step from this opening.

3. **Why the bound does NOT trivially extend to non-adjacent pairs (explains
   the difficulty).** For `i<n`, `gcd(a_n,a_i) | (a_n-a_i)`, but `a_n-a_i` is
   only bounded by `(n-i)·R` (accumulated gap), which is *unbounded* as
   `n-i→∞`. So the same elementary trick gives no finite universe for
   non-adjacent links — consistent with, and explaining structurally, why
   round 2's residue-alignment counterexample (large prime, old index) is not
   contradicted by opening 1. This delineates precisely where the "primes
   must be small" phenomenon does and doesn't apply — a concrete boundary
   the outliner can use to scope any future monovariant attempt (a monovariant
   built only on adjacent-pair structure has a chance of being provably
   correct; one that implicitly needs a bound on non-adjacent-pair primes
   will likely re-hit the refuted prime-size-threshold mechanism).

4. **Crux-corpus opening for the *secondary* (prefix-extension) gap, not the
   central one.** `past_crux_moves_database.json`, `problem_id=aimo-0680`
   (IMO-SL 2015 N4, `domain=number_theory`, `subtopic=divisibility-and-gcd`
   / `size-bounding-and-descent`) has a crux move genuinely analogous in
   *shape* to the open prefix-extension gap: "Upgrade a relation known only
   along an infinite index subset to all indices: for a fixed target index,
   pick a subset index far enough that both candidate quantities are
   divisible by their gap while their difference is smaller than the gap,
   forcing the difference to vanish" (`how_used`: for fixed `j`, choose `y`
   in the known-good index set with `y-j` exceeding
   `|f^j(a_x)-(a_x+jT_x)|`; both `f^y(a_x)-f^j(a_x)` and `(y-j)T_x` are
   divisible by `y-j`, and their difference is smaller than `y-j` in absolute
   value, forcing it to be exactly `0`). This is a **"divisible + bounded ⟹
   zero"** finishing technique, structurally *different* from the
   pigeonhole-on-a-growing-state family that `monotonicity-obstruction.md`
   proves cannot close the prefix-extension gap — it does not require any
   state to literally recur at index 1, only a boundedness estimate plus a
   divisibility relation between spacing quantities at different indices.
   **Caveat (do not over-claim):** in aimo-0680 the divisibility
   `(y-j) | [f^y(a_x)-f^j(a_x)]` comes for free from the problem's hypothesis
   that `f^n(m)-m` is divisible by `n` for all `m,n` — imo-2026-06 has no such
   given iteration structure, so this move cannot be imported verbatim; the
   outliner would need to manufacture an analogous divisibility fact for
   `(a_n)` from scratch (e.g. from the periodicity-of-residue-class-union
   structure once Hypothesis SS is granted) before this technique becomes
   usable. Flagging it as a *candidate finishing technique* for the secondary
   gap, not a solved step.

### Small-case / intuition notes (labeled conjecture where not proven)
- **Proven, not conjecture**: `gcd(a_n,a_{n+1}) ≤ rad(a_1)` for every `n≥1`,
  and its prime factors lie in the fixed finite set `{p ≤ rad(a_1)}`.
  Verified numerically too: for `a_1 ∈ {15,35,65,105,231,91}` over hundreds
  to thousands of terms, the set of primes ever dividing a consecutive gcd is
  small and stable (`{2,3}` for 15 and 105, `{2,3,5}` for 35 and 65, `{3}`
  for 231, `{2,3,5,7}` for 91) — well below `R` in every case, though the
  proof only guarantees `≤ R`, not this tighter empirical bound.
- **Conjecture (unverified beyond examples above, and refuted as an exact
  identity)**: the adjacent-link prime set is *related to but not equal to*
  `rad(L)` — it seems to always be a *subset*, in the four checked cases
  (`{2,3}⊆{2,3,5,7}=rad(210)` for `a_1=105` needs checking — actually
  `105=3·5·7`, its true `L` wasn't computed this round, only `35`'s was
  confirmed as `L=210`). Recommend next round explicitly compute `(T,L)` for
  several more `a_1` and check `Λ ⊆ rad(L)` (not `Λ = rad(L)`) as a more
  modest, possibly-true structural claim worth formalizing.
- `a_1=91=7·13` recruits `{2,3,5,7}` as link primes — `13` (a genuine prime
  of `a_1` itself) is *not* among them, consistent with round 2's finding
  that greedy can permanently drop one of `a_1`'s own primes.
