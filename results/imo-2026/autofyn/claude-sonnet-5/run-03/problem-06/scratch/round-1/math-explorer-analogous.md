- Distinct openings (from the analogous-problem lens):
  1. **"Table" / orbit-decomposition framing (via aimo-0680, IMO-SL 2015 N4).** That problem proves an almost identical *conclusion shape* — "f(n)-n is eventually periodic" for an injective f:Z+→Z+ with (i) n | f^n(m)-m and (ii) finite complement of the image — using: injectivity from a divisibility-forces-equality trick, decomposition of Z+ into finitely many disjoint orbits ("rows of a Table"), a density/pigeonhole argument to find a "dense row" that must itself be an AP, and finally a **divisibility-forces-vanishing** argument (`(y-j) | two quantities whose difference has absolute value < y-j ⟹ difference = 0`) to nail down the AP step exactly. Adapt: view a_n's own structure (not an arbitrary f, but the specific greedy gcd sequence) through an analogous lens — e.g. track, for each "surviving" prime p that the sequence uses infinitely often, the arithmetic-progression sub-behavior of a_n along residues mod small primes, and try the same "bound a difference below a divisor that must divide it ⟹ difference is 0" finishing trick to nail T, L once a candidate periodic block is isolated.
  2. **Direct prime-covering framing (via aimo-0224, aimo-0447).** Both cruxes show how to turn "gcd(x,y)>1 for a whole family of pairs" into "every pair is jointly covered by an assigned prime" (aimo-0447: literal grid of primes covering cells; aimo-0224: assign each index a finite prime-subset so gcd>1 ⟺ subsets intersect). Adapt: assign to each a_n the (finite) set of primes dividing it; the greedy rule forces a_n's prime set to intersect every a_i's prime set for i≤n. Since only finitely many "small" primes can be reused indefinitely (an infinite antichain of coprime numbers would violate the pairwise-gcd>1 requirement — cf. aimo-0421's pigeonhole-on-finite-divisor-values argument), eventually only a bounded set of primes {p_1,...,p_k} is "active," and once the sequence is forced to always share one of these primes, the greedy choice becomes a periodic/quasi-periodic residue-avoidance sieve mod P = product (or lcm of ranges) of {p_1,...,p_k}. This is the direction to build the actual periodicity constants T, L from (T tied to the residues mod some period built from the finitely many surviving primes, L the sum of gaps over one period).
  3. **Finite-primes pigeonhole framing (via aimo-0421).** aimo-0421's core crux — "a gcd with a fixed element takes only finitely many values, so pigeonhole over an infinite family forces repeats/stabilization" — is the right tool to prove the *foundational structural fact* this problem needs first: only finitely many distinct primes can ever be "freshly introduced" into the sequence (i.e. a_n cannot forever need a genuinely new prime factor to beat every earlier a_i, because the greedy process would otherwise be forced to jump by unboundedly large steps — this needs a Bertrand-postulate/prime-gap style growth argument, cf. KB Bertrand's postulate entry, to rule out "always needs a fresh huge prime").

- Small-case / intuition notes (numerically verified with a direct Python simulation of the greedy rule, gcd via math.gcd — this is evidence/conjecture only, not a proof):
  - Starting at a prime-power-only seed (a_1 ∈ {2,3,5,7,9}, i.e. only ever needing one prime factor), the greedy process degenerates trivially: a_n = a_1 · n for all n (every successive smallest number sharing that one prime works), i.e. T=1, L=a_1 — periodicity holds from n=1 with no transient. This is a strict special case, not representative of the general problem (the problem's hypothesis is presumably meant for sequences that end up needing several primes, or holds for every valid greedy sequence including these degenerate ones — worth flagging to the outliner to make sure the general proof also covers/subsumes this trivial case correctly).
  - Starting at a_1=15 (=3·5, needs two primes at once): the difference sequence a_{n+1}-a_n becomes exactly periodic with period T=8 and per-period sum L=30, and this periodicity kicks in almost immediately (by n=2), i.e. the "transient" before periodicity is very short in this example.
  - Starting at a_1=105 (=3·5·7, needs three primes): difference sequence becomes exactly periodic with period T=58 and per-period sum L=106, again with a short transient (verified out to 200 terms with the pattern repeating exactly 3 times).
  - These numerics strongly support the problem's claim (as expected — it is stated as a fact to prove) and additionally suggest: (1) the eventual period T and shift L both appear tied to the finite set of primes the sequence ends up perpetually reusing (as opposed to a period growing without bound or depending delicately on arbitrarily large primes), and (2) the "settling into periodicity" transient looks short/explicit in these small examples, which may mean a workable proof strategy is to *explicitly* identify the (finite, bounded) set of primes in play early, rather than relying purely on an abstract density/pigeonhole existence argument (as aimo-0680 does) — a genuinely different, more constructive framing than the Table method, worth flagging as an alternative route if the abstract pigeonhole method proves hard to adapt.
