## imo-2026-05

- Distinct openings:
  1. **The x=f(y) collapse (key substitution).** Plugging x=f(y) into the original chain makes BOTH outer bounds (QM and GM of x,f(y)) collapse to the same value f(y), since x=f(y) means the pair (x,f(y)) is literally (f(y),f(y)) — QM=GM=f(y) automatically. This forces the middle term to equal that value too, turning the two *inequalities* into one *exact identity*: **f(f(y)) = 2f(y) − y for all y>0.** (Rigorously derived: apply the left inequality at x=f(y) to get f(f(y))+y ≤ 2f(y), and the right inequality at x=f(y) to get f(f(y))+y ≥ 2f(y); together they force equality.) This is the crux substitution for this lens — it converts an inequality problem into a genuine FE and is not conjectural, it's proved for any solution.
  2. **Orbit / arithmetic-progression analysis.** The identity f(f(y))=2f(y)−y says the forward orbit y, f(y), f(f(y)), ... has *constant* increments d=f(y)−y (an arithmetic progression). Since the orbit must stay in R_{>0} forever, d<0 is impossible (would eventually go negative), so **f(y) ≥ y for all y** — this is a clean, rigorous pointwise bound, not just conjecture.
  3. **Injectivity for free.** From the identity alone: if f(a)=f(b), apply the identity at a and at b: f(f(a))=2f(a)−a, f(f(b))=2f(b)−b=2f(a)−b. But f(a)=f(b) ⟹ f(f(a))=f(f(b)), so 2f(a)−a=2f(a)−b ⟹ a=b. **f is injective**, proved directly from the identity, no separate argument needed.
  4. **The "found family" opening — check f(x)=x+c for constant c≥0.** Setting a=x, b=f(y)=y+c, the middle term (f(x)+y)/2 = (x+c+y)/2 = (a+b)/2 exactly (since f(x)−x = f(y)−y = c always). So the whole chain becomes literally QM(a,b) ≥ AM(a,b) ≥ GM(a,b), the standard power-mean inequality — **always true**. So **f(x)=x+c is a valid solution for every constant c ≥ 0** (need c≥0 so f(x)=x+c>0 for all x>0). I verified this both algebraically and numerically (2000 random (x,y) pairs per c ∈ {0, 0.5, 1, 3.7}, all pass). This is important: the answer is almost certainly NOT just f(x)=x — it's the whole family f(x) = x + c, c ≥ 0. Any approach assuming uniqueness of f(x)=x alone will be wrong; the outliner must target the characterization {f(x)=x+c : c≥0}.
  5. **The remaining gap: ruling out non-affine h.** Let h(y)=f(y)−y ≥ 0. From the identity, h(f(y)) = h(y) (h is constant along each orbit), but this alone only pins h constant *within* an orbit, not globally across different starting points. The real content of the problem is to show h is the SAME constant for all y (not just orbit-wise), using the original inequality for x,y drawn from *different* orbits. I tested several natural substitutions (x,y consecutive on the same orbit; x=y; asymptotic x→∞ or y→∞ along one orbit) and none produced a contradiction for non-constant h — they all reduce to trivial true statements (c²≥0 type). This suggests the real proof needs a genuinely cross-orbit substitution or a monotonicity/continuity-free density argument — likely the hardest remaining step and where the outliner should focus.
