ALWAYS: for geometric "cut and discard" game problems, first reduce to pure angle/length algebra (angles sum, cut point parametrized continuously) before searching for invariants — the reduction itself often reveals a clean supplementary/complementary-sum fact that drives both directions of the characterization (round 1, imo-2026-04).
ALWAYS: when a threshold value (e.g. θ=90°) appears as a "boundary," check algebraically whether it's the UNIQUE solution to the "force both branches" equation system — this both proves the boundary is exact and rules out nearby dead-end conjectures (round 1, imo-2026-04).
NEVER: assume a defender's invariant that works on one side of a threshold (e.g. θ>90° defense) automatically mirrors to the other side (θ<90°) — verify with quick random-cut simulation before conjecturing symmetry; asymmetric threshold problems often break symmetry exactly at the boundary (round 1, imo-2026-04).
ALWAYS: for triangle-cutting/angle games, derive the exact child-angle formulas via law-of-straight-angle at the cut point first (child1={B,t,180-B-t}, child2={C,A-t,B+t} when cutting vertex A with split t) — this immediately reveals "double-win" (both children hit target) conditions algebraically instead of guessing (round 1, imo-2026-04).
ALWAYS: when a problem has a real-valued/continuous parameter but the target answer is a clean characterization, run an exact integer-grid fixed-point/BFS solver (not a depth-limited minimax, which gives false negatives from the "treat unresolved as loss" default) over many target values to spot the pattern — it can reveal exact number-theoretic characterizations (e.g. "θ works iff θ|180") cheaply before any proof attempt (round 1, imo-2026-04).
NEVER: trust a depth-limited minimax's "False" outcome as evidence of a genuine loss — it conflates "not yet found within depth" with "provably unwinnable"; only its "True" outcomes are reliable evidence. Use monotone fixed-point BFS instead when the game has no forced draws/cycles issue (round 1, imo-2026-04).
