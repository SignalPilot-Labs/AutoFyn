### 1. The exact reduction of the goal (fully rigorous, no gap)

Place `A` at the origin. Then `M = B/2`, `N = C/2` (since `M,N` are the
midpoints of `AB, AC`). For any point `O`, expand squared norms via
`|O−X|² = |O|² − 2 O·X + |X|²`:

`OM² − ON² = (|O|² − 2O·M + |M|²) − (|O|² − 2O·N + |N|²) = 2O·(N−M) + |M|²−|N|².`

Since `N − M = (C−B)/2` and `|M|²−|N|² = (|B|²−|C|²)/4`, this gives, with no
hypothesis used yet,

`OM² − ON² = O·(C−B) + (|B|²−|C|²)/4.`  (∗)

Hence **`OM = ON` if and only if `O·(C−B) = (|C|²−|B|²)/4`.** This is an exact
equivalence (given `OM,ON ≥ 0`, `OM²=ON² ⟺ OM=ON`), so the whole problem
reduces to proving this single linear (dot-product) identity for `O` = the
circumcenter of `A,K,L`, where `A,K,L,B,C` satisfy the problem's hypotheses.
This matches and rigorously re-derives the target flagged by this round's
math-explorer.

### 2. Circumcenter of `A, K, L` in closed form (fully rigorous, no gap)

With `A` at the origin, `O` is equidistant from `A,K,L`, so `|O|=|O-K|=|O-L|`
gives, by the same expansion as above,

`O·K = |K|²/2`,  `O·L = |L|²/2`.

This is a 2×2 linear system in the coordinates of `O` (as long as `K,L` are
not collinear with `A`, which holds since `A,K,L` are a genuine, non-
degenerate triangle — they have a circumcenter by hypothesis). By Cramer's
rule,

`O = ( |K|² (L×ŷ or) ... )` — explicitly, writing `K=(k1,k2), L=(l1,l2)`,
`det = k1 l2 − k2 l1 ≠ 0`, and

`O_x = (|K|² l2 − |L|² k2) / (2 det)`,  `O_y = (k1 |L|² − l1 |K|²) / (2 det)`.

This is a fully explicit rational function of the coordinates of `K, L`
(matching the outline's step 4), and its derivation has no gap: it is
exactly the statement that `O` is the unique solution of the two linear
equidistance equations `OA=OK`, `OA=OL`.

### 3. A structural symmetry of the whole hypothesis set (fully rigorous, new lemma this round)

**Lemma (σ-symmetry).** Let `σ` be the relabeling `B↔C, K↔L, M↔N` (fixing
`A`). If `(A,B,C,K,L,M,N)` satisfies every hypothesis of the problem, then so
does its image under `σ`, namely `(A,C,B,L,K,N,M)` — i.e. `(L,K)` satisfies
the same five hypotheses (three angle equalities, `L` inside `∠KCA`, `K`
inside `∠LBA`... more precisely, relative to the swapped triangle roles) with
`B,C` and `M,N` exchanged. Moreover the conclusion `OM=ON` is literally
carried to itself by `σ` (it becomes `ON=OM`).

*Proof.* Check each hypothesis clause is carried to another (or the same)
clause of the hypothesis list:

- **Containment `K ∈ △BMC`.** Since `σ` sends `K↦L, B↦C, M↦N, C↦B`, this
  clause is sent to `L ∈ △CNB = △BNC` — exactly the hypothesis
  "`L` inside `△BNC`" (triangles `△CNB` and `△BNC` are the same set of three
  points, so the same triangle). ✓ matches a given hypothesis.
- **Containment `L ∈ △BNC`.** Symmetrically sent to `K ∈ △CMB = △BMC`. ✓
  matches the other given hypothesis.
- **`K` inside `∠LBA`.** `σ` sends `K↦L, L↦K, B↦C`, `A↦A`, giving
  `L` inside `∠KCA`. Since `∠KCA = ∠ACK` (angle notation is symmetric in its
  two rays), this is exactly "`L` inside `∠ACK`" — the given hypothesis. ✓
- **`L` inside `∠ACK`.** Symmetrically sent to `K` inside `∠ABL = ∠LBA` —
  the given hypothesis. ✓
- **`∠KBA = ∠ACL`.** `σ` sends `K↦L,B↦C,A↦A,C↦B,L↦K`, giving
  `∠LCA = ∠ABK`. Since `∠LCA=∠ACL` and `∠ABK=∠KBA` (angle notation
  symmetric), this reads `∠ACL = ∠KBA`, the *same equation* as the
  hypothesis (equality is a symmetric relation). ✓ self-image.
- **`∠LBK = ∠LNC`.** `σ` sends `L↦K,B↦C,K↦L,N↦M,C↦B`, giving
  `∠KCL = ∠KMB`. Since `∠KCL=∠LCK` and `∠KMB=∠BMK`, this reads
  `∠LCK = ∠BMK` — exactly the *third* hypothesis. ✓
- **`∠LCK = ∠BMK`.** By the symmetric computation, `σ` sends this to
  `∠LBK = ∠LNC` — the *second* hypothesis. ✓ (`σ` swaps hypotheses 2 and 3.)

So `σ` permutes the hypothesis list into itself (fixing hypothesis 1 and
swapping hypotheses 2,3, and likewise permuting the four containment
clauses in pairs). Hence if `(K,L)` satisfies all hypotheses relative to
`(A,B,C)`, then `(L,K)` satisfies all hypotheses relative to `(A,C,B)`.

Finally, the circumcenter of the (unordered) point set `{A,K,L}` is the same
point whether we call it "circumcenter of `A,K,L`" or "circumcenter of
`A,L,K`" — the point `O` itself is unchanged by relabeling `K,L`. Under `σ`,
`M↔N`, so the conclusion `OM=ON` is sent to `ON=OM`, the same statement. ∎

*Use of this lemma.* It shows the problem has a genuine built-in symmetry:
proving the target identity `O·(C−B)=(|C|²−|B|²)/4` for one "half" of the
construction (say, expressing things via the parameter at vertex `B`) forces
the same identity in the swapped labeling, which is a useful consistency
check and can halve casework in the final write-up (e.g. it is enough to
verify the mechanism of cancellation for one of the two symmetric
sub-equations, the other follows by applying `σ`). It does **not** by itself
collapse the free parameter or complete the proof.

### 4. Explicit rotation parametrization of K, L from hypothesis 1 (rigorous derivation, sign convention justified from the configuration)

Normalize by a similarity of the plane (translation + rotation + scaling —
valid since `OM=ON` is invariant under similarities applied to the whole
configuration) so that `A=(0,0)`, `B=(1,0)`, and `C=(a,c)` with `c>0` (i.e.
the triangle `ABC` is oriented so that going `A→B→C` is counterclockwise;
this is a WLOG choice of orientation, the other orientation being the
mirror image with all angle conditions reflected identically).

Let `β = ∠KBA ( = ∠ACL` by hypothesis 1`)`. The ray `BA` has direction
`u = A−B = (−1,0)` (already a unit vector). Because `K` lies inside
`△BMC` and inside `∠LBA` — both of which place `K` on the same side of line
`AB` as `C` (the interior of the triangle) — the ray `BK` is obtained from
ray `BA` by rotating **into the triangle**, i.e. towards `C`. Writing
`R(θ)` for the counterclockwise rotation matrix by angle `θ`, the ray
towards the interior at `B` (which sweeps from `BA` towards `BC` as the
rotation angle increases from `0` at `BA`, since `A→B→C` counterclockwise
means the interior angle at `B` opens by increasing the angle in the
*clockwise* sense from `BA`) is `R(−β) u`. Concretely
`R(−β)(−1,0)^T = (−cosβ, sinβ)`, which indeed has positive second
coordinate for `0<β<π`, i.e. points towards the `c>0` half-plane — the
triangle interior. So

`K = B + t1 (−cosβ, sinβ)`,  for some `t1 = BK > 0`.

Symmetrically, at `C` the ray `CA` has direction `w = (A−C)/|A−C| = (−a,−c)/r`
with `r=|AC|=√(a²+c²)`, and `L` lies inside `△BNC` and inside `∠ACK`, again

rotating **counterclockwise** by `β` (the mirror sense to `B`, consistent
with the `σ`-symmetry of §3, which exchanges the two vertices and reverses
this rotation sense). So

`L = C + t2 · R(β)w`,  for some `t2 = CL > 0`,

where `R(β)w = ( (−a cosβ + c sinβ)/r,\ (−a sinβ − c cosβ)/r )`.

*Where this leaves 2 unknowns.* Given `β`, hypothesis 1 alone does not pin

### 6. Why σ-symmetry does not simply halve this elimination (new finding, round 2)

The outline proposed using the certified σ-symmetry lemma (swap `B↔C, K↔L,
M↔N`) to obtain the "`t2`-side" elimination for free from the "`t1`-side"
one. This was checked carefully and **does not work as literally stated**:
the rotation parametrization of §4 is written in a coordinate frame that
already breaks the σ-symmetry — it fixes `A=(0,0), B=(1,0)`, so `B` is
distinguished from `C=(a,c)` by the choice of similarity normalization
itself. Applying σ (which swaps `B,C`) sends this frame to a *different*
one (`A=0, C=(1,0), B=(a',c')`, i.e. a different rotation of the same
triangle), not to the same `(t1,t2,s,cc,R,a,c)`-system with `t1,t2` and
`poly2,poly3` merely swapped. Concretely: `poly2`'s dependence on `R` (up to
degree 4) and `poly3`'s complete independence of `R` are *not* symmetric
under `t1↔t2` in the current coordinates — a genuine asymmetry — so one
cannot simply "invoke σ" to skip deriving `poly2`'s role in the elimination.
**Correct fix (not completed this round):** re-run the entire §4 rotation
parametrization in the frame `A=0, C=(1,0), B=(a',c')` (i.e. apply the
actual similarity that σ induces) to get a genuinely σ-conjugate system, and
only then match the two eliminations term-by-term. This is extra work, not
a free saving, and was not carried out given the time budget; the
computations in §5 and §7 were therefore done directly (without a symmetry
shortcut), on the full system.

## Promotable lemmas

- **Vector reduction of `OM=ON` (§1).** For any triangle `ABC` with `M,N`
  midpoints of `AB,AC` and any point `O`, `OM=ON \iff O\cdot(C-B) =
  (|C|^2-|B|^2)/4` when `A` is placed at the origin. Proved in full by direct
  expansion of squared norms (polarization identity), no hypothesis-specific
  content — reusable by any other approach to this problem (e.g. a synthetic
  approach could instead aim to show `O` lies on the perpendicular bisector
  of `MN` directly, and this lemma converts that geometric statement into
  the same linear algebraic target used here).
- **σ-symmetry of the hypothesis set (§3).** The relabeling `B\leftrightarrow
  C, K\leftrightarrow L, M\leftrightarrow N` (fixing `A`) carries every
  hypothesis of the problem to another hypothesis of the problem (fixing
  hypothesis 1, swapping hypotheses 2 and 3, and swapping the four
  containment clauses in pairs), and carries the conclusion `OM=ON` to
  itself. Proved in full by direct case check of every clause. Reusable by
  any approach (synthetic or coordinate) to halve the casework needed, or as
  a sanity check on any proposed intermediate lemma (a correct intermediate
  claim about `K,B,M` should have a "mirror" claim about `L,C,N` that is
  automatically also true by this symmetry).
- **Explicit low-degree constraint/target polynomials (§5, round 2).** With
  `A=0,B=(1,0),C=(a,c)` and the §4 rotation parametrization, the three
  polynomial constraints reduce to explicit, fully-symbolic-in-`(a,c)`
  polynomials of modest degree: `poly2` (deg 2 in `t1`, 4 in `t2`, 4 in `R`,
  113 monomials), `poly3` (deg 4 in `t1`, 2 in `t2`, **0 in `R`**, 57
  monomials — the `R`-independence of `poly3` is a genuinely useful
  structural fact), and the target `num` (deg 2 in `t1,t2,R`, only 54
  monomials, explicit form given in §5). Reusable directly by any future
  attempt at this exact elimination (no need to re-derive).
- **Negative result: σ-symmetry does not conjugate the §4 rotation frame
  (§6, round 2).** The coordinate frame `A=0,B=(1,0),C=(a,c)` used in the
  rotation parametrization is not itself σ-invariant (σ swaps `B,C`, which
  changes which point sits on the positive x-axis), so σ cannot be used to
  "get the `t2`-side elimination for free" from a `t1`-side computation
  without first re-deriving the parametrization in the σ-conjugate frame.
  Useful for any future approach considering the same symmetry shortcut.
- **Negative result: naive "reduce mod one constraint, ignore the other as a
  variable" is an invalid ideal-membership test (§7, round 2).** For a
  2-variable elimination problem (here: variables `t1,t2`), reducing a
  target modulo one constraint polynomial `poly2` purely as a polynomial in
  `t1` (treating the second variable `t2` as a free coefficient-field
  parameter) does not correctly test membership in `ideal(poly2,poly3)`,
  because `k[t1]` over the field `k=ℚ(t2,\ldots)` is a PID in which
  `gcd(poly2,poly3)=1` generically (no common `t1`-root exists for generic
  `t2`) — the correct test requires a genuine multivariate elimination
  (Gröbner basis, or a resultant chain that keeps `t2` as a ring variable
  throughout, not localized into the coefficient field). This is a general
  computer-algebra pitfall worth flagging for any future approach doing a
  similar elimination.
