## Lemma: Self-Absorbing Core Theorem (certified, round 14 — proof gap closed)

**Source.** `n1-periodicity-reconciliation` (round 13, new result; round 14, "combining
both parts" gap fixed after round 13's proof-reviewer flagged a hand-wave-by-citation
in the original write-up). Proposed for certification by this round's builder;
pending the proof-reviewer's independent confirmation before being treated as
load-bearing by other approaches.

**Status of conditionality.** This is a CONDITIONAL theorem: it assumes (i) a finite
core S* ⊇ S₀ is self-absorbing, and (ii) FAH holds at level S*. Neither hypothesis is
established anywhere in the workspace; both remain open (see "Open sub-gaps" below).
The theorem itself, GIVEN these hypotheses, is now proved with no gap.

**Setup (imported, not re-derived).** Fix the certified stack: Q = P(a₁), τ(n) =
P(a_n) ∩ Q (Persistent-Type Pigeonhole, `persistent-type-pigeonhole.md`), S₀ ⊇ Q the
finite core from the Finite Core Theorem (`finite-core-theorem.md`), and for any
finite S ⊇ Q, ρ_S(n) := P(a_n) ∩ S and 𝒫'(S) the finite, nonempty set of
S-extended-persistent types with threshold N(S), given by the Extended
Persistent-Type Pigeonhole (`extended-persistent-type-pigeonhole.md`, applied at
level S in place of S₀).

**Definitions.** For a finite S ⊇ Q for which 𝒫'(S), N(S) are defined, the
**absorption operator** is
  S⁺ := S ∪ ⋃_{j=1}^{N(S)} P(a_j)
(a finite union of finite sets, well-defined since N(S) is finite). Call S
**self-absorbing** if S⁺ = S, i.e. P(a_j) ⊆ S for every j = 1,...,N(S).

**Theorem.** Suppose S* ⊇ S₀ is self-absorbing and FAH holds at level S* (every two
elements of 𝒫'(S*) intersect, as subsets of S*). Let L* := ∏_{p ∈ S*} p and define,
for r ∈ Z/L*Z, sig(r) := {p ∈ S* : p | r} (well-defined by CRT), and

  G* := { r ∈ Z/L*Z : sig(r) ∩ P(a_j) ≠ ∅ for every j = 1,...,N(S*), AND
          sig(r) ∩ B ≠ ∅ for every B ∈ 𝒫'(S*) }.

Then G* is a fixed, finite, nonempty subset of Z/L*Z, and with T* := |G*|,

  a_{n+T*} = a_n + L*  for every n ≥ N(S*).

**Proof.**

*Step 1 (Sufficiency, for an arbitrary candidate c).* Fix n ≥ N(S*) and suppose c is
any integer with c mod L* ∈ G*.
- For j ≤ N(S*): self-absorption gives P(a_j) ⊆ S*, so
  gcd(c,a_j) > 1 ⟺ P(c) ∩ P(a_j) ≠ ∅ ⟺ (P(c) ∩ S*) ∩ P(a_j) ≠ ∅ ⟺ sig(c mod L*) ∩
  P(a_j) ≠ ∅ (the last equivalence is the standard CRT fact that p | c, for p ∈ S*,
  depends only on c mod L*). This holds by the first conjunct of G*'s definition.
- For N(S*) < j ≤ n: by Extended Persistent-Type Pigeonhole at level S*, ρ_{S*}(j) ∈
  𝒫'(S*). Taking B := ρ_{S*}(j) in the second conjunct of G*'s definition gives
  sig(c mod L*) ∩ ρ_{S*}(j) ≠ ∅; since ρ_{S*}(j) = P(a_j) ∩ S* ⊆ P(a_j), this is a
  common prime factor of c and a_j, so gcd(c,a_j) > 1.
Hence: (S) c mod L* ∈ G* ⟹ gcd(c,a_j) > 1 for every j = 1,...,n.

*Step 2 (Landing: the real a_{n+1} always lies in G*).* Fix n ≥ N(S*).
- First conjunct: by the certified, unconditional Free Facts Lemma
  (`free-facts-gcd.md`, part 1), gcd(a_{n+1},a_i) > 1 for every i = 1,...,n; in
  particular for every i = j ≤ N(S*). Fix such j: a prime p ∈ P(a_{n+1}) ∩ P(a_j)
  exists; self-absorption gives P(a_j) ⊆ S*, so p ∈ S*, hence p ∈ P(a_{n+1}) ∩ S* =
  sig(a_{n+1} mod L*). So sig(a_{n+1} mod L*) ∩ P(a_j) ≠ ∅ for every j = 1,...,N(S*).
- Second conjunct: n+1 > N(S*), so ρ_{S*}(n+1) ∈ 𝒫'(S*); write A' := ρ_{S*}(n+1) =
  P(a_{n+1}) ∩ S* = sig(a_{n+1} mod L*). The hypothesis "FAH holds at level S*" means
  A ∩ B ≠ ∅ for every two A, B ∈ 𝒫'(S*); applying it to the pair (A', B) for
  arbitrary B ∈ 𝒫'(S*) (valid since A' ∈ 𝒫'(S*)) gives A' ∩ B ≠ ∅, i.e.
  sig(a_{n+1} mod L*) ∩ B ≠ ∅, for every B ∈ 𝒫'(S*).
Combining: (L) a_{n+1} mod L* ∈ G*, for every n ≥ N(S*).

*Step 3 (Assembling periodicity).* Fix n ≥ N(S*). Let c' be any integer with a_n < c'
< a_{n+1}. By minimality of a_{n+1} (defined as the smallest integer exceeding a_n
legal against a_1,...,a_n), c' is not legal against a_1,...,a_n: gcd(c',a_j) = 1 for
some j ≤ n. By the contrapositive of (S), c' mod L* ∉ G*. So every integer strictly
between a_n and a_{n+1} has residue outside G*, while a_{n+1} itself has residue in
G* (by (L)). Hence a_{n+1} is exactly the smallest integer exceeding a_n whose residue
mod L* lies in the fixed set G*. This holds for every n ≥ N(S*) with the SAME G*, so
the residue sequence (a_n mod L*)_{n ≥ N(S*)} is generated by the deterministic map
"advance, cyclically in increasing residue order mod L*, to the next element of G*,
adding L* on wraparound" — a permutation of the finite nonempty set G* (nonempty by
(L)), consisting of a single |G*|-cycle (a cyclic advance through a finite totally
cyclically ordered set visits every element exactly once before repeating). Hence the
residue sequence is purely periodic with period T* := |G*| from n = N(S*) onward,
giving a_{n+T*} = a_n + L* for every n ≥ N(S*). ∎

**What this resolves.** This completely settles the "early transient term
disqualifies an eligible residue" obstruction (`covering-system-construction` Step
9.3, obstruction (i)): by enlarging the core to literally absorb every early term's
full factorization (not merely its S₀-intersection), the eligible-residue test G*
correctly incorporates ALL of a_1,...,a_{N(S*)}, not just their S₀-restricted parts,
and the "landing" direction — that the real greedy process never escapes to a
residue outside G* — is proved directly from the Free Facts Lemma (early conjunct)
and the FAH-at-S* hypothesis itself (persistent-type conjunct), with no citation to
any other construction.

**What this does NOT resolve (open sub-gaps, unchanged from the source file).**
(a) Existence/termination of a self-absorbing S*: it is not shown that iterating
S ↦ S⁺ from S₀ reaches a fixed point in finitely many steps. (b) Even granting (a),
N(S*) = 0 is not established — the theorem gives periodicity only for n ≥ N(S*), not
literally from n = 1, unless N(S*) happens to be 0. Both remain fully open.

**Precision note (round 14 proof-reviewer, added for future use).** The
hypothesis "FAH holds at level S* (every two elements of 𝒫'(S*) intersect)" is
mathematically EQUIVALENT to (not a stronger burden than) the standard
disjoint-base-type-only formulation of FAH used elsewhere in this workspace to
define gap (†): for any `A', B' ∈ 𝒫'(S)`, writing `A := A'∩Q`, `B := B'∩Q`,
the fact `ρ_S(n)∩Q = τ(n)` exactly (since `Q ⊆ S`) gives `A ⊆ A'`, `B ⊆ B'`; if
the base types `A, B` are NOT disjoint, any shared prime of `A,B` already lies
in `A'∩B'`, so non-disjoint-base-type pairs intersect automatically, for free,
independent of any FAH-type hypothesis. Hence "every two elements of 𝒫'(S*)
intersect" reduces to exactly "every two DISJOINT-base-type elements intersect"
(standard FAH) plus this free fact. The source approach file asserts this
equivalence without deriving it; this note supplies the missing one-line
derivation so a future round does not mistake the theorem's hypothesis for
something strictly stronger than standing FAH-at-S*.
