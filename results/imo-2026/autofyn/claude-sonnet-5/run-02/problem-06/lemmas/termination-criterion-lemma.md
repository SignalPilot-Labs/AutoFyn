## Lemma: Termination Criterion Lemma — CERTIFIED, round 15 (diagnostic/reduction,
sub-gap (a) NOT resolved)

**Source.** `n1-periodicity-reconciliation`, round 15 build. Independently
re-derived in full (both directions) and confirmed correct by the round-15
proof-reviewer.

**Depends on.** Only the Extended Persistent-Type Pigeonhole
(`extended-persistent-type-pigeonhole.md`, applied generically at any finite core
S ⊇ Q — confirmed reusable this way per round-14's certification note) and
elementary finite-set/chain combinatorics. Fully unconditional — no FAH hypothesis.

**Setup.** Define the absorption chain S_0 := S₀, S_{k+1} := S_k⁺ (the absorption
operator from `self-absorbing-core-theorem.md`: S⁺ := S ∪ ⋃_{j=1}^{N(S)} P(a_j)).
S_k ⊆ S_{k+1} always. The process **terminates** if S_k = S_{k+1} for some k
(equivalently S_k is self-absorbing).

**Statement.** The absorption process (S_k)_{k≥0} terminates in finitely many
steps if and only if the sequence of thresholds (N(S_k))_{k≥0} is bounded (there
is a finite M with N(S_k) ≤ M for every k).

**Proof.**

*(⟹)* If the process terminates at step K, N(S_k) = N(S_K) (constant) for all
k ≥ K, and N(S_0),...,N(S_{K-1}) are each individually finite (Extended
Persistent-Type Pigeonhole applied at each of the finitely many distinct cores
S_0,...,S_{K-1}). A max over finitely many finite values is finite, so
(N(S_k))_{k≥0} is bounded.

*(⟸)* Suppose N(S_k) ≤ M for every k, for some finite M (M need not be
effectively known — only asserted to exist). Define the FIXED finite set
P*_M := ⋃_{j=1}^{M} P(a_j) (a finite union of the finitely many prime factors of
the specific integers a_1,...,a_M — completely unconditional, no pigeonhole
needed). By induction on k, S_k ⊆ S_0 ∪ P*_M: base case trivial; inductive step,
S_{k+1} = S_k ∪ ⋃_{j=1}^{N(S_k)} P(a_j) ⊆ S_k ∪ ⋃_{j=1}^{M} P(a_j) (since
N(S_k) ≤ M, the union over a shorter index range is a subset) = S_k ∪ P*_M ⊆
(S_0 ∪ P*_M) ∪ P*_M = S_0 ∪ P*_M. So every S_k lies inside the fixed finite set
S_0 ∪ P*_M of size m. The chain is non-decreasing and, at every non-terminating
step, strictly increasing (S_{k+1} ⊋ S_k, since "not self-absorbing" means some
j ≤ N(S_k) has P(a_j) ⊄ S_k). A monotone strictly-increasing chain of subsets of
a fixed m-element set can strictly increase at most m − |S_0| times, so the
process terminates within m − |S_0| + 1 steps. ∎

**What this resolves.** Replaces the informal "does S ↦ S⁺ converge?" question
(sub-gap (a) of `n1-periodicity-reconciliation`) with a precise, equivalent
numerical criterion (boundedness of the actual sequence N(S_0), N(S_1), ...).

**What this does NOT resolve (honest, not overclaimed).** Boundedness of
(N(S_k))_{k≥0} is itself NOT established by this lemma or anywhere else in the
workspace — no certified tool currently bounds how the Extended Persistent-Type
Pigeonhole threshold behaves under the specific core-enlargement sequence
generated by iterating S ↦ S⁺. This is flagged (not proved) to be a question of
comparable general shape — a greedy/monotone-enlargement process governed by a
non-constructive pigeonhole threshold — to the sibling, still-open FAH/
recruitment-process termination question, and to the "refinement can manufacture
new classes" phenomenon documented in `witness-discontinuity-obstruction.md`. It
is a logically DISTINCT object (the absorption chain, built from early-term full
factorizations, differs from the recruitment chain, built from forced-witness
primes on rogue base-type pairs) — no claim of equivalence in difficulty to FAH is
made or established, only a structural analogy.

**Verification note (round 15 proof-reviewer, CERTIFIED).** Independently
re-derived both directions from scratch. (⟹) is a one-line finite-max argument.
(⟸) is a correct, standard monotone-finite-chain argument; checked in particular
that P*_M is genuinely independent of k (built only from the fixed integers
a_1,...,a_M, not from S_k itself), so the induction is non-circular, and that the
"strictly increasing at every non-terminating step" claim correctly follows from
the definition of self-absorption (¬self-absorbing at S_k ⟺ some j ≤ N(S_k) has
P(a_j) ⊄ S_k ⟺ S_{k+1} ⊋ S_k). No gap found. **Certified** as a diagnostic/
reduction lemma (matching the Lemma-F/Lemma-I precedent for honestly-reported,
not-yet-closing content, but certified as reusable positive machinery since it
is a genuine iff, not merely a negative diagnosis).
