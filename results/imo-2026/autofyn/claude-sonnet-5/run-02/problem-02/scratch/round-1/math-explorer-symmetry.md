Since MN ∥ BC (midline, length BC/2) and this bisector is perpendicular to BC, the claim OM=ON is algebraically equivalent (for any point O) to `(O − X)·(C−B) = 0` where X is any fixed point already known to be equidistant from M,N. Take X = the nine-point center N9 of ABC (equidistant from M,N automatically since M,N lie on the nine-point circle). Then `OM²−ON² = 2(O−N9)·(N−M)`, so OM=ON ⟺ **the vector O−N9 is perpendicular to BC** (equivalently parallel to the altitude from A). This reformulation is a genuinely different, possibly more tractable target than chasing OM and ON directly — it turns a "two distances equal" claim into a "one vector is perpendicular to a fixed direction" claim, which is often more amenable to a spiral-similarity / rotation argument or a coordinate computation with a smaller number of terms. NOTE: O is *not* equal to N9 in general (verified numerically, distance from O to N9 varies nontrivially as the parameter moves) — so don't try to prove O=N9; only that O−N9 ⊥ BC.
