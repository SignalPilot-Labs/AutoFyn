ALWAYS: before trusting an outline's claim that an angle equality "has the shape of the inscribed-angle/concyclicity criterion," check explicitly whether the two equal angles share a COMMON pair of arm-points (both arms must match, e.g. ∠XPY=∠XQY needs the same X,Y) — an equality like ∠LBK=∠LNC shares only one arm (L) between vertices B and N, so it is NOT the classical criterion on any 4 of the named points; this a priori structural check is cheap and should precede/accompany the numerical gate (round 1, imo-2026-02).
NEVER: use scipy.optimize.fsolve with path-continuation (single initial guess, sweep one parameter) to search for valid geometric configurations under containment/inequality constraints — it follows one branch and can entirely miss the containment-satisfying region; use random multi-start least_squares (many random initial points respecting the intended containment regions, e.g. barycentric-random points inside the target sub-triangles) instead, which reliably finds the valid branch (round 1, imo-2026-02).

NEVER: expect a single round's budget to close a full symbolic circumcenter identity for a genuinely hard (IMO P2/P3-level) geometry problem via brute polynomial elimination — the intermediate polynomials blow up to degree 5+ in 2 variables within 2-3 elimination steps; budget explicitly for reporting a structural partial result (e.g. "unknown K is constrained to a fixed named-triangle-dependent algebraic curve") rather than gambling the whole round on reaching a clean 0=0 remainder (round 1, imo-2026-02).
ALWAYS: before trusting a "relabeling symmetry σ swaps two labeled points ⟹ target is antisymmetric ⟹ target=0" proof strategy, check whether the target quantity's sign-flip under σ is a PURE TAUTOLOGY of its own algebraic definition (e.g. any OM²-ON² is trivially antisymmetric under swapping the names M,N for ANY point O, no hypotheses needed) — if so, the mechanism carries zero constraining power (it needs a second, non-tautological relation T(swapped)=+T(original), which relabeling alone never supplies, only an actual geometric isometry does); verify by symbolically computing target+target(swapped) with FULLY FREE unconstrained coordinates in sympy — if it's identically 0 with no hypothesis substituted, the mechanism is vacuous (round 2, imo-2026-02).
ALWAYS: when polynomial division of a target-numerator by an elimination-equation (in one variable, coefficients rational functions of others) yields remainder coefficients that are large messy rational-function expressions, run `sympy.cancel` on each remainder coefficient individually (not `sympy.simplify`/`factor` on the raw fraction) — this correctly reduces common factors between numerator and denominator and reveals a clean `(known_factor)*(new_factor)/(other_known_factor)` structure that a full-fraction `factor()` call can obscure; this is how the "closing identity" gap in imo-2026-02 was actually found from scratch after a previous round's copied/unverified formula failed to reproduce (round 2, imo-2026-02).
NEVER: trust a "cofactor identity" or similar closing-the-gap claim carried over from another agent's report without re-deriving Fn_num (or equivalent target numerator) via your OWN fresh circumcenter-formula/fraction-clearing computation first — sign conventions (which point's coordinate you solved for, order of subtraction) differ enough between independent scripts that a copied formula's specific polynomial (e.g. a claimed auxiliary factor D2) can be numerically/structurally real while the exact equation asserted around it is false; always regenerate the target quantity from the raw geometric formula and verify the closing identity by `sympy.expand(LHS-RHS)==0` in your own script (round 2, imo-2026-02).
