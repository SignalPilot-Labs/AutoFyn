### self-similar-potential-certificate: new
Target: c(n) = 2^n/(2^{n+1}-1) for every n — both directions, general n, via a single certificate valid for all n simultaneously (not a case-by-case strategy family or an ad hoc LP region split).
Technique: a **static weight/potential-function certificate** (the LP-duality idea, but realized as one explicit self-similar function rather than an enumerated finite strategy family) — genuinely different framing from both live approaches: instead of "name Xiang Yu's move" (greedy-halving-adversary) or "enumerate finitely many template moves and contradiction-argue over a region split" (smoothing-compactness-certificate), this approach builds a single fractal/self-similar weight function tied to the ladder's own self-similarity and proves it dominates *every* achievable final configuration at once, by induction on the certificate's recursive definition rather than on strategies.
Skeleton:
  1. Import Lemma 1 (claiming reduction) and Lemma 2 ($\Phi(S)=(\mathrm{Total}(S)+A(S))/2$, $A(S)=\int_0^\infty\mathbb1[N(x)\text{ odd}]dx$).
  2. **Define the certificate recursively**, mirroring the self-similarity already found (ladder's tail rescaled = smaller ladder): for budget $n$, define a "potential" $\Psi_n(S)$ on any finite multiset $S$ with total mass $T$ as follows — sort $S$ descending, isolate the largest element $M$ and the rest $S'$ (total $T-M$); set $\Psi_n(S) := M - \Psi_{n-1}(S')$ if $M > T-M$ (superincreasing-at-top case), else a base value reflecting the "no dominant element" regime (to be pinned down: likely $\Psi_n(S):=(T)/2$ when no element exceeds half the total, matching Lemma 4's forced-$1/2$ result). Base case $\Psi_0(S) = $ the single remaining element (or $0$ for empty $S$).
  3. **Certificate lemma (the crux to prove):** for every achievable final multiset $S$ reachable from the ladder $p_1,\dots,p_{n+1}$ by any Xiang Yu response with $\le n$ cuts, $A(S)\ge \Psi$-value evaluated on the *original* ladder (a fixed number, $1/(2^{n+1}-1)$), i.e. the certificate is **cut-monotone**: show directly that a single cut of any one piece changes $A(S)$ by an amount bounded below using the recursive structure — specifically, prove by induction on the number of cuts used so far that $A(S)\ge \Psi_n(\text{ladder}) $ is maintained as an invariant, using the identity from Lemma 2 (splitting the integral at the *current* largest element's threshold, exactly generalizing Lemma 6's method but applied inductively per-cut rather than per whole strategy).
  4. **Matching construction (upper bound half):** show the same recursive $\Psi_n$ definition, read as a *strategy* (always cut to make the current max exactly match $T-M$'s achievable structure via the $(n-1)$-certificate applied to $S'$), is realizable with exactly $n$ cuts and achieves $A=1/(2^{n+1}-1)$ against the ladder, and — crucially — against *any* Liu Bang config, achieves $A\le \Psi_n(\text{that config})\le 1/(2^{n+1}-1)$ whenever the config is not itself the ladder (strict domination), closing the general upper bound in the same single argument.
Key lemmas (claim + mechanism):
  - Self-similarity: $\Psi_n$'s recursive definition applied to the ladder reproduces exactly $1/(2^{n+1}-1)$ — because the ladder's tail rescaled by $1/r$ *is* the $(n-1)$-ladder (already verified algebraically: $p_i/r=2^{(n-1)+1-(i-1)}/(2^{(n-1)+1}-1)$), so $\Psi_n(\text{ladder}) = p_1 - r\cdot\Psi_{n-1}(\text{ladder}_{n-1})$ telescopes to a clean closed form solvable by the same recursion that generates $1/(2^{n+1}-1)$ from $1/(2^n-1)$ (check: $p_1 - r/(2^n-1) = 2^n/(2^{n+1}-1) - \frac{2^n-1}{2^{n+1}-1}\cdot\frac1{2^n-1} = \frac{2^n-1}{2^{n+1}-1} = 1/(2^{n+1}-1) \cdot(2^n-1)$... — the builder must carry out this telescoping check exactly and confirm it lands on $1/(2^{n+1}-1)$, not merely something proportional to it; this arithmetic check is the first thing to verify before investing in the rest).
  - Cut-monotonicity: any single cut of a piece $L$ into $L_1,L_2$ changes $A(S)$ in a way controlled by which side of the *current* threshold structure $L_1,L_2$ land — this is exactly the "monotonicity sub-claim" already proved in Lemma 1's write-up (decreasing one coordinate of a sorted multiset is $A$-monotone in a specific direction), so this step **reuses a certified lemma** rather than needing new machinery.
Open gaps: the precise recursive definition of $\Psi_n$ in the "no dominant element" branch (step 2) is only sketched, not pinned down; the telescoping arithmetic check in Key lemma 1 must be verified exactly before the rest of the plan is trusted (do this first, cheaply, by hand or `sympy`); the cut-monotonicity argument (step 3) needs to be carried out per-cut rather than per-strategy, which is a genuinely new proof obligation even though it reuses Lemma 1's sub-claim.
Cases to cover: the two branches of $\Psi_n$'s definition (dominant top element vs. no dominant element) at every recursive level.
Watch out for: this is the round's designated "far from the wall" approach — if the arithmetic telescoping check in Key lemma 1 fails, do NOT patch it with a case-by-case correction (that collapses back into the same finite-template wall as smoothing-compactness-certificate); instead report the failure honestly as a refutation of this specific certificate shape, distinct from a slow partial success.

### integer-lattice-reduction: new
Target: c(n) = 2^n/(2^{n+1}-1) for every n — a genuinely different top-level reduction: reduce the continuous game to a discrete integer-combinatorics problem before attacking it, rather than working in $\mathbb{R}$ throughout.
Technique: compactness + rational-density reduction (the game value is achieved by a continuous function on a compact simplex — extreme value theorem — and is piecewise-linear/rational in any rational configuration by Lemma 1's rank-sum formula) to justify restricting to a **finite-denominator discrete version**: WLOG Liu Bang's optimal config has all $p_i \in \frac1D\mathbb Z$ for some common denominator $D$ (approximation argument: the game value function is Lipschitz/continuous in the $p_i$, so the sup over the simplex equals the sup over a dense rational subset, and by piecewise-linearity that sup is attained on a rational point — this needs a genuine argument, e.g. that the optimal region for a fixed combinatorial "response type" is a rational polytope, so its optimum is a rational vertex), then solve the purely discrete problem: "$n+1$ positive integers summing to $D$, Xiang Yu splits with $\le n$ integer-preserving cuts (each replacing one integer by two positive integers summing to it) to minimize the alternating sum of the sorted list" by strong induction on $D$ using **binary-digit / superincreasing-sequence characterization** (a classical fact in the flavor of the "weighing problem with powers of two", adapted from generic subset-sum reasoning in the combinatorics knowledge base).
Skeleton:
  1. Justify the rational reduction: fix the combinatorial "type" of Xiang Yu's globally optimal response (which rank each fragment/piece ends up at) — for fixed type, both $\Phi$ (Liu Bang's payoff for a fixed Liu Bang config against Xiang Yu's best type-consistent response) and the feasibility region of that type are piecewise-linear/rational in the $p_i$; since there are finitely many types (bounded by $n$), the outer $\min$ over types of a piecewise-linear function is piecewise-linear, and its $\max$ over the simplex (a rational polytope) is attained at a vertex of the arrangement, which is a rational point. State this as a citation of standard LP theory (vertices of a bounded polyhedron defined by rational inequalities are rational) rather than re-derive from scratch.
  2. Clear denominators: scale to integers $q_1\ge\dots\ge q_{n+1}$, $\sum q_i = D$, and restate the extremal claim purely in $\mathbb Z_{>0}$: Xiang Yu uses $\le n$ splits (each split replaces one part $m$ by two parts $a,m-a$, $0<a<m$, not necessarily integers even here — cuts need not land on integer points even if the $q_i$ are integers, so this step needs to justify that Xiang Yu's *optimal* response can also be taken rational/integer-comparable, likely via the SAME piecewise-linearity argument applied one level down, restricted to Xiang Yu's own optimization for a fixed Liu Bang config).
  3. Prove the discrete extremal claim — "$q_i=2^{n+1-i}$ (i.e. $D=2^{n+1}-1$) uniquely maximizes Xiang Yu's minimum achievable residual, which equals $1$" — by strong induction on $n$, using the superincreasing property $q_1 = \sum_{j>1}q_j + 1$ as the exact borderline that makes exact 2-partition (residual 0) impossible with only $n$ splits, generalizing the classical fact that a superincreasing sequence cannot be 2-partitioned into equal halves except by using every element split at least once (a counting/budget argument: $n+1$ parts need $n$ splits just to reach $2(n+1)/2$-many pieces sufficient for a perfect pairing, using every split optimally, and the "+1" imbalance is exactly what one split short cannot absorb).
  4. Transport the discrete result back to the continuous claim via step 1's rationality argument.
Key lemmas (claim + mechanism):
  - Rational-vertex reduction — because the game value is the max of a min of finitely many rational-piecewise-linear functions over a rational polytope, a standard LP/polyhedral fact (cite as "vertices of a rational polyhedron are rational," a standard result, not re-derived).
  - Superincreasing sequences uniquely resist 2-partition with a one-split-short budget — because splitting $n+1$ parts into 2 groups of near-equal sum using only $n$ splits is exactly one split short of what is needed to make every part individually divisible into the other group's shape, and the "+1" gap in $q_1=\sum_{j>1}q_j+1$ is the minimum possible imbalance achievable, forced by the discrete pigeonhole on how many parts can be fully absorbed.
Open gaps: step 1's rationality argument is only sketched at the level of "cite standard LP polyhedral theory" — the builder must actually verify the finitely-many-types claim and that each type's region + payoff really is rational-affine (this could be subtle since "type" includes continuous branch points, e.g. Lemma 6's threshold $r$ vs $p_1$ comparison); step 3's induction is the same combinatorial core difficulty as the other approaches' open gaps, just recast in $\mathbb Z_{>0}$ — restating in integers may or may not make it easier, this is the main risk of this approach and should be evaluated honestly next round (if the integer version turns out to need exactly the same case analysis as the continuous version, this approach adds no leverage and should be marked low priority).
Cases to cover: none beyond the general induction in step 3.
Watch out for: this approach's main risk is that the "rationalization" step (1–2) is significant technical overhead that may not simplify anything (the hard combinatorial core in step 3 is the same subset-sum/matching difficulty already identified by both live approaches) — treat this round's build as primarily a **feasibility probe** on whether working in $\mathbb Z_{>0}$ genuinely simplifies the superincreasing-domination argument (e.g. via clean binary-representation induction) before investing in the full rationalization machinery of step 1; if the discrete core is just as hard, report that honestly rather than padding with the (comparatively easy) rationalization argument.
