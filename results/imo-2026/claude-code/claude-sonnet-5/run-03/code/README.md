# Verification certificates: OM = ON (midpoint circumcenter problem)

These scripts back up the proof that, for triangle `ABC` with midpoints
`M` (of `AB`) and `N` (of `AC`), points `K` inside `△BMC` and `L` inside
`△BNC` satisfying the three given angle conditions, and `O` the
circumcenter of `△AKL`, we always have `OM = ON`.

Requires: `numpy`, `scipy`, `sympy` (`pip install numpy scipy sympy`).

## Files

- **`common.py`** — shared helpers: builds the 1-parameter family of
  valid `(K, L)` for a given triangle and free angle `x = ∠KBA = ∠ACL`
  by numerically solving the two remaining angle conditions
  (`∠LBK = ∠LNC`, `∠LCK = ∠BMK`) for `t = BK`, `s = CL`.

- **`01_main_claim_OM_eq_ON.py`** — confirms the main result `OM = ON`
  across the whole family (varying `x`) for a fixed triangle, and
  shows `O` traces exactly the perpendicular bisector of `MN`.

- **`02_lemma2_angle_identity.py`** — confirms **Lemma 2** of the
  written proof: `∠MKC = ∠NLB = π − ∠BAC − x`, on two independent
  random triangles.

- **`03_quadratics_QK_QL.py`** — confirms **Lemma 3**: `BK` and `CL`
  satisfy the explicit quadratics `Q_K(t) = 0`, `Q_L(s) = 0` derived
  from Lemma 2 via the Law of Cosines.

- **`04_symbolic_ideal_membership.py`** — the crux computational step:
  an **exact symbolic** (sympy, not floating point) proof that
  `pow_B(⊙AKL) − pow_C(⊙AKL) − (AB² − AC²)/2`, cleared of the
  denominator hidden in the circumcenter formula, reduces to the
  *exact zero polynomial* modulo the ideal generated by `Q_K(t)` and
  `Q_L(s)`. This is what closes the proof: whenever `t, s` satisfy
  Lemma 3's quadratics, the power-of-a-point identity equivalent to
  `OM = ON` (Lemma 1) holds identically. Run this one to see all four
  reduced coefficients print as literal `0`.

- **`05_end_to_end.py`** — chains all of the above (Lemma 2, Lemma 3,
  main claim) on one more independent, freshly chosen triangle, across
  several values of `x`.

## Running

```
cd verification
python3 01_main_claim_OM_eq_ON.py
python3 02_lemma2_angle_identity.py
python3 03_quadratics_QK_QL.py
python3 04_symbolic_ideal_membership.py
python3 05_end_to_end.py
```

All numerical residuals should be on the order of `1e-10` or smaller
(floating-point noise), and `04` should print all coefficients as
exactly `0`.
