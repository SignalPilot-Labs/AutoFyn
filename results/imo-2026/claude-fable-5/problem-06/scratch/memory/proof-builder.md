# proof-builder per-role rules

ALWAYS: before proving a "pure combinatorial" abstraction of a number-theoretic structure, spend bounded effort building a counterexample from graph duality (paths vs. minimal finite cuts of an infinite locally finite graph are blockers of each other; delta-composition {{1,2}} ∪ {1}+L1 ∪ {2}+L2 glues a dual pair into one identically self-blocking clutter) — it refuted the round-1 target outright (round 1).
NEVER: enumerate minimal s–t cuts of an infinite graph from the s-side only in a computer check — minimal cuts also arise as δ(W) for finite W containing t, and omitting them produced false counterexamples to a true lemma before being diagnosed (round 1).
ALWAYS: when a refutation kills a slug, record it as a reusable "no-go / hypothesis-filter" promotable lemma and list exactly which extracted properties the counterexample satisfies, so rivals know which of their pending lemmas are unprovable purely (round 1).
ALWAYS: For greedy-sequence problems, extract the STATIC residue of greedy minimality as an explicit lemma ("every excluded element has an EARLIER witness") before hunting counterfactual arguments — it was the exact leverage that closed imo-2026-06's GAP A (round 1).
NEVER: Trust an outline's empirical claim without re-testing at larger seeds — "∪M ⊆ {p ≤ g} in all tests" was false at a_1=385 ({2,11,19} ∈ M, g=14); prove the weakest bound that suffices, not the prettiest (round 1).
NEVER: Attack the intersecting family M of imo-2026-06 with covering/density arguments alone — any constructed AP of terms has some member's radical in its modulus and every Y ∈ M shares a prime with that member, so the AP is covered for free; minimality must enter quantitatively (two attacks died this way, round 1).
ALWAYS: Cap external-lookup time at ~5 min — AoPS is Cloudflare-blocked from this container and Google/DDG have no 2026 IMO content indexed (round 1).
ALWAYS: When directed to extract shared lemmas, write them with a "Certification: proposed (round N, by <builder>)" header line so the proof-reviewer can flip it to certified; see results/imo-2026-06/lemmas/ for the format (round 1).
