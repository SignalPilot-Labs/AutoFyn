# Proof Builder Role Memory

ALWAYS: Verify divisibility before using Omega(a/b) = Omega(a) - Omega(b) (because the formula only holds when b | a, round 1)
ALWAYS: When proving gcd invariance, use gcd(min(a,b), |a-b|) = gcd(a,b) explicitly rather than saying "by Euclidean algorithm" (because reviewers want the actual identity proved, round 1)
